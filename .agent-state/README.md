# .agent-state — состояние проверок агента

Рабочее состояние гейта и его инструментов. **Вне git**: в репозитории лежит
только этот файл, всё остальное игнорируется (`.gitignore`). Каталог называет
манифест проекта — `project.json → state`; инструменты берут путь оттуда и
создают каталог сами, когда он нужен.

## Что здесь лежит

| Что | Кто пишет | Зачем |
|---|---|---|
| `runs/run-<ГГГГ-ММ-ДД>-<ЧЧММСС>-<id>.jsonl` | `.agents/tools/runlog.mjs` — его зовут сенсор, линтер ДС и аудит спек | журнал прогонов: время, инструмент, файл, вердикт и **сработавшие** коды. По нему `lessons-cli stats` отвечает, сработал ли сторож на настоящей работе и не вернулся ли дефект после закрепления урока |
| `gate-snapshot.json` | `.agents/tools/lessons-cli.mjs gate` | отпечатки файлов (путь → время и размер) и список упавших шагов: по ним гейт решает, что перепроверять, и не даёт красному шагу исчезнуть молча |

Один прогон гейта — один файл журнала: все инструменты, которые он запускает,
пишут в него (путь приходит переменной окружения `RUNLOG_FILE`). Отдельный
запуск инструмента — свой файл. Хранятся последние 2000 строк: когда
появляется новый файл, самые старые удаляются целиком, поэтому разрыва в
истории нет. Фикстуры в журнал не пишутся намеренно — иначе «код срабатывал»
стало бы верно для любого сторожа с фикстурой, и сигнал обнулился бы.

## Почему вне git

Состояние меняется при каждом прогоне. Внутри репозитория оно давало бы шум в
`git status`, конфликты при слиянии веток и случайные коммиты — а после
разводки частей проекта по разным репозиториям пачкало бы чужой репозиторий
после каждой проверки. Поэтому с 21.09.2026 состояние живёт здесь
(реструктуризация, шаг Ш4).

## Что это значит на практике

- **Свежий клон — пустая история.** `stats` начинает копить сигнал с первого
  прогона на этой машине, а первый гейт идёт полным: снимка ещё нет.
- **Каталог можно удалить целиком.** Это не поломка: инструменты создадут его
  заново, гейт прогонит всё и запишет новый снимок. Потеряется только история
  прогонов этой машины.
- **Руками здесь ничего не правят.** Журнал и снимок — производные от работы
  инструментов.

Проверить состояние журнала: `node .agents/tools/lessons-cli.mjs state`;
что случилось после закрепления уроков — `… lessons-cli.mjs stats`.
