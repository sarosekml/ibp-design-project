# Прототипы IBP — вход для агентов

`AGENTS.md` — открытый формат файла правил: его читают разные агентные CLI.
Здесь только указатели; правила живут там, куда они ведут.

## Где что

| Что | Где | Когда читать |
|---|---|---|
| Правила процесса: проект, границы записи, файлы, проверки, контекст, самообучение | `.agents/rules/process.md` | в начале задачи, целиком |
| Дизайн-система и её правила для агента: карта, чтение, запреты, каркас экрана, каталог компонентов | `design-system/AGENTS.md` | в начале задачи, целиком |
| Харнес агента: роли, команды, скиллы, оснастка | `.agents/` (вход — `.agents/AGENTS.md`, весь рабочий процесс — `.agents/README.md`) | по роли и шагу задачи |
| Структура проекта: где ДС, харнес, хаб, треки приложений | `project.json` | когда нужен путь |
| Приложения: экраны и их спеки, трек в `app.json` | `apps/` (обзор — `apps/README.md`) | перед сборкой экрана |
| Адрес ДС — строка `DS_PATH` в `apps/ds-config.js`; загрузчик и реестр хаба генерируются, руками не правятся | `apps/ds-config.js`, `apps/ds-body.js`, `hub.js` (`.agents/tools/boot-build.mjs`, `hub-build.mjs`) | когда меняется путь до ДС или приложение |
| Адаптер opencode — один файл: пути до харнеса, режимы и права ролей | `.opencode/opencode.json` | правится вместе с `.agents/` |

## Главное правило

Ничего не выдумывать. Цвет, размер, отступ, радиус, шрифт, класс, имя иконки —
только из дизайн-системы. Нет нужного — спросить, а не изобрести.

## Роли и команды

Ведущая роль — `ai-designer` (`.agents/agents/ai-designer.md`): говорит с
пользователем и распределяет работу по ролям `screen-builder` (сборка) и
`screen-reviewer` (приёмка); `ux-researcher` выключен, пока нет базы знаний.
Команды — `.agents/commands/`: `/screen`, `/screen-check`, `/concepts`,
`/handoff`, `/resume <Задача>`.

**Если инструмент не подхватывает роли, команды и скиллы сам — роль, команда
и скилл берутся чтением файла из `.agents/`, и работа идёт по нему в той же
сессии.** Субагент запускается только по прямой просьбе пользователя.

## Проверка

Заход закрывается одной командой, строка `ВЕРДИКТ:` идёт в отчёт:

```bash
node .agents/tools/lessons-cli.mjs gate
```
