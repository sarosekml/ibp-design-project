    Как устроены темы

    Тема — JSON-файл в папке foundations/Themes/tokens/. Выбранная тема действует на всех страницах ДС; на экранах прототипов её выбирают в панели прототипа. Без выбора действует IBP Legacy — нынешняя ДС без атрибута data-theme.

    Базовые файлы: IBP Legacy — нынешняя ДС, только светлая; IBP Neo — тема по алгоритму, светлая по эталону «Colors / Core»; Custom — сиреневая. Legacy и Neo закрыты от перезаписи: доработку сохраняйте через «Сохранить как…». Служебная тема панели прототипа живёт отдельно.

    Файлы и база

    Профиль режима (light, dark) задаёт brand и neutral — цвет опорной ступени, brandStep и neutralStep — саму ступень (по умолчанию 500), adjust — тон, насыщенность, температуру, overrides — ручные правки ступеней и ролей, onFill — текст на заливке. Остальные 17 тонов — фиксированные базовые растяжки base-light.json и base-dark.json. tokens.data.js — зеркало всех JSON для file://.

    Алгоритм

    Опорная ступень — ровно заданный цвет, остальные строятся по кривой эталона. Светлая — по растяжке «Colors / Core»: светлота пропорционально сдвигается к белому и чёрному, доля насыщенности и сдвиг тона — как у эталона. Тёмная — по общей тёмной шкале: края (50 и 950) на месте, опорная ступень — ровно вход. Цвет вне sRGB теряет насыщенность, тон сохраняется.

    Правка ступени в конструкторе переносит опорную точку на эту ступень — растяжка сдвигается за ней. Переключатель «Только эта ступень» в пикере оставляет точечную ручную правку.

    Основная кнопка — ровно brand 500 в обеих темах; наведение и нажатие — ступени 600 и 700. Заливку ради контраста не затемняем: текст на ней — «белый» или «тёмный» в «Настроить», провал виден на вкладке «Контраст» в «Все цвета».

    «Сгенерировать» (пробел) даёт случайный тон; светлота и насыщенность — как у ступени 500 IBP Legacy (brand #00AA9B, neutral #617C7C). Метод задаёт тон neutral относительно brand.

    Слои токенов

    Цвет доходит до компонента по цепочке: --ramp-neutral-50 → --color-bg-inverse → --bg-hint → --tip-bg. Тема меняет только первые два слоя.

    Палитра — рампы --ramp-*: 19 тонов по 11 ступеней. Генерируются только brand и neutral, остальные 17 — базовые растяжки.

    Токены темы — 160 ролей --color-*. Роль называет назначение цвета, а не сам цвет: --color-bg-raised — «поднятая поверхность» для модалки, Drawer и поповера. Роль ссылается на ступень рампы, поэтому смена brand или neutral перекрашивает все её места разом. В конструкторе правится роль.

    Токены UI-kit — 119 имён из UI-kit разработки (--primary, --text-primary, --bg-tile…). Компоненты пишут их. В IBP Legacy у них исходные значения, в остальных темах каждое ссылается на свою роль (--bg-tile: var(--color-bg-surface)), поэтому компоненты перекрашиваются без правок. Несколько имён могут вести в одну роль; имя правится через свою роль.

    Токены компонентов — переменные в CSS компонента (--tip-bg, --ddl-bg): настройка одной детали одного компонента. Своего цвета у них нет, тема ими не управляет — они берут значение слоем выше.

    Статусы и графики фиксированы; акцентные статусы следуют за brand.

    Сохранение

    Chromium пишет JSON и зеркало в подключённую папку tokens (File System Access API); разрешение браузер может спросить в новом сеансе. Firefox и Safari: «Скачать JSON», положить файл в tokens и пересобрать зеркало: node design-system/tools/theme-build.mjs. Несохранённое живёт до перезагрузки; перед уходом страница предупреждает.

    API

    DSTheme.get(), DSTheme.set(name, mode), DSTheme.list(), DSTheme.files(), DSTheme.selection(). Старые id ibp-light и ibp-dark ведут на IBP Neo. Событие ds:themechange.

    Проверки

    node design-system/tools/theme-build.mjs --check — источники, legacy, контраст, свежесть зеркала и CSS; --selftest — алгоритм; node design-system/tools/theme-files-selftest.mjs — запись, защита базы и откаты.
