ColorPicker

Выбор одного цвета в sRGB: поле насыщенности и яркости, тон, Hex, пипетка и копирование. Открывается в Popover или размещается в форме.

Использование

Для правки цвета. Имя роли и её назначение задаёт окружающая форма.

Анатомия

Сверху — SV-поле с маркером (насыщенность по горизонтали, яркость по вертикали), под ним — Slider тона без подписи. Ниже строка: InputText S с плашкой текущего цвета слева, IconButton «Пипетка» (dropper, только где есть EyeDropper) и «Копировать» (copy). Подвал появляется, когда потребитель передал footer или onReset: слева слот, справа «Сбросить».

С подвалом: слот и «Сбросить»

Варианты

У триггера — bind(trigger, opts) открывает пикер в Popover M рядом с кнопкой или плашкой; дальше триггер сам открывает и закрывает пикер по клику, open() — только для программного открытия; повторный bind того же триггера перенастраивает живой пикер, а не создаёт второй. В форме — create(root, opts) встраивает пикер в поток страницы, ширина — по контейнеру.

Размеры

SV-поле — квадрат во всю ширину пикера, маркер 14px; у триггера — Popover M, 320px (поле 288 × 288), без прокрутки. Поле Hex — InputText S, кнопки — IconButton M. В форме ширина пикера — по контейнеру, рекомендуемая — от 240px.

Контент

Hex принимает «18a59e», «#18A59E» и «#abc». Ошибка формата — текстом, только по Enter или уходу из поля, не на каждое нажатие.

Поведение

SV — pointer drag; стрелки меняют S/V на 1%, Shift на 10%. Тон — Slider; Hex применяется сразу после полного корректного ввода. onChange — каждое промежуточное значение, onCommit — законченная правка.

Состояния

Default — все части доступны. Disabled — disabled: true или picker.disabled(true): ввод выключен, цвет виден. Ошибка Hex — некорректный ввод после Enter или ухода из поля: поле в состоянии Error, под ним подсказка «Цвет в формате #RRGGBB»; цвет остаётся прежним. Отмена пипетки (Esc) цвет не меняет.

Доступность

SV — role=slider с aria-valuetext; тон и Hex имеют label. Без EyeDropper кнопка скрыта.

Типографика

Подписи полей — LabelHelper, кнопки — Buttons; компоненты используют шрифты ДС.

Цвета

Цветовое поле показывает функциональные значения HSV; хром — цвета ДС. Только непрозрачный sRGB, альфа не редактируется.

Для разработчиков

Рантайм ColorPicker.js подключён в ds.js. API: create(root, opts), bind(trigger, opts) → { picker, open, close, configure, destroy }. События: опции onChange (каждое движение) и onCommit (законченная правка); на корне всплывает colorpicker:change с detail { value, final }. Эталонная разметка — во вкладке «Код».
