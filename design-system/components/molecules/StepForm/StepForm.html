StepForm

Пошаговая форма — шаги «номер и подпись слева, контролы справа», разделённые пунктиром, с заметкой внизу. Шаг заполнен — номер сменяется галочкой. Собирается из StepMarker, полей InputText, чипов Chip, вложенной подложки Tile Inset и заметки Note. Своего фона, рамки и полей нет — их даёт контейнер.

Использование

Форма, где порядок шагов важен и пользователь видит, что уже заполнено: конструктор запроса в панели поля ввода, мастер настройки в боковой панели. Выберите объект и фокус — шаги отметятся галочкой.

Конструктор запроса — живое демо

Когда использовать

  • форма разбита на 2–5 шагов, и заполненный шаг стоит показать: номер сменяется галочкой;
  • у шага есть подпись, которая объясняет, что выбирать, а контролы — поле, чипы или оба.

Не используйте для обычной формы полей с метками — там поля ДС со своей меткой (InputText, TableFilter). Навигация по экранам мастера — Stepper (бэклог ДС), а не StepForm.

Правила

Так

Шаги разделяет сам компонент — пунктир над каждым шагом, кроме первого.

Не так

Свой разделитель между шагами — линия встаёт второй рядом с пунктиром компонента.

Так

Подпись шага — короткое существительное: колонка подписей узкая, поля широкие.

Не так

Подпись-предложение упирается в треть формы и переносится, поля сжимаются.

Анатомия

Форма — грид из двух колонок; шаг — подсетка формы, поэтому колонка подписи общая у всех шагов.

  1. Форма (.stepform) — колонка подписи (по самой длинной подписи, не шире трети) и колонка контролов; зазор колонок 16, шагов — 12. Контейнер для запроса ширины stepform.
  2. Шаг (.stepform__step, атрибут data-state) — пунктир сверху с отступом 12 (у первого шага нет), строки шага через 8.
  3. Подпись (.stepform__label) — StepMarker M + название .stepform__title (Body S Strong) + скрытый статус .stepform__status; строка высотой 40 — по полю M.
  4. Контролы (.stepform__control) — колонка, зазор 8: поле InputText M, ряд чипов, подсказки.
  5. Блок на всю ширину (.stepform__wide) — опц., класс на самом блоке: Tile Inset с историей, сводка выбора.
  6. Подвал (.stepform__foot) — опц. заметка Note S под пунктиром.

Варианты

Оси конфигурации компонента — каждая описана отдельным подразделом.

Состав шага

Контролы шага — любые поля ДС размера M: поле поиска, ряд чипов выбора, поле и чипы вместе. Поле без своей метки подписано названием шага (aria-labelledby).

Блок на всю ширину шага

Под подписью и контролами — блок на обе колонки: Tile Inset со списком, сводка. Класс .stepform__wide ставится на сам блок: пока блок скрыт (hidden), пустой строки нет.

Подвал

Заметка Note S под пунктиром — срок, условие, что будет дальше. Подвал один, после всех шагов.

Появление — опция

Модификатор .stepform--appear переносит анимацию прототипа: форма в панели, которую открыли, проявляется со сдвигом, шаги и подвал — лесенкой. По умолчанию выключено — форма на странице появляется сразу. Тайминги — раздел «Поведение».

Контент

  • название шага — существительное или короткая фраза: «Объект анализа», «Дополнительный фокус»; без двоеточия и точки;
  • шаги нумеруются по порядку с 1, номер ставит StepMarker;
  • контролы — только компоненты ДС размера M; плейсхолдер поля подсказывает, что вводить;
  • подвал — одна заметка Note: срок, условие, что будет дальше.

Поведение

Своего рантайма нет: состояние шага выставляет экран атрибутом data-state, раскладку и анимацию делает CSS.

Узкая форма

Форма уже 840px — подпись встаёт над контролами. Порог считается по ширине самой формы (container query, контейнер stepform), а не окна: форма сжимается и в узкой панели, и когда рядом открыта боковая панель. 840 — нижняя граница класса Expanded Material 3; в поле промпта шириной 880 форма — 846px, две колонки.

Шаг готов

Экран меняет data-state шага по данным (выбор, ввод) — маркер внутри шага красится сам: номер гаснет, галочка появляется с поворотом (StepMarker). Скрытый статус «выполнено» становится доступен скринридеру. Демо — раздел «Использование».

Появление панели — опция .stepform--appear

Значения из прототипа. Пока панель закрыта (inert на ней или на предке), форма прозрачна и сдвинута на 16 вверх. Панель открыли — форма проявляется (0,25 с) и встаёт на место (0,55 с) с задержкой 0,06 с, шаги и подвал — лесенкой: 145 / 200 / 255 мс, сдвиг 10 → 0 за 0,6 с; кривая cubic-bezier(.22, 1, .36, 1). Блок на всю ширину шага появляется так же (0,4 с), когда его показывают. При prefers-reduced-motion — без анимации.

Состояния

Состояние шага — атрибут data-state на .stepform__step. Маркер красится сам; у недоступного шага название тоном неактивного текста, контролы выключает экран (disabled).

Доступность

  • Форма — role="group" с aria-label; шаг — section с aria-labelledby на подпись: скринридер читает «Объект анализа, выполнено».
  • Статус шага — скрытый текст .stepform__status--done / --error: компонент открывает его скринридеру только в своём состоянии. Маркер — aria-hidden.
  • Контролы шага подписаны названием шага: aria-labelledby на .stepform__title — у поля без своей метки и у группы чипов (radiogroup / group).
  • Порядок Tab — по шагам сверху вниз, внутри шага — по контролам.

Бэклог

Кейсы, которых недостаёт компоненту.

  • Поля S — строка подписи 32 под поля S для плотных панелей. Сейчас в StepForm только поля M.
  • Сворачиваемые шаги — готовый шаг сворачивается в строку со сводкой выбора, текущий раскрыт (вертикальный мастер).
  • Stepper — навигация мастера по экранам на тех же StepMarker; отдельный компонент.
