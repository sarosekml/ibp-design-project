> Спека для быстрого контекста. Источник истины — CSS-файл и страница компонента. При изменении компонента обновляй эту спеку и блок в specs/_cheatsheet.md.

## Назначение
Документ как вложение: плашка с иконкой, название (открывает просмотр), параметры документа и до двух действий — «Просмотр» и «Скачать ▾» с меню форматов. Стоит в нити чата, в ленте активности, под сообщением. Перенесена из нити AI Pitcher (прототип ai-bankster v02, задача MS0011): карточка готового материала и документа коллеги. Решение человека 06.10.2026: отдельная молекула, а не Tile Card + Entity — композиция не держала вид прототипа (радиус, поля, наведение, мета).

## Инварианты
- Кликабельны только название (`button.doccard__title`) и кнопки действий: сама карточка не кнопка и не ссылка — вложенного интерактива нет. Наведение на карточку только подсвечивает рамку и поднимает её тенью; фона и «нажатия» у карточки нет.
- Название — одна строка с многоточием и тултипом полного текста (`data-tooltip` + `data-tooltip-truncated="only"`, Tooltip).
- Параметры (`.doccard__meta`) — одна строка: тип · версия · дата или автор · дата · объём.
- Действия — до двух кнопок Buttons Outline S; меню форматов — ContextMenu (`[data-menu]`). Третье действие — в меню, не кнопкой.
- Один размер — других не будет (решение человека 06.10.2026). Ширина — по контейнеру; карточка не растягивается по высоте ряда.
- Действие под карточкой («Добавить в контекст») — раскладка экрана рядом с карточкой (Button Transparent S с `aria-pressed`), не часть карточки.

## Ключевые правила (из разделов страницы)
- **Использование** — готовый документ в потоке: материал агента в нити, документ коллеги, вложение в ленте. Не для списка документов (там Entity в списке) и не для файла, который прикладывают к сообщению (там Chip с крестиком).
- **Анатомия** — карточка → плашка иконки `.doccard__icon` · текст `.doccard__main` (название `.doccard__title` + параметры `.doccard__meta`) · действия `.doccard__actions`.
- **Варианты** — действия: два · одно · нет; иконка документа — по типу (`document-check` — готовый материал).
- **Размеры** — один размер (других не будет, решение 06.10.2026): поля 12, радиус `--radius-xl` (12), плашка 40 (радиус 8, глиф 22), зазоры 12 / 2 / 8.
- **Контент** — название документа, как его назвал автор или агент; параметры — тип · версия · дата.
- **Поведение** — усечение названия + тултип; наведение — рамка и тень (0,15 / 0,2 с); меню «Скачать» — ContextMenu.
- **Состояния** — карточка: Default · Hover (рамка `--border-primary` + `--shadow-card-hover`); название: Hover (`--primary-dark` + подчёркивание) · Focus (обводка 2px `--primary`). Витрина — `.is-hover`, `.is-focus`.
- **Доступность** — название — `<button>` (открывает просмотр), порядок Tab: название → «Просмотр» → «Скачать»; иконка `aria-hidden`; кнопка меню — `aria-haspopup="menu"` + `aria-expanded`.
- **Типографика** — название `--type-body-m-strong`, параметры `--type-body-xs`.
- **Цвета** — фон `--bg-tile`, рамка `--border-light` / наведение `--border-primary`, тень `--shadow-card-hover`, плашка `--primary-bg` + глиф `--primary`, название `--text-primary` / наведение `--primary-dark`, параметры `--text-secondary`.

## Для разработчиков (выжимка)

### Точные размеры (redline)
Таблица рендерится на странице через getComputedStyle. Точные значения — в CSS-файле компонента (см. `css:` в шапке).

### Разметка · HTML (эталонная реализация ДС)

```
<div class="doccard">
  <span class="doccard__icon" aria-hidden="true"><i data-icon="document-check"></i></span>
  <div class="doccard__main">
    <button type="button" class="doccard__title" data-tooltip="ПАО «Волга-Агро» — материал с идеями" data-tooltip-truncated="only">ПАО «Волга-Агро» — материал с идеями</button>
    <span class="doccard__meta">Детальный · версия 2 · 05.10.2026</span>
  </div>
  <div class="doccard__actions">
    <button type="button" class="btn btn--outline btn--s"><i data-icon="visibility-on"></i><span class="btn__label">Просмотр</span></button>
    <button type="button" class="btn btn--outline btn--s" aria-haspopup="menu" aria-expanded="false" data-menu="doc-menu"><i data-icon="download"></i><span class="btn__label">Скачать</span><i data-icon="chevron-down"></i></button>
  </div>
</div>
```

### Справочник классов и атрибутов

| Класс/атрибут | Назначение |
|---|---|
| `.doccard` | корень — карточка: рамка, радиус 12, поля 12; наведение — рамка и тень |
| `.doccard__icon` | плашка 40 с иконкой документа, `aria-hidden` |
| `.doccard__main` | колонка: название + параметры, зазор 2 |
| `button.doccard__title` | название — кнопка, открывает просмотр; одна строка, тултип при усечении |
| `.doccard__meta` | параметры документа, одна строка |
| `.doccard__actions` | до двух кнопок Outline S, зазор 8 |
| `.is-hover` | витрина: наведение на карточку / название |
| `.is-focus` | витрина: фокус названия |
