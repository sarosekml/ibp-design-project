DocCard

Карточка документа — документ как вложение в потоке: плашка с иконкой, название (открывает просмотр), параметры и до двух действий — «Просмотр» и «Скачать ▾». Кликабельны только название и кнопки; сама карточка при наведении подсвечивает рамку и поднимается тенью.

Использование

Готовый документ в нити чата: материал, собранный агентом, или документ коллеги. Под карточкой экран может поставить своё действие — например, переключатель «Добавить в контекст».

Нить чата — материал агента и документ коллеги

Когда использовать

  • документ появился в потоке — его можно открыть и скачать, не уходя со страницы;
  • у документа есть параметры, по которым его узнают: тип, версия, дата или автор.

Не используйте для списка документов — строки списка собираются из Entity в .entity-list. Файл, который прикладывают к сообщению, — Chip с крестиком. Карточка целиком не кликается: если документ открывается по клику на любое место — это Tile Card без кнопок внутри.

Правила

Так

Не больше двух действий кнопками; форматы выгрузки — в меню «Скачать».

Не так

Третья кнопка теснит название — уберите действие в меню.

Так

Просмотр открывает название-кнопка: она в порядке Tab и видна на наведении.

Не так

Вся карточка-ссылка с кнопками внутри — вложенный интерактив: клик по кнопке открывает и документ.

Анатомия

Карточка в один ряд: плашка, текст, действия. Текст сжимается, плашка и действия — нет.

  1. Карточка (.doccard) — фон --bg-tile, рамка 1px --border-light, радиус --radius-xl, поля 12; наведение — рамка --border-primary и тень --shadow-card-hover.
  2. Плашка иконки (.doccard__icon) — 40, радиус --radius-m, фон --primary-bg, глиф 22 --primary; декоративная.
  3. Название (button.doccard__title) — Body M Strong, одна строка с многоточием и тултипом; открывает просмотр.
  4. Параметры (.doccard__meta) — Body XS --text-secondary, одна строка.
  5. Действия (.doccard__actions) — до двух кнопок Buttons Outline S; меню форматов — ContextMenu.

Варианты

Оси конфигурации компонента — каждая описана отдельным подразделом.

Действия

Два действия — «Просмотр» и «Скачать ▾» с меню форматов; одно — только «Просмотр»; без действий — документ открывается названием.

Размеры

Один размер — других не будет (решение 06.10.2026). Ширина — по контейнеру (колонка нити, лента); высота — по содержимому, 66px с кнопками S.

Контент

  • название — как документ назвал автор или агент: объект и тип материала («ПАО «Волга-Агро» — материал с идеями»);
  • параметры — то, по чему документ узнают: тип · версия · дата у своего материала, автор · дата · объём у документа коллеги; разделитель « · »;
  • иконка — по типу документа: document-check — готовый материал.

Длинное название

Название и параметры — в одну строку с многоточием; полное название — в тултипе при наведении и фокусе (Tooltip, data-tooltip-truncated="only" — тултип только у усечённого).

Поведение

  • Наведение на карточку — рамка --border-primary (0,15 с) и тень --shadow-card-hover (0,2 с): подсказка, что внутри есть действия. Фон не меняется, «нажатия» нет — карточка не кнопка.
  • Название — кнопка: клик открывает просмотр документа (обработчик экрана); наведение — тон Primary Dark и подчёркивание.
  • «Скачать ▾» открывает меню форматов — ContextMenu (data-menu, рантайм сам ставит aria-expanded).
  • При prefers-reduced-motion — без переходов.

Состояния

У карточки — Default и Hover; у названия — Hover и Focus. Кнопки действий — по правилам Buttons. Витрина состояний — классы .is-hover (карточка, название) и .is-focus (название).

Доступность

  • Название — <button>: доступно с клавиатуры, имя — полный текст названия (усечение только визуальное).
  • Порядок Tab: название → «Просмотр» → «Скачать»; карточка сама в порядок Tab не попадает.
  • Плашка иконки — aria-hidden.
  • Кнопка меню — aria-haspopup="menu" и aria-expanded (ставит рантайм ContextMenu).
  • Фокус названия — обводка 2px --primary со смещением 2px.

  • Тип документа — иконка и тон плашки по типу файла (PDF, Word, Excel).
