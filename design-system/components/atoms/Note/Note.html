Note

Заметка — нейтральное пояснение «иконка + вторичный текст» в потоке: под формой, в модальном окне, в тайле. Без заливки, рамки и полей — встаёт между блоками как строка текста. Это не статус (статус — Alert) и не подпись поля (подпись — LabelHelper).

Использование

Заметка поясняет блок целиком: срок, условие, что произойдёт дальше. Стоит под формой или группой полей, в теле модального окна, в подвале пошаговой формы.

Под формой — S, акцент

В модальном окне — XS, нейтральная

Когда использовать

  • пояснить срок или условие для всего блока: «Подготовка отчёта обычно занимает до 30 минут»;
  • сказать, что будет после действия, не отвлекая от формы.

Не используйте заметку для статуса — ошибка, предупреждение, успех показываются Alert. Пояснение к одному полю — хелпер поля (LabelHelper). Кнопок в заметке нет — действие выносится в кнопку рядом с блоком.

Правила

Так

Заметка поясняет: срок, условие, что будет дальше.

Не так

Ошибка в нейтральной заметке теряется — статус показывает Alert.

Так

Одна мысль, одна-две строки, без кнопок.

Не так

Кнопка в заметке — не её работа: действие — отдельной кнопкой у блока.

Анатомия

Иконка и текст в одну строку. Фона, рамки и полей нет — линию над заметкой, если она нужна, рисует контейнер.

  1. Иконка (.note__icon) — декоративная, aria-hidden. Коробка иконки высотой в строку текста: глиф стоит по центру первой строки.
  2. Текст (.note__text) — --text-secondary, переносится по словам; внутри допустима ссылка Link (.link--inline).

Варианты

Оси конфигурации компонента — каждая описана отдельным подразделом.

Тон иконки

По умолчанию иконка красится --secondary — штатным цветом иконки ДС. Модификатор .note--accent красит её --primary: заметка в подвале формы, на которую стоит обратить внимание. Текст в обоих тонах — --text-secondary.

Текст со ссылкой

Ссылка внутри текста — .link--inline тона Accent: ведёт к подробностям. Других интерактивных элементов в заметке нет.

Размеры

Три размера — по кеглю текста. S — по умолчанию: подвал формы рядом с полями M; XS — плотные блоки и модальные окна; M — пояснение в тексте Body M.

Контент

  • законченное предложение с точкой, одна мысль, одна-две строки;
  • без восклицаний и без призыва к действию — действие у блока делает кнопка;
  • иконка поясняет тему: срок — clock-timer, справка — info-circle, прошлые запросы — history; иконки статуса (ошибка, предупреждение) в заметку не ставятся.

Поведение

Статична. Длинный текст переносится по словам, иконка остаётся у первой строки.

Перенос длинного текста

Ширина — по контейнеру. Коробка иконки высотой в строку (1lh) держит глиф по центру первой строки при любом числе строк.

Состояния

Не применимо: заметка не интерактивна — не фокусируется и не реагирует на наведение. Состояния есть только у ссылки внутри текста — по правилам Link.

Доступность

Заметка — обычный абзац <p>: скринридер читает текст по порядку на странице. Иконка декоративная (aria-hidden="true") — смысл несёт текст. Ссылка внутри — в порядке Tab, по правилам Link. Ролей status и alert у заметки нет: она не сообщает об изменениях.

Бэклог

Кейсы, которых недостаёт компоненту.

  • Заметка без иконки — сейчас иконка обязательна; строка вторичного текста без иконки собирается обычным абзацем Typography. Вариант без иконки — если появится потребитель.
  • Сворачиваемая заметка («Подробнее» с раскрытием) — для длинных пояснений; сейчас длинный текст выносится в справку по ссылке.
