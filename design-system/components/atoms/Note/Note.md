> Спека для быстрого контекста. Источник истины — CSS-файл и страница компонента. При изменении компонента обновляй эту спеку и блок в specs/_cheatsheet.md.

## Назначение
Нейтральное пояснение «иконка + вторичный текст» в потоке: под формой, в модальном окне, в тайле — «Подготовка отчёта обычно занимает до 30 минут». Без заливки, рамки и полей. Подвал StepForm собирается из Note. Перенесена из подвала конструктора запроса AI Pitcher (прототип ai-bankster v02, задача MS0010e).

## Инварианты
- Не статус: ошибка, предупреждение, успех — это Alert (тоновая плашка). У Note тонов статуса нет.
- Не подпись поля: пояснение под конкретным полем — LabelHelper (`.ds-helper`) внутри поля.
- Не интерактивна: внутри допустима только ссылка Link (`.link--inline`), кнопок нет.
- Фона, рамки и полей нет — Note встаёт в поток; линию над ней рисует контейнер (в StepForm — пунктир подвала).
- Иконка декоративная (`aria-hidden`) и стоит по центру первой строки; длинный текст переносится, иконка остаётся у первой строки.
- Цвет иконки по умолчанию — `--secondary` (правило ДС); акцент — модификатор `.note--accent`.

## Ключевые правила (из разделов страницы)
- **Использование** — пояснение к блоку: срок, условие, что будет дальше. Одна-две строки.
- **Анатомия** — иконка `.note__icon` (коробка высотой в строку) + текст `.note__text`.
- **Варианты** — тон иконки: нейтральный (`--secondary`) · акцент (`.note--accent`, `--primary`); текст со ссылкой Link inline.
- **Размеры** — XS (Body XS, иконка 16, зазор 4) · S, по умолчанию (Body S, иконка 18, зазор 8) · M (Body M, иконка 20, зазор 8).
- **Контент** — законченное предложение с точкой, одна мысль, одна-две строки; без восклицаний и без призыва к действию.
- **Поведение** — длинный текст переносится, иконка у первой строки; статична.
- **Состояния** — Не применимо: не интерактивна.
- **Доступность** — обычный текст `<p>`, иконка `aria-hidden`; ссылка внутри — по правилам Link.
- **Типографика** — `--type-body-xs` / `--type-body-s` / `--type-body-m` по размеру.
- **Цвета** — текст `--text-secondary`, иконка `--secondary` или `--primary` (акцент).

## Для разработчиков (выжимка)

### Точные размеры (redline)
Таблица рендерится на странице через getComputedStyle. Точные значения — в CSS-файле компонента (см. `css:` в шапке).

### Разметка · HTML (эталонная реализация ДС)

```
<p class="note note--s">
  <span class="note__icon" aria-hidden="true"><i data-icon="clock-timer"></i></span>
  <span class="note__text">Подготовка отчета обычно занимает до 30 минут. Работа продолжится, даже если закрыть инструмент.</span>
</p>

<!-- акцент: иконка --primary -->
<p class="note note--s note--accent">…</p>
```

### Справочник классов и атрибутов

| Класс/атрибут | Назначение |
|---|---|
| `p.note` | корень — заметка |
| `.note--xs` / `--s` / `--m` | размер: Body XS / Body S / Body M |
| `.note--accent` | иконка тоном Primary |
| `.note__icon` | слот иконки, `aria-hidden="true"`, внутри `<i data-icon>` |
| `.note__text` | текст пояснения |
