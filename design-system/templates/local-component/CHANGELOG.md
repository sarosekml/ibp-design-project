# <Имя> — журнал изменений

Формат записи: что изменилось · почему · по какому требованию. Без «почему» правку через
месяц откатывают обратно. Новая запись — сверху.

Правка вида, поведения или состава — новая версия: `## М.ммм — ДД.ММ.ГГГГ`. Правка только
описания версию не меняет — запись без номера: `## Паспорт — ДД.ММ.ГГГГ`. Приведение к
новым правилам ДС — тоже отдельная запись с новой `rulesVersion`.

## 1.000 — ДД.ММ.ГГГГ

**Компонент создан.** *Почему:* … *Требование:* …
