# IBP DS — дизайн-система

Дизайн-система продукта **IBP (Investment Banking Platform)** — визуальный язык интерфейса: токены (цвета, типографика, скругления, тени), шрифты SB Sans, иконки, иллюстрации и документация компонентов.

## Контекст
IBP — внутренняя платформа инвестиционного банкинга. Интерфейс — плотный, деловой, на русском; акцентный цвет — изумрудно-зелёный. 

## Формат: ванильный HTML/CSS
Эта ДС — **чистый HTML + CSS**, без React и без шага сборки. Источник истины: CSS основ и компонентов (токены и классы) и HTML-страницы документации. Компонент — папка со всеми своими файлами: `components/<категория>/<Имя>/` (`<Имя>.css`, `<Имя>.js`, `<Имя>.html`, `<Имя>.page.js`, спека `<Имя>.md`); файлы компонента печатает `node tools/ds-paths.mjs <Имя>`. Страницы открываются двойным кликом (`file://`). Экран подключает ДС двумя тегами: `ds.css` (все стили) и `ds.js` (все рантаймы). Маркер `<!-- @dsCard … -->` первой строкой страницы проверяет линтер (правило C1).

## Структура
```
ds.css                   ← единственная точка подключения стилей (@import CSS основ и компонентов)
ds.js                    ← единственная точка подключения рантаймов
index.html               ← обзор ДС (карточки компонентов)
CHANGELOG.md             ← журнал правок; большой — дописывать в секцию даты, целиком не читать
MAINTAINING.md           ← правила ведения ДС: контракт страницы, чек-листы, проверки
components/              ← atoms/, molecules/, organisms/: папка на компонент; поля с общей базой — molecules/Inputs/
foundations/             ← основы той же формы; токены — Colors, Typography, Spacing, Radius, Elevation
patterns/ · rnd/         ← паттерны и рабочие материалы той же формы
utils/                   ← общие рантаймы без своего компонента
docs-kit/                ← оболочка страниц документации (навигация, docs-split)
tools/                   ← линтер ds-lint.js и разбор его правил ds-lint.md, гейт ds-check.mjs, модуль путей ds-paths.mjs
specs/                   ← только общее: _index.md (манифест), _cheatsheet.md (чит-шит), _runtime-hooks.md, _TEMPLATE.md
templates/               ← screen/Screen.html — стартовый шаблон экрана; local-component/ — заготовка локального компонента
fixtures/                ← корпус фикстур линтера (пары «эталон / дефект»)
assets/                  ← logo.svg · illustrations/ · fonts/ (SB Sans, .otf)
```

## Компоненты
Актуальный состав и версии — `specs/_index.md`; полноту `index.html` и навигации против страниц компонентов сверяет линтер (правила D1–D4). Перечень здесь намеренно не дублируется: копия расходится с диском.

## Иконки и иллюстрации
- Иконки — глиф-сет в `foundations/Icons/icons-data.js` (большой, в одну строку — не читать), вставляются как `<i data-icon="имя"></i>` через `foundations/Icons/Icons.js` (SVG в `currentColor`). Имена глифов — `foundations/Icons/Icons.md`, поиск — `node tools/ds-icon.mjs --list <подстрока>`.
- Иллюстрации — SVG продукта в `assets/illustrations/`.

## Как пользоваться
- Правила ведения, чек-листы (новый компонент / правка / экран) и команды проверки — `MAINTAINING.md`.
- Компонент для экрана — блок в `specs/_cheatsheet.md` (точечно, по заголовку), при сложном поведении — полная спека.
- Новый экран — копия `templates/screen/Screen.html` + компоненты из спек.
