### Л_. `<style>` страницы не держит правила без потребителя
- **Дата/зона:** 04.10.2026 | design-system/foundations/Themes/Themes.html (задача RE0006)
- **Симптом:** в `<style>` страницы «Темы» оставалось правило `.theme-demo__readout { … }`, которого нет ни в разметке, ни в скриптах страницы; линтер молчал.
- **Причина:** `ds-lint` ловит класс разметки без CSS (P5), но обратного правила — CSS без потребителя — нет; осиротевшее правило никого не краснит.
- **Правило:** `<style>` страницы не держит правил без потребителя: каждый селектор из локального `<style>` встречается в статической разметке или в строках `*.page.js`/скриптов страницы.
- **Закрепление:** неизмеримое — сторож-правило линтера пока не написано (кандидат: класс из локального `<style>` без потребителя в разметке и скриптах).
- **Промоут:** не промоутить — кандидат в исполняемое правило линтера
