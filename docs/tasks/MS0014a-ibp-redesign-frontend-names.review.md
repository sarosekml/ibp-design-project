- Закрывающий `node .agents/tools/lessons-cli.mjs gate` после обновления документов и витрины: **ВЕРДИКТ: OK (21 шаг.)**. Он сохраняет два известных красных шага полного прогона как долг, а не объявляет их исправленными. `git diff --check` чистый; неразрешённых конфликтов Git нет.
- Opportunity.preview.html: K4 «Клиент», строка 93 — 8 полей на 4 колонках; «Общая информация», строка 138 — 6 полей на 4 колонках. Ширины 4+4+4 взяты из MS0014 §4.3; MS0014a предписывает сохранить это отклонение. Оно явно записано в спеке Opportunity.

- Остальные 17 страниц проходят сенсор без блокеров. Ширины клиентских рядов заданы в HTML, панели Splitter и скрытые шаблоны имеют объяснение `data-off-grid`; это реальные места с внешним управлением шириной.

## Данные и ссылки

Проверены реальные data/*.js и store.js в Node: **12 клиентов, 225 сделок, 85 лидов, 21 встреча, 20 задач**. У всех сущностей уникальные ID; ссылки задач, встреч, продуктов, лидов и клиентов разрешаются в правильный тип объекта. Ранее заявленные 105 лидов не подтверждаются текущим набором — фактически их 85.

Обнаружена и исправлена коллизия ID 166103 между основной сделкой и генерируемой записью. Генератор резервирует ID основных объектов; store проверяет уникальность исходных и сохранённых массивов. Сделка 166104 дополнительно открыта в браузере с совпадающим ID и заголовком.

Имена страниц, подкомпонентов, ссылки и шаги панели согласованы с текущими спеками. Для пар, которых нет в дереве фронтенда, это явно указано; неоднозначные соответствия В1–В6 остаются допущениями.

## Ограничения и принятые допущения

- Проверка живого прототипа по `file://` недоступна: политика инструмента браузера разрешает HTTP/HTTPS и отклонила переход. Относительные подключения и сборка проверены статически, поведение проверено по HTTP. Работа двойным кликом отдельно не подтверждена.
- В1–В6 не получили ответов человека. Используются ранее записанные рекомендации агента; PASS реализации не означает согласования этих имён человеком.
- «Фильтр» кредитов виден и не действует по Р6: формы в источнике нет. Переключение «Карточки / Список» через раскрытие/сворачивание — записанное в спеке допущение.
- Непросмотренные строки и другие отсутствующие варианты ДС остаются названными пробелами в спеках; собственные стили вместо них не добавлены. Неактивные вкладки и ссылки сохранены по Р3/Р5/Р6.
- Автоматические снимки не делались. Композиция проверена по структуре, сенсору, исходным изображениям и измерениям DOM доступных сценариев; отдельной полной визуальной сверки скриншотов каждого состояния нет.
