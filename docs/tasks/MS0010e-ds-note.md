# Note: заметка с иконкой

## Коротко

- **Откуда.** Низ конструктора в `RequestThread.html` v02 (`.bld__foot`,
  строки ~433–435): иконка `clock-timer` в `--primary` и текст
  «Подготовка отчета обычно занимает до 30 минут. Работа продолжится, даже
  если закрыть инструмент.» — `body-s`, `--text-secondary`, сверху
  пунктирная линия.
- **Чего нет в ДС.** Alert — плашка с заливкой тона, это статус, а не
  справка. LabelHelper (`.ds-helper`) живёт только внутри поля. Нейтральной
  строки «иконка + пояснение» вне поля нет.
- **Задача.** Новый атом **Note** — `components/atoms/Note/`, версия `1.000`.
  Используется в StepForm (MS0010h) как подвал; подходит для пояснений под
  формами, в модалках, в тайлах.
- **Часть группы MS0010.** Альтернатива — не заводить компонент, а сделать
  подвал частью StepForm (вопрос 4.1). Правка ДС — после согласования.

## Objective

В ДС есть атом Note: нейтральное пояснение с иконкой, без заливки и рамки.
Подвал конструктора v02 собирается из него.

## 1. Решение

### 1.1. Разметка

```html
<p class="note note--s">
  <span class="note__icon" aria-hidden="true"><i data-icon="clock-timer"></i></span>
  <span class="note__text">Подготовка отчета обычно занимает до 30 минут. Работа продолжится, даже если закрыть инструмент.</span>
</p>
```

### 1.2. Визуал

| Свойство | S (по умолчанию) | XS |
|---|---|---|
| текст | `--type-body-s`, `--text-secondary` | `--type-body-xs`, `--text-secondary` |
| иконка | 18, цвет — §1.3 | 16 |
| зазор | `--space-8` | `--space-4` |
| выравнивание | иконка по первой строке (`align-items: flex-start`, отступ под высоту строки) | то же |

- Фона, рамки, паддинга нет — Note встаёт в поток. Линия над ним — забота
  контейнера (в StepForm — Divider dashed).
- Длинный текст переносится, иконка остаётся у первой строки.

### 1.3. Цвет иконки

Правило ДС: иконка по умолчанию — `var(--secondary)`. В прототипе —
`--primary`. Варианты: тон `.note--accent` (иконка `--primary`) и база с
`--secondary` — вопрос 4.2.

### 1.4. Чем Note не является

- Не статус: ошибка, предупреждение, успех — это Alert.
- Не подпись поля: под полем — LabelHelper.
- Не интерактивна: ссылка внутри текста допустима (Link inline), кнопки — нет.

## 4. Вопросы к человеку

1. **Отдельный атом или часть StepForm?** Рекомендую атом: подобные
   пояснения «иконка + текст» нужны и под формами в модалках; если
   других потребителей не видно — сделать подвалом StepForm
   (`.stepform__foot`) и закрыть эту задачу без компонента.
2. **Цвет иконки** — `--secondary` по умолчанию + тон `--accent`
   (рекомендую, правило ДС) или сразу `--primary`?
3. **Имя** — `Note` (`.note`) или `Hint`?
