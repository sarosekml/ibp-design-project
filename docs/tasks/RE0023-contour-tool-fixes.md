# Перенос правок и дефектов оснастки из контура (RE0023)

## Коротко

- **Что не так.** Контрольный заход RE0022 в рабочем контуре нашёл дефекты оснастки; часть из них
  агент контура обошёл или поправил **в своей копии**, но копия в репозиторий не приходит — наружу
  ушёл только md-файл отчёта. Здесь репозиторий ничего из этого не знает.
- **Что должно получиться.** Каждый пункт О9/О10 отчёта
  (`docs/tasks/RE0022-contour-run.md`) — либо починен в репозитории с проверкой, либо отклонён
  решением человека с записью почему.
- **Для кого.** Агенты в обоих контурах: гейт без вечных `FAIL`, `task-cost` с числами по
  журналам CLI контура.

## Решение

Порядок — от дешёвого и однозначного к требующему решения человека. Каждый этап — правка,
отрицательный контроль (проверка краснеет без правки) и гейт.

**Без решения человека — однозначные дефекты:**

- **Э1 · лимит шага гейта.** Поднять предел шага (значение — по замеру 308,9 с, с запасом) или
  разбить корпус `verify --corpus lint`. Протокол для контура писать «поднять значение», не
  `perl`-строкой: там `perl -pi -e` отклонён политикой шелла.
- **Э2 · NFC.** Имена с диска и из каталога сравнивать в одной нормализации
  (`normalize('NFC')`) в `module-readme.mjs` и `docs-index.mjs`; генерат писать в NFC. Проверка —
  фикстура с NFD-именем.
- **Э3 · Б13 членством в списке классов** (`(^|\s)tbl(\s|$)` / разбор `class`), фикстуры
  `Б13@substring…bad.html` и эталон без дефекта; урок **Л233** в
  `.agents/skills/screen-review/references/lessons-raw.md` (номер свободен — последний Л232) и
  выжимка — по скиллу `lessons`. Суть урока — RE0022, О9.
- **Э4 · `task-cost.mjs`:**
  - узнавать форму журналов CLI контура (`message.parts[].functionCall`, `functionResponse`,
    `usageMetadata.promptTokenCount/candidatesTokenCount/cachedContentTokenCount`,
    `role: "model"`) — фикстура по именам полей из О7 (значений в отчёте нет — фикстура
    придумывается по форме);
  - «Время» по сессиям — объединение интервалов (не сумма); урок **Л234** с самотестом на
    двух перекрывающихся сессиях;
  - метки блока «Затраты» — только строкой целиком и ровно одна пара, иначе отказ без записи;
  - журналы субагентов: `--all-sessions` по умолчанию у `mark` или предупреждение, если в окне
    есть журнал субагента — выбрать при правке, записать в «Решения агента»;
  - три разных текста отказа вместо одного «журналов не найдено».
- **Э5 · `assemble.mjs`:** неизвестный аргумент — ошибка с кодом 2, `--help` — текст использования.

**Только с решения человека** (правило «новые сторожа — с согласия»), каждый пункт отдельно:

- **Э6 · вопросы ниже** — разобрать с человеком; принятое — этапами Э7+. Разобрано 15.10.2026,
  решения — в таблице выше.
- **Э7 · долг гейта.** `lessons-cli.mjs`, блок «Упавшее в прошлый раз»: красные пофайловые шаги не
  переносить в долг без запуска, а перезапускать на каждом гейте. Отрицательный контроль — фрагмент,
  красный до вшивки, после вшивки уходит из долга без `gate --full`.
- **Э8 · фрагменты `widgets/`.** `layout-check.mjs` (пропуск фрагмента сейчас — только при
  `includersOf`) и линтер: файл в `widgets/` — фрагмент и без вшивки; экранные правила
  (Б1, Б5, Б6, A2, A4, A7) к нему не применяются, пропуск печатается строкой. Фикстура — невшитый
  виджет без каркаса.
- **Э9 · «правило обязано молчать».** Абзац в README корпуса фикстур: ловушка оформляется парой
  `<ID>@<вариант>.bad.html` + `_<вариант>.ok.html` (`verifyCorpus` уже требует молчания на эталоне
  варианта). Б13 «подстрока» переносится так (в Э3).
- **Э10 · `assemble.mjs` и `Б12`.** При сборке `X.preview.html` — предупреждение, если спека
  `X.screen.md` не объявляет его строкой `file:`; спеку инструмент не правит. Вместе с Э5.
- **Э11 · сторожа «сторож промолчал»** — каждый отдельным шагом: правка, фикстура `.bad.html` и
  эталон, `verify --only <ID>`; новые номера правил — по свободным.
  - (а) `Б4` в обратную сторону: селекторы, которые читает `<Имя>.js` виджета, есть в его разметке;
  - (б) `page-run` без сценария — не зелёный, а «проверена только загрузка, сценария нет»;
  - (г) относительная ссылка `href` на файл проекта внутри экрана ведёт на существующий файл;
  - (д) `Б18`: блок в тайле рядом с `.tile__grid` со своими отступами — тоже находка.
- **Э12 · урок (в)** «запрет — разметкой, не стилем»: контрол, запрещённый состоянием, получает
  `disabled` / теряет `href`, а не прячется CSS-классом. По скиллу `lessons`, следующий свободный Л.

## Критерии приёмки

- Свежая распаковка архива на машине с NFD-ФС: `МР3`/`КД3` нет (проверка фикстурой).

- Красный до вшивки фрагмент после вшивки уходит из `ДОЛГ` обычным гейтом, без `--full` (Э7).
- Невшитый файл `widgets/` не даёт находок Б1/Б5/Б6/A2/A4/A7, пропуск напечатан строкой (Э8).
- `assemble.mjs` на странице без `file: X.preview.html` в спеке печатает предупреждение (Э10).

- `node .agents/tools/task-cost.mjs --selftest`, `node .agents/tools/lessons-cli.mjs gate` —
  `ВЕРДИКТ: OK`.
