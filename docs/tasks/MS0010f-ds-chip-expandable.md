# Chip: раскрывающийся чип

## Коротко

- **Откуда.** Композер `RequestThread.html` v02: фрагмент материала («Доработать
  в чате») встаёт чипом над полем. Раньше текстовый фрагмент раскрывался
  отдельным блоком цитаты под чипами (`.cmp-quote`), а раскрытый чип
  подкрашивался рамкой (`.cmp-ctx[aria-expanded]`).
- **Решение человека 06.10.2026 (разбор MS0010c).** Отдельного блока нет —
  **раскрывается сам чип**: по клику растягивается на всю ширину строки и
  показывает весь текст фрагмента внутри; повторный клик — сворачивается.
  Стиль чипа не меняется (никакого «выбранного» цвета) — меняются размер и
  содержимое. Задача MS0010c (состояние «раскрыт») заменена этой; молекула
  Quote отложена на будущее — `MS0012-ds-quote.md`.
- **Версия Chip** `1.019` → `1.020`.

## Решения (06.10.2026)

1. **Стрелка.** В свёрнутом чипе — ˅ (подсказка, что чип раскрывается), в
   раскрытом — ˄: одна иконка `chevron-down`, поворот на 180° (как шеврон
   кнопки меню).
2. **Шапка раскрытого чипа** — источник «Фрагмент материала · <раздел>»
   вместо начала текста; весь текст — ниже.
3. **Анатомия:**
   ```
   span.chip.chip--edit.chip--s.chip--expandable
   ├─ button.chip__toggle  [aria-expanded, aria-controls]   шапка: иконка · подпись / источник · стрелка
   ├─ span.chip__remove   [role=button]                    крестик «убрать» — рядом со стрелкой
   └─ span.chip__body#…                                    весь текст (виден, когда раскрыт)
      └─ span.chip__text.ds-scroll                         до 8 строк, дальше — прокрутка
   ```
   Шапка — настоящая кнопка: внутри кнопки содержимое для скринридера
   сливается в одно имя, поэтому текст фрагмента лежит рядом с кнопкой, а не в
   ней. Стрелка — признак раскрытия (`.chip__expand`), а не список значений
   (`.chip__dropdown`): с крестиком сочетается.
4. **Раскрыт:** чип во всю ширину строки (исключение из `max-width: 320px` —
   только для раскрытого), текст с переносами, до 8 строк (как блок цитаты
   180px в прототипе), дальше прокрутка внутри; появление текста — анимация
   прототипа (`opacity` + сдвиг 4px, 0,25 с); `prefers-reduced-motion` — без
   анимации. Подложка наведения у раскрытого — только над шапкой.
5. **Поведение — рантайм `Chip.js`:** клик по шапке (Enter / Space — сама
   кнопка) раскрывает и сворачивает; в одном чиплисте раскрыт один чип;
   событие `ds-chip:toggle` (`detail.expanded`) на чипе; Backspace / Delete на
   шапке убирает чип, как у любого Edit-чипа с крестиком. API —
   `DSChip.expand(chip, open)`.
6. Чип графика не раскрывается — у него нет текста и стрелки.
