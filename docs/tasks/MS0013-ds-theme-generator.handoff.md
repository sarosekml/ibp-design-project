## Как повторить сверку Э6

```bash
git worktree add --detach <папка-main> origin/main
node .agents/tools/page-snapshot.mjs serve <папка-main> --out main.jsonl --port 8767 --once
node .agents/tools/page-snapshot.mjs serve . --out after.jsonl --port 8765 --once
```

Открыть `http://localhost:<порт>/__snapshot/` в одном и том же браузере для обоих деревьев (скрытая вкладка встроенного браузера тормозит таймеры — удобнее headless Chrome), затем:

```bash
node .agents/tools/page-snapshot.mjs compare main.jsonl after.jsonl --expect <файл ожидаемых>
```
