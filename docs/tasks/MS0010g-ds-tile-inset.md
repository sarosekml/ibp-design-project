# Tile Inset: вложенная подложка

## Коротко

- **Откуда.** Конструктор `RequestThread.html` v02, под выбранным объектом
  анализа — «История запросов по объекту анализа — 2» (`.bprior`, строки
  ~412–418, `drawPrior()` / `priorRow()` ~1661–1690). Скриншоты человека
  05.10.2026 (4 и 5): серая подложка внутри белой карточки, заголовок с
  иконкой `history`, пояснение «Документ откроется в чате, конструктор
  останется на месте…», список отчётов коллег — Entity S с аватаром-
  инициалами, подписью «автор · дата · объём» и кнопкой «Показать в чате»;
  строки разделены Divider.
- **Что уже ДС.** Строки — Entity S, Avatar, Buttons Outline XS, Divider,
  `.entity-list`. Локальна только **подложка** с шапкой:
  `background: var(--bg-page); border: 1px solid var(--border-light);
  border-radius: var(--radius-m); padding: var(--space-12)`, шапка
  `body-s-strong` + иконка 18 px `--primary`, пояснение `body-xs`.
- **Чего нет в ДС.** Tile — белая карточка верхнего уровня. Вложенной
  нейтральной подложки «внутри карточки» (поверхность на ступень ниже) нет;
  Alert — тоновая плашка статуса, не контейнер списка.
- **Задача.** Расширить Tile вариантом **Inset** (`.tile--inset`) —
  поверхность `--bg-page` для группы внутри карточки, модалки, панели.
  Версия Tile `1.015` → `1.016`.
- **Часть группы MS0010.** Правка ДС — после согласования вопросов §5.

## Objective

Вложенная группа с заголовком и списком собирается из Tile Inset + Entity;
блок истории запросов v02 — без локального CSS `.bprior*`.

## 1. Почему вариант Tile, а не новый компонент

- Анатомия совпадает с Tile: шапка (`tile__header`: иконка-подзаголовок,
  заголовок, подпись), тело (`tile__body`) со списком. У Tile уже есть
  варианты (обычный / Accordion / Headless / Card) — Inset ложится пятым по
  оси «поверхность».
- Новый компонент «Panel/Group» задвоил бы шапку, тело, Accordion и
  правила заголовка Tile.
- Вопрос 5.1 — если человек решит иначе.

## 2. Решение

### 2.1. Разметка

```html
<section class="tile tile--inset" aria-labelledby="priorTitle">
  <header class="tile__header">
    <div class="tile__header-main">
      <div class="tile__title-row">
        <span class="tile__title-icon" aria-hidden="true"><i data-icon="history"></i></span>
        <h3 class="tile__title" id="priorTitle">История запросов по объекту анализа — 2</h3>
      </div>
      <p class="tile__subtitle">Документ откроется в чате, конструктор останется на месте. Содержание запросов доступно только их авторам.</p>
    </div>
  </header>
  <div class="tile__body">
    <div class="entity-list">…Entity S…<hr class="dvd dvd--h">…</div>
  </div>
</section>
```

`.tile__title-icon` — проверить, есть ли ведущая иконка заголовка в Tile
1.015; если нет — добавляется этой задачей (вопрос 5.2).

### 2.2. Визуал Inset (токены)

| Свойство | Inset | Обычный Tile |
|---|---|---|
| фон | `--bg-page` | `--bg-tile` |
| рамка | `1px solid var(--border-light)` | по Tile |
| радиус | `--radius-control` (= `--radius-m`) | `--radius-card` |
| поля | `--space-12` | по Tile |
| тень | нет | по Tile |
| заголовок | `--type-body-s-strong` | по Tile |
| подзаголовок | `--type-body-xs`, `--text-secondary` | по Tile |
| иконка заголовка | 18, `--primary` (вопрос 5.3) | — |

Инварианты:

- Inset — **только внутри** другой поверхности (Tile, Modal, Drawer,
  PromptInput). На фоне страницы он сливается с `--bg-page`.
- Inset в Inset — нельзя.
- Alert-слот, грип, Accordion — у Inset не бывает (как у Card нет алерт-слота).
- Если строки внутри — интерактивные Entity (`.entity--interactive`), их
  подложка hover выносится на 8 px по вертикали и 10 px по бокам: поля Inset
  12 px это вмещают; строки — только в `.entity-list` (правило Entity, Б33).
  В прототипе строки не интерактивны — проверить, что так и останется.

## 5. Вопросы к человеку

1. **Вариант Tile или новый компонент** («Group», «Panel»)? Рекомендую
   вариант Tile (§1).
2. **Иконка заголовка** — если в Tile её нет: добавить `.tile__title-icon`
   всем вариантам или только Inset? Рекомендую всем (одно правило).
3. **Цвет иконки заголовка** — `--primary`, как в прототипе, или
   `--secondary` по правилу ДС?
4. **«Показать в чате» / «В чате»** — переключатель (`aria-pressed`) или
   кнопка, меняющая действие на «перейти к документу» (как сейчас)?
   Рекомендую как сейчас: второе нажатие не убирает документ из чата.

## Решения (06.10.2026)

1. **Вариант Tile**, не новый компонент (рекомендация §5.1).
2. **Иконка заголовка** `.tile__title-icon` — всем вариантам (рекомендация
   §5.2): Tile и Card — глиф 20, Inset — 18; коробка высотой в строку заголовка.
3. **Цвет иконки** — `--secondary` по умолчанию (правило ДС) и тоны
   `--accent` (`--primary`, как в прототипе), `--success`, `--warning`,
   `--error`, `--info` — тем же правилом, что у иконки-приписки.
4. **«Показать в чате» / «В чате»** — как сейчас: `DSButton.swap` (MS0010b).

Поправка к §2.2: радиус обычного Tile — `--radius-m` (8), а не `--radius-card`;
у Inset тот же.
