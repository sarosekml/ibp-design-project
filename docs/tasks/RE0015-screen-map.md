# Карта экранов Post

## Коротко

- **Что.** Карта страниц проекта Post в виде майндмапа: от главной до самых
  глубоких экранов. Клик по карточке открывает страницу в состоянии по
  умолчанию, с живыми демо-данными.
- **Зачем** (словами человека, 11.10.2026): открыть любую страницу быстрее, чем
  проходить на неё через весь пользовательский сценарий от одной страницы к
  другой. Глубокие экраны зависят от адреса (`Tranche.preview.html?id=&tr=`,
  `FinInstrument.preview.html?id=&fi=`, `FairValueCalculation.preview.html?id=&role=`),
  без цепочки до них не дойти.
- **Состояния** — отдельно и опционально: переключатель «Состояния» на карте
  (по умолчанию выключен) показывает под страницами чипы — окна, статусы,
  варианты по параметрам.
- **Где.** Папка `apps/screen-map/` (не раздел и не приложение, как
  `apps/local-components/`), генератор `.agents/tools/screen-map.mjs`, отрисовщик
  `.agents/proto-panel/map-view.js`, инструмент «Карта» в панели прототипа.
  Экраны модулей и ДС не правим.
- **На будущее.** Другие проекты (Pre, Core, IB) подключаются своей записью в
  `project.json → screenMap.maps` и своим `map.yaml`.

Решения человека 11.10.2026:

| Вопрос | Решение |
|---|---|
| Входы | пункт «Карта Post» на хабе в колонке «Проекты», сразу под «Post — ДИД»; инструмент «Карта» в рельсе панели прототипа (`Alt+Shift+P` на странице Post) |
| Что на карте | страницы проекта Post (модули `deals-app`, `post-reports-app`) в состоянии по умолчанию; концептов нет |
| Точка входа | одна — главная Post `deals-app/pages/MainPage.html`, как на реальном проекте: главная → остальные страницы |
| Состояния | переключатель на карте, по умолчанию выключен; в панели — состояния текущей страницы |
| Вид | майндмап: Главная слева, ветви вправо; в шторке панели — вертикальное дерево |
| Проверка | только в генераторе, шага `map` в гейте нет |
| «Новый транш» | не делаем: окна создания транша нет — транш добавляется в дерево сразу |

## Objective

С хаба или из панели на любой странице Post открывается карта проекта:
страницы обоих модулей и связи «откуда куда» от главной. Клик по странице
открывает её с живыми демо-данными; при включённых состояниях клик по чипу
открывает страницу в нужном виде. Карта описана одним файлом на проект, и
генератор следит, чтобы ни одна страница не выпала.

## 2. Как выглядит

    ( Главная ) ──┬─ Текущий портфель ── Сделка ─┬─ Транш ── Корректировки РСБУ
                  │                              └─ Финансовый инструмент
                  └─ Реестр расчетов FV ── Расчет FV

- **Карточка страницы** — Tile-карточка ДС с Entity внутри: модуль, название,
  файл и параметры мелким текстом. Клик открывает страницу с демо-данными.
- **Связи** — кривые SVG от родителя к ребёнку, ребро — из `parent` узла;
  своё поверх ДС только это, на токенах цвета (как схема статусной модели
  витрины, `apps/local-components/kit-model.js`).
- **Состояния** — чипы под карточкой, видны при включённом переключателе.
- **В панели** — вертикальное дерево (`.prow-tree` ДС), текущая страница
  подсвечена, под ней — её состояния.

## 3. Источник данных

`apps/screen-map/<раздел>/map.yaml` пишется руками. Узел описывается языком
сценариев панели (`page`, `do`), состояние — своё (`page` с параметрами или
`do`) или ссылкой на сценарий панели (`flow:` и `steps:`). Формат и коды КЭ —
шапка `.agents/tools/screen-map.mjs`.

Генератор собирает `map.yaml` в `map-data.js` (обычный `<script>`: по
file:// fetch не работает) и проверяет: страницы и приложения узлов, связи,
сценарии, селекторы действий, демо-параметры адресов, одну точку входа и
**покрытие** — каждая страница модулей проекта стоит на карте, иначе дефект с
именем страницы.

## Acceptance Criteria

- На хабе в колонке «Проекты» сразу под «Post — ДИД» — пункт «Карта Post».
  Карта показывает майндмапом все 8 страниц `deals-app` и `post-reports-app` от
  главной; концептов нет.
- Клик по каждой странице открывает живую страницу с данными, а не каркас без
  параметров.
- Переключатель «Состояния»: «Сформирован» открывает расчет FV `id=16`,
  хардсы транша переключаются, «Новая сделка» открывает окно на портфеле.
- На `Tranche.preview.html` `Alt+Shift+P` → «Карта»: транш подсвечен, его
  состояния под ним, клик по «Расчет FV» уводит в другой модуль.
- Если временно убрать узел из `map.yaml`, генератор называет пропущенную
  страницу.
