# Упростить экран чата M4P: убрать временно ненужные функции

## Objective

Упростить экран чата M4P в прототипе: убрать функции, которых пока не будет, сократить статусы чатов и метаданные. Формулировки изменений — в списке ниже, сохранены как в постановке без правок.

## Tasks

1. Поиск компании убрать, пока просто поле ввода без подстановки
2. Доп фокус - пока константы
3. Скрепки пока не будет, К запросу можно приложить PDF, Word, PowerPoint и Excel - убрать
4. Источники в сообщении пока убираем
5. Поделиться, настроить уведомления не нужно пока
6. Скачать пока только мд - кнопка просто скачать без дропдауна
7. Предпросмотр пока тоже убираем из m4p
8. Статусы чатов пока только 2: подготовка и ответ готов
9. Версия, файлов, доступ из метадаты под хедером убрать, в списке чатов исправить тоже теги: версия и т.д.
10. По клиенту · Группа · Детальный - эти параметры пересмотреть что сюда выводить

## Acceptance Criteria

- Все пункты нумерованного списка выполнены
- Остальной функционал экрана не затронут
