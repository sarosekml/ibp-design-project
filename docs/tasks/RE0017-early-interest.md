# Досрочные проценты

## Коротко

- **Что.** Новая карточка «Досрочные проценты» на странице транша и кредитоподобного
  опциона (опцион со «Структурой выплат по опциону» = «Процентные платежи»). Карточка
  ведёт на страницу «Досрочные проценты». На странице — таблица досрочных платежей
  процентов, окно «Новые проценты» (ввод и правка) и окно «Порядок погашения». Порядок
  один на инструмент: по нему сумма платежа гасит типы процентной задолженности.
- **Источник.** Только бизнес-требования (БТ), текст — в разделе 1. Макетов нет: тайл и
  окна собраны по образцу «Корректировок процентов РСБУ» (RE0013, RE0016). Всё, что решил
  агент, перечислено отдельно — раздел «Решения агента — на разбор».
- **Где.** Концепт `apps/postrade/drafts/early-interest/` (на хабе — «Post — Досрочные
  проценты»). Страница транша — копия `deals-app/pages/Tranche.html` с новым тайлом. Виджеты
  концепта лежат в его `widgets/`; концепт может брать виджеты модулей своего раздела, а модуль
  из `drafts/` — нет (СБ6). Согласованный концепт переносится в `deals-app` командой `/promote`.
- **Роли.** Редактируют Финансист ДИД и Финансист СБИ. Смотрят те же роли, что и
  «Процентные схемы» и «Процентные периоды». Вид без права правки — параметр `?mode=view`
  (панель прототипа).

Решения человека 12.10.2026:

| Вопрос | Решение |
|---|---|
| Основа концепта | копия страницы транша из `deals-app`, новый концепт в `drafts/` раздела Post |
| Источник | только БТ, макетов нет; решения агента — отдельным списком на разбор |
| Типы задолженности | не важно, заглушки допустимы |
| Показ и правка порядка погашения | придумать самому: удобно показать и удобно править |
| Перестановка в окне порядка | стрелками |
| Два платежа на одну дату | теоретически можно |
| Сумма | без верхнего предела, валюта — валюта инструмента |
| Роль просмотра и окно порядка | окно открывается на чтение |
| Текст «Недоступна к заполнению» | придумать самому |
| Влияние на «Процентные» и «Плановые платежи» | пометка на тайлах компонентом ДС Note |
| Тайл «Заполнена» | предложить полезное для пользователя |
| Кредитоподобный опцион | хватит транша |
| Адрес страницы | страница в концепте, как корректировки РСБУ |

## Objective

Показать бизнесу и разработке, как вносят досрочные платежи процентов: где на транше
карточка и в каких она видах, как выглядит страница со списком платежей, как платёж
вносят, правят и удаляют, как задаётся порядок погашения задолженности и как он виден
на странице. Результат — концепт с панелью прототипа и спеками, готовый к `/promote` в
`deals-app` и к спецификации на разработку (`/dev-spec`).

## 1. Источник — БТ (12.10.2026)

1. На странице инструментов «Транш» и кредитоподобный опцион (любой опцион со
   «Структурой выплат по опциону» = «Процентные платежи») есть карточка «Досрочные проценты».
2. Состояния карточки:
   - **Не заполнена.** Кнопка-переход на страницу «Досрочные проценты» и кнопка
     «Заполнить»: она открывает эту страницу с окном «Новые проценты».
   - **Заполнена.** Кнопка-переход на страницу «Досрочные проценты».
   - **Недоступна к заполнению.** Сначала нужно рассчитать «Процентные платежи».
3. Доступ к карточке и странице: редактирование — Финансист ДИД, Финансист СБИ;
   просмотр — те же роли, что у карточек «Процентные схемы», «Процентные периоды» и т. д.
4. Есть страница «Досрочные проценты».
5. Кнопка «Новые проценты» открывает окно корректировки с полями:
   - **«Дата платежа».** Дата платежа, с которого начинается погашение остальных типов
     задолженности в заданном порядке. Выпадающий список из дат платежей по погашению
     всех видов процентов из «Плановых платежей». Обязательное поле.
   - **«Сумма платежа».** Влияет, в том числе, на погашение остальных типов задолженности в
     заданном порядке. Обязательное поле.
   - **«Тип платежа».** По умолчанию «Погашение процентов (досрочное)». Поле заполнено
     заранее, сменить тип нельзя.
   - **«Комментарий».** Ручной ввод текста.
6. Таблица с данными из окна «Новые проценты». Столбцы: «№», «Дата платежа», «Сумма
   платежа», «Комментарий». Каждую строку можно править в том же окне или удалить
   отдельной кнопкой.
7. Кнопка «Порядок погашения» открывает окно с порядком погашения процентной
   задолженности. «Сумма платежа» из «Новых процентов» гасит процентные платежи в этом
   порядке. Порядок один на весь инструмент. В окне перечислены все типы задолженности, их
   можно расставить в любом порядке; № 1 — самый приоритетный. Пример: 1. Капитализированная
   задолженность, 2. Отложенная задолженность, 3. Капитализированная отложенная
   задолженность. Платёж сначала гасит всю капитализированную задолженность; если её
   хватило погасить целиком, переходит к отложенной, и так далее.
8. На странице показан «Порядок погашения»: первые три типа задолженности по приоритету.
9. Данные карточки «Досрочные проценты» участвуют в расчёте «Процентных платежей» и
   «Плановых платежей».

## 3. Тайл «Досрочные проценты»

| Вид по БТ | Оси | Что видно |

## 4. Страница «Досрочные проценты»

```
Page (Layout, nav--rail, screen--app; крошки … → Транш → Досрочные проценты)
├── PageHeader — «Досрочные проценты», «В транш»; справа «Новые проценты»
├── InterestRepaymentOrderTile (12 колонок) — «Приоритет 1…3», подсказка Note, карандаш → окно
└── Table (dtable--fill) — №, Дата платежа, Сумма платежа (+ код валюты), Комментарий, Действия
```

Пусто — `dtable__empty` с кнопкой «Новые проценты». Просмотр (`?mode=view`) — без «Новые
проценты» и колонки «Действия», в тайле порядка «Посмотреть» вместо карандаша. Параметры
адреса для панели: `?open=add`, `?demo=filled|edit|delete|error|order`, `?mode=view`.
Возврат на транш несёт `eiState` (по числу строк) и `recalc=1` (если платежи или порядок менялись).

## 5. Окна

**«Новые проценты» / «Редактирование досрочных процентов»** (`EarlyInterestPaymentModal`, `modal--w4`):

| Поле | Компонент | Правило |
|---|---|---|
| Дата платежа | Select + DropdownList | даты погашения процентов из «Плановых платежей»; обязательное |
| Сумма платежа | InputAmount | больше нуля, без предела, валюта инструмента постфиксом; обязательное |
| Тип платежа | InputText `inp--disabled` | «Погашение процентов (досрочное)», не меняется |
| Комментарий | InputText `inp--multiline` | необязательное |

Под формой — Note с первыми тремя типами порядка погашения. Ошибки — Alert вверху окна.

**«Порядок погашения»** (`InterestRepaymentOrderModal`, `modal--w4`): Note с правилом погашения,
список Entity «Приоритет N» + тип, стрелки «выше» / «ниже» в строке (края выключены, фокус
остаётся на стрелке), «Отменить» / «Сохранить»; на чтение — без стрелок, «Закрыть».

## Acceptance Criteria

- На хабе в «Концептах» — «Post — Досрочные проценты». Страница транша показывает тайл
  в трёх видах по БТ и в режиме просмотра.
- «Заполнить» открывает страницу с поднятым окном «Новые проценты». Строку можно
  добавить, поправить и удалить с подтверждением, номера в «№» пересчитываются.
- Окно не сохраняется без даты и суммы и с суммой 0. «Тип платежа» не меняется. Даты — только
  из списка «Плановых платежей».
- «Порядок погашения» меняет порядок стрелками, и тайл на странице показывает первые три типа.
- В режиме просмотра нет кнопок правки, добавления и удаления; порядок открывается на чтение.
- На каждый `.html` есть `.screen.md`, у каждого виджета есть паспорт.
  `layout-check.mjs` — без блокеров, `lessons-cli.mjs gate` — `ВЕРДИКТ: OK`,
  `vendor-scan.mjs` — OK.
