# Quote: цитата фрагмента

## Коротко

- **Откуда.** Композер `RequestThread.html` v02. Пользователь выделяет
  текст в материале и жмёт «Доработать в чате» — фрагмент встаёт чипом над
  полем; по клику на чип фрагмент раскрывается целиком (`.cmp-quote`,
  строки ~334–339; разметка ~655–661): подпись источника «Фрагмент
  материала · <раздел>», кнопка «Свернуть» (`ibtn--s`, `chevron-up`), текст
  `body-s`. Слева акцентная линия 3 px `--primary`, фон primary 6 %,
  скругление только справа, `max-height: 180px` со скроллом, анимация
  появления `quoteIn`.
- **Чего нет в ДС.** Блока цитаты нет ни в компонентах, ни в Typography.
- **Задача.** Новая молекула **Quote** — `components/molecules/Quote/`,
  версия `1.000`. Внутри — IconButton (уже ДС). Перевести цитату прототипа.
- **Часть группы MS0010.** Используется PromptInput (MS0010). Цитаты в
  ответах агента, в комментариях, в истории изменений — следующие
  потребители. Правка ДС — после согласования вопросов §5.

## Objective

В ДС есть молекула Quote: выделенный фрагмент чужого текста с подписью
источника и необязательными действиями. Цитата в композере v02 собирается
из неё без локального CSS.

## 1. Решение

### 1.1. Анатомия

```html
<figure class="quote" id="cmpQuote">
  <figcaption class="quote__head">
    <span class="quote__source">Фрагмент материала · Долговая нагрузка</span>
    <span class="quote__actions">
      <button type="button" class="ibtn ibtn--neutral ibtn--s" aria-label="Свернуть фрагмент" data-tooltip="Свернуть"><i data-icon="chevron-up"></i></button>
    </span>
  </figcaption>
  <blockquote class="quote__text ds-scroll"><p>…текст фрагмента…</p></blockquote>
</figure>
```

- `figure` + `figcaption` + `blockquote` — нативная семантика цитаты.
- `quote__head` и `quote__actions` необязательны.
- Текст длиннее максимума прокручивается внутри (`.ds-scroll`) — шапка
  остаётся на месте.

### 1.2. Визуал (токены)

| Часть | Свойство | Значение | В прототипе |
|---|---|---|---|
| `.quote` | акцентная линия | `inset`-тень 3 px слева или `border-left` — толщина: вопрос 5.1 | `border-left: 3px solid var(--primary)` |
| | фон | `--st-primary-light` (вопрос 5.2) | `color-mix(primary 6 %)` |
| | радиус | `0 var(--radius-control) var(--radius-control) 0` | `0 --radius-m --radius-m 0` |
| | поля | `--space-8` `--space-8` `--space-8` `--space-12` | то же |
| | зазор | `--space-4` | то же |
| `.quote__source` | текст | `--type-body-xs`, `--text-secondary` | то же |
| `.quote__text` | текст | `--type-body-s`, `--text-primary` | то же |
| | макс. высота | вопрос 5.3 | 180 px |

Тоны: базовый — primary; нейтральный `.quote--neutral` (линия
`--border-primary`, фон `--bg-page`) — для цитат в чужом контексте (вопрос 5.4).

### 1.3. Поведение

- Компонент статичен, рантайма нет. Показ и скрытие — атрибут `hidden`
  (`.quote[hidden]`), его ставит экран.
- Анимация появления `quoteIn` — не переносится (нет токенов движения,
  см. MS0010 вопрос 7.5).

### 1.4. Доступность

- Источник — в `figcaption`, читается вместе с цитатой.
- Кнопка «Свернуть» — `aria-label`; чип, который раскрыл цитату, —
  `aria-expanded` + `aria-controls` на `id` цитаты (MS0010c).

## 5. Вопросы к человеку

1. **Толщина линии** 3 px — в ДС нет токена толщины. Варианты: `--space-4`
   (4 px), `--space-2` (2 px) или 3 px литералом в CSS компонента.
   Рекомендую `--space-4` — ближайший токен, ровная сетка.
2. **Фон** — `--st-primary-light` (рекомендую, ступень рампы) или без фона,
   только линия?
3. **Максимальная высота** 180 px — не токен. Рекомендую «6 строк body-s».
4. **Нейтральный тон** нужен сейчас? Рекомендую нет — по первому запросу.
