# Kbd: обозначение клавиши

## Коротко

- **Откуда.** Подсказка под композером `RequestThread.html` v02:
  «`Enter` — отправить · `Shift` + `Enter` — новая строка». Клавиши —
  `<kbd>` с локальным стилем `.cmp__hint kbd` (строка ~324).
- **Чего нет в ДС.** Компонента для клавиши нет (греп `kbd` по CSS ДС
  05.10.2026 — ноль). `<kbd>` встречается только в двух копиях этого экрана.
- **Задача.** Новый атом **Kbd** — `components/atoms/Kbd/`, версия `1.000`.
  Перевести подсказку прототипа на него.
- **Часть группы MS0010** (поле промпта): атом, без зависимостей, идёт до
  PromptInput. Правка ДС — после согласования вопросов §5.

## Objective

В ДС есть атом Kbd: клавиша и сочетание клавиш в тексте подсказок, тултипов и
пунктов меню. Подсказка композера v02 собирается из него без локального CSS.

## 1. Как сейчас

```css
.cmp__hint kbd { display: inline-block; min-width: 18px; padding: 0 var(--space-4);
  font: inherit; text-align: center; color: var(--text-secondary);
  background: var(--bg-tile); border: 1px solid var(--border-light);
  border-bottom-width: 2px; border-radius: var(--radius-s); }
```

Вид: светлая плашка, рамка, нижняя грань толще на 1 px — «клавиша».
Размер текста — наследуется (`body-xs` подсказки). `min-width: 18px` — не токен.

## 2. Решение

### 2.1. Анатомия и разметка

```html
<kbd class="kbd">Enter</kbd>
<!-- сочетание: клавиши и «+» между ними, «+» — обычный текст -->
<span class="kbd-combo"><kbd class="kbd">Shift</kbd> + <kbd class="kbd">Enter</kbd></span>
```

- Элемент — нативный `<kbd>`: скринридер и копирование текста работают как
  у текста.
- `.kbd-combo` — `inline-flex`, `align-items: center`, зазор `--space-4`,
  не переносится внутри (`white-space: nowrap`).
- Глиф вместо слова (`⌘`, `↵`) — вопрос 5.2.

### 2.2. Размеры

| Размер | Где | Шрифт | Высота |
|---|---|---|---|
| S (по умолчанию) | подсказки body-xs, тултипы, меню | `--type-body-xs` | по строке 16 + рамки |
| M | в тексте body-s / body-m | `--type-body-s` | по строке 20 + рамки — вопрос 5.1 |

`min-width` = высота клавиши (квадрат под одну букву) — из токена шкалы,
не 18 px.

### 2.3. Визуал (токены)

| Свойство | Значение |
|---|---|
| фон | `--bg-tile` |
| рамка | `1px solid var(--border-light)`, нижняя — `2px` |
| радиус | `--radius-control-s` (= `--radius-s`) |
| текст | `--text-secondary`, по центру |
| паддинг | `0 var(--space-4)` |
| тёмная тема | проверить контраст рамки на `--bg-page` в `ibp-dark` |

Состояний нет: клавиша не интерактивна. Не фокусируется, `hover` нет.

### 2.4. Правила применения

- Kbd — только обозначение клавиши. Не кнопка и не чип: нажимать его нельзя.
- В тултипе — справа от подписи действия («Отправить `Enter`»).
- Не больше трёх клавиш в сочетании.

## 5. Вопросы к человеку

1. **Размер M** нужен сейчас или только S? Рекомендую только S: других
   потребителей нет, M — по первому запросу.
2. **Глифы клавиш** (`⌘`, `⌥`, `↵`) вместо слов — нужны? Рекомендую нет:
   пользователи на Windows, слова понятнее.
3. **Имя** — `Kbd` (как HTML-элемент; так в GitHub Primer, Mantine) или
   «Keyboard key»? Рекомендую `Kbd`.
