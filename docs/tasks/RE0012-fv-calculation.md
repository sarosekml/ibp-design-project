## Коротко

- **Что.** Плитка «Расчет FV» на главной (`ibp-home.js`, id `fv-calculation`, группа «Отчёты») ведёт в `#`. Нужны страницы: реестр расчетов FV и страница расчета на дату с окнами правки ФИ, загрузки и выгрузки файлов.

По плитке «Расчет FV» открывается реестр расчетов, из него — страница расчета. Все состояния из макетов воспроизводятся сценариями панели прототипа для обеих ролей. Правила статусов записаны один раз (раздел 3) и совпадают в данных, скрипте и спеке.

## 3. Модель статусов и действий

- **Статусы расчета:** Формируется → Сформирован → Отправлен в LP → Рассчитывается LP → Рассчитан | Ошибка → Утвержден. Везде «Утвержден», не «Утвержден РМ».
- **Статусы ФИ и инструмента:** Сформирован, Отправлен в LP, Рассчитывается LP, Рассчитан, Возвращен из LP (LP нашёл ошибку в файле), Ошибка (мы сами вернули файл кнопкой «Вернуть с ошибкой», чтобы поправить), Нет данных (файл удалён). Если хоть один инструмент «Возвращен из LP» или «Ошибка», у ФИ статус «Ошибка».
- **Тона чипов:** Формируется и Рассчитывается LP — серый, Сформирован — голубой, Отправлен в LP — оранжевый, Рассчитан — фиолетовый, Утвержден — зелёный, Ошибка, Возвращен из LP и Нет данных — красный.
- **Обновить** подгружает в расчет ФИ, созданные после последнего расчета. Новые приходят «Сформирован», текущие не меняются.
- **Пересчитать** заново считает весь расчет, все ФИ и инструменты. Расчет переходит в «Формируется», затем в «Сформирован». То же — для выбранных ФИ (массово и в строке).
- **Отправить в LP** отправляет только ФИ «Сформирован» с отметкой «Передавать в LP». Нет таких — кнопка выключена. После «Обновить» с новым готовым ФИ включается снова. «Рассчитан» — повторная отправка разрешена. «Ошибка» — кнопки нет, сначала «Пересчитать». Отправлять нечего — снекбар «Нет данных для отправки в LP».
- **Меню «⋮»**, порядок один для всех статусов: Обновить · Пересчитать · Выгрузить в XML · Выгрузить в xlsx. Сформирован — все четыре; Отправлен в LP, Рассчитывается LP, Рассчитан — Обновить, XML, xlsx; Ошибка, Утвержден — Пересчитать, XML, xlsx.
- **Утвердить** — только роль «Риск-менеджер», только статус «Рассчитан».
- **Правка ФИ** доступна в любом статусе. По «Сохранить» — подтверждение; ФИ становится «Сформирован», XML-файлы пересчитываются. В «Утвержден» пересчитывается только этот ФИ.
- **Файлы инструментов:** Сформирован — выгрузить шаблон, загрузить, удалить (удалить можно только загруженный); Отправлен в LP и Рассчитывается LP — выгрузить, «Вернуть с ошибкой»; Рассчитан — только выгрузить. В колонке «Файл xml» после загрузки «Загружен», после удаления «Удалён».
- **Ошибки выгрузки:** весь расчет — снекбар; файл одного инструмента — алерт в окне ФИ.
- Плашку «ФИ требующих внимания» убираем. Счётчик раздела фильтра показывает число заполненных полей.

Матрица «статус × роль → кнопки, меню, правка, файлы» хранится в одном месте — в словаре данных. Скрипт экрана и спека берут её оттуда.
