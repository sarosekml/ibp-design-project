## Живая проверка

Встроенный браузер, реальные скрипты и компоненты, временный HTTP-сервер.
Проверены Legacy, Neo light/dark, Custom light/dark; входы и ступень 500;
ползунок клавиатурой; методы генерации; правка ступени и роли через ColorPicker,
сброс и возврат undo/redo; копирование CSS в OKLCH.

Через OPFS подключена отдельная тестовая папка. «Сохранить как…» создало
test-orbit.json и зеркало; другая страница Slider сразу загрузила
test-orbit-dark с CSS на лету и без ошибок. Legacy/Neo не перезаписаны;
дубликат отвергнут. Тестовые файлы в репозиторий не попали.

Чистый документ не отменяет beforeunload; после правки он отменяет уход.
Попытка навигации с несохранённым не ушла со страницы. Новый документ снова
загрузил сохранённые входы — черновик не записывается в браузер.
Встроенный браузер не показывает нативный диалог beforeunload агенту, поэтому
обработчик дополнительно проверен cancelable-событием служебной страницы.

На RequestThread v02 проверены State 03 → открытый конструктор, комментарий,
Fix State и удаление только тестового чернового состояния. Рубильник панели
применяет Custom dark; service-хром сохранён. Drawer прилегает к верхнему,
нижнему и правому краям (0 / 720 / 1280 при viewport 1280 × 720).

Композиция: демо отделено сплиттером, палитры сгруппированы двумя строками
по 11 ступеней, служебные таблицы раскрываются отдельно, настройки и действия
доступны в нижней закреплённой панели. Панели скроллятся независимо.

Открытие file:// во встроенном браузере запрещено его политикой URL.
Файловое зеркало и синхронный загрузчик проверены исполнением JS без fetch;
визуальная проверка проведена через локальный HTTP. Нативное разрешение
записи в папку проверялось заменой DirectoryHandle на OPFS, как предписано ТЗ.
