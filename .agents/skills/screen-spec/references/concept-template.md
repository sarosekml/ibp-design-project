- Кнопка «Новые проценты» → окно `EarlyInterestPaymentModal` в режиме создания.
- Кнопка «Порядок погашения» → окно `InterestRepaymentOrderModal`.
- Пустой реестр → пустое состояние таблицы с текстом «Записей пока нет».
