Задача: панель прототипа у приложения — сценарии показа, зафиксированные
состояния (State NN) и комментарии рядом с прототипом. Процедура — скилл `proto-panel`
(`.agents/skills/proto-panel/SKILL.md`), форматы — `.agents/proto-panel/README.md`.

Приложение: $1
Действие: $2

Если приложение не названо — перечисли приложения с папкой `proto-panel/` и
без неё (каталоги с `app.json` в `apps/`) и спроси, с каким работать.
`<приложение>` для инструмента — путь от корня, от `apps/` или `id` из
`app.json`.

| Действие | Что делаешь |
|---|---|
| пусто или `on` | `node .agents/tools/proto-panel.mjs --enable <приложение>`; сценарии по экранам и ТЗ (скилл, п. 3); `--check`; строка о панели в README приложения; гейт. В отчёте — как открыть панель: `Alt+Shift+P` на любой странице, кнопки по умолчанию нет |
| `flows` | (пере)описать сценарии по текущим экранам (скилл, п. 3); `node .agents/tools/proto-panel.mjs`; гейт |
| `states` | привести в порядок зафиксированные состояния (скилл, п. 5): `--states <приложение>` → план человеку одним списком (названия, `note`, хрупкие селекторы, пометки) → правки прототипа и `flows.yaml` → `--state <приложение> <NN> --clear-issues` → сборка → гейт |
| `comments` | маршрут «Правки по комментариям» (скилл, п. 6): `--list <приложение> --open` → план правок одним списком → правки → `--resolve` по каждому → гейт |
| `off` | выключение с подтверждением (скилл, п. 8): есть комментарии — показать и получить явное «удалить» |

Панель уже включена, а просят `on` — не включай повторно: предложи `flows`.

Заход закрывается гейтом: `node .agents/tools/lessons-cli.mjs gate`, строка
`ВЕРДИКТ:` — в отчёт.
