Задача: концепт прошёл согласование — перенести его из
`apps/<раздел>/drafts/<имя>/` в модуль того же раздела
`apps/<раздел>/<модуль>-app/` так, чтобы всё работало.

Концепт: $1
Модуль: $2

Если концепт не назван — перечисли концепты раздела (папки `drafts/` с
`app.json`) и спроси, какой переносить. Если не назван модуль — предложи
модуль того же раздела по смыслу (README модулей, раздел «Имена фронтенда»)
и дождись подтверждения: модуль выбирает человек.

1. Сухой прогон — покажи пользователю план:

   ```bash
   node .agents/tools/promote.mjs <концепт> <модуль> --dry
   ```

   Строка `ПР1`–`ПР3` — перенос невозможен: другой раздел, источник не
   концепт или конфликт (у модуля своя запись `app.json`, файл с тем же
   путём). Покажи причину и остановись — слияние двух приложений делается
   решением человека, не инструментом.

2. Спроси про трек: модуль — согласованная часть системы, обычно `product`
   (дальше агент правит его только с подтверждением). Перенос с другим
   треком — `--track rnd`.

3. Перенос:

   ```bash
   node .agents/tools/promote.mjs <концепт> <модуль> [--track product]
   ```

   Инструмент переносит файлы (формы концепта и модуля одинаковые),
   пересчитывает пути до загрузчика ДС и хаба (на один `../` короче), метки
   виджетов и ссылки в концепт из других страниц, `file:` в спеках, правило
   прав агента в конфиге адаптера; делает README концепта описанием модуля;
   пересобирает реестр хаба, страницы и дерево README модуля.

4. Строки «упоминание старого пути» — файлы, где старый путь стоит в тексте
   (правила, заметки): поправь их по смыслу, историю в `docs/` не переписывай.

5. Имена: в модуле действует правило «имя — как у фронтенда, тип в конце»
   (`apps/README.md`, «widgets»). Сверь виджеты и страницы с разделом «Имена
   фронтенда» README модуля; переименование — только по подтверждению
   человека, затем `node .agents/tools/assemble.mjs` и
   `node .agents/tools/module-readme.mjs`.

6. Опиши модуль в его README (текст вокруг блока дерева): что это за часть
   системы, какие экраны, пары во фронтенде.

7. Заход закрывается гейтом: `node .agents/tools/lessons-cli.mjs gate`,
   строка `ВЕРДИКТ:` — в отчёт. Покажи пользователю, где теперь открывать
   экраны (хаб — корневой `index.html`).
