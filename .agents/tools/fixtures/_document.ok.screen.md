# Фикстура-эталон документа

Файл не описывает продуктовый экран. Он объявляет для `_document.ok.html`
вид `kind: document`: лист-документ без каркаса приложения. Сенсор не
применяет к такому файлу Б5 (каркас) и К12, а Б6 проверяет как «ровно один
h1».

Фикстура `Б5@document.bad.html` — тот же лист, но её спутник строки `kind`
не несёт: одно изменение между фикстурой и этим эталоном — строка вида в
спеке. Так доказываются обе половины: вид работает, и лист без объявленного
вида по-прежнему краснеет как экран без каркаса.
