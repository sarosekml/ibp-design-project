# Приоритет погашения

## Описание (Purpose)

Тайл страницы «Досрочное погашение процентов». Сумма досрочного платежа гасит процентную
задолженность по видам в заданном порядке: сначала весь вид с приоритетом 1, остаток — вид с
приоритетом 2 и далее. Приоритет один на весь инструмент. Тайл показывает все виды списком: номер
приоритета в сером квадрате и название. Перестановка — в окне «Приоритет погашения», которое
открывает карандаш в шапке (только с правом редактирования).

## Раскладка (Layout)

```
Tile (заголовок «Приоритет погашения»)
├── шапка: IconButton edit «Изменить приоритет погашения» (только data-mode="edit")
└── тело — список Entity S: номер приоритета в квадрате (entity__icon--neutral) + название вида
```

## Переполнение (Overflow)

| Случай | Правило |
|---|---|
| Длинный текст в поле | Название переносится на следующую строку, номер остаётся по центру высоты строки |
| Много строк или записей | Показываются все виды; тайл тянется на высоту колонки |
| Узкая ширина | Названия переносятся |
| Полная ширина | Без изменений |

## Поведение (Behavior)

- Карандаш «Изменить приоритет погашения» → окно «Приоритет погашения» с перестановкой.
- После «Сохранить» в окне → список показывает новый порядок, страница показывает тост «Приоритет погашения изменен».
