# Окно «Приоритет погашения»

## Описание (Purpose)

Артефакт тайла «Приоритет погашения». «Сумма платежа» из окна «Новый платеж» гасит процентную
задолженность по видам в этом порядке: сначала весь вид с приоритетом 1; если платёж погасил
его целиком, остаток идёт на вид с приоритетом 2, и так далее. Порядок один на весь
инструмент. В окне — все виды задолженности, их можно расставить в любом порядке; приоритет 1 —
сверху. Подсказка окна (макет): «Досрочный платёж гасит задолженность сверху вниз: сначала тип
с приоритетом 1, остаток — следующий по порядку. Порядок один на весь инструмент.»

Порядок окно не хранит: получает его при открытии, новый отдаёт странице по «Сохранить»
(`PostModalRepaymentOrder.bind(scrim, { labels, save })`, `RepaymentPriorityModal.js`).

## Раскладка (Layout)

```
Modal w4 (заголовок «Приоритет погашения», IconButton L «Закрыть»)
├── тело
│   ├── Note — правило погашения
│   └── entity-list — строка Entity в рамке на каждый вид задолженности
│       ├── номер приоритета в сером квадрате · название вида
│       └── действия: IconButton S «Выше» (chevron-up) · «Ниже» (chevron-down) — только edit
└── подвал: edit — «Отменить» (transparent) · «Сохранить» (accent); view — «Закрыть» (accent)
```

Ширина — `modal--w4`. Ось `data-mode` (`edit` · `view`) — на `.modal`.

## Поведение (Behavior)

| Триггер | Результат |
|---|---|
| Перетаскивание за грип (`drag-dots`) в начале строки | строка бледнеет, место вставки — линия 2px `--primary-dark` в зазоре между строками (как у Kanban); по отпусканию вид занимает новое место, номера пересчитываются. Рантайма перетаскивания в ДС нет — код локальный по образцу списка колонок «Настройка таблицы» (`TableSettings.js`) |
| «Выше» в строке | вид поднимается на одно место, номера пересчитываются, фокус остаётся на стрелке этой строки |
| «Ниже» в строке | вид опускается на одно место, то же |
| «Сохранить» | окно закрывается, тайл «Приоритет погашения» показывает новый порядок, тост «Приоритет погашения изменен» |
| «Отменить», крестик, Esc | окно закрывается, порядок прежний |
| «Закрыть» (view) | окно закрывается |
