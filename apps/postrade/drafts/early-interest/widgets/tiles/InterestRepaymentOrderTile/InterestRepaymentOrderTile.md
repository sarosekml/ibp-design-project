# Порядок погашения

## Описание (Purpose)

Тайл страницы «Досрочные проценты». Сумма досрочного платежа гасит процентную задолженность
по типам в заданном порядке: сначала весь тип с приоритетом 1, остаток — тип с приоритетом 2
и далее. Порядок один на весь инструмент. Тайл показывает первые три типа по приоритету
(требование) и объясняет правило погашения подсказкой; полный список и перестановка — в окне
«Порядок погашения», которое открывает кнопка шапки. Показ и правка стоят рядом, над таблицей
платежей, — пользователь видит, как распределится сумма, до того как вносит платёж.

## Раскладка (Layout)

```
Tile (заголовок «Порядок погашения»)
├── шапка: IconButton edit «Изменить порядок погашения» (edit) | maximize «Посмотреть порядок погашения» (view)
└── тело
    ├── tile__grid в три колонки — ReadOnlyField «Приоритет 1», «Приоритет 2», «Приоритет 3»
    └── Note — правило погашения и «Ещё N типов задолженности — в окне „Порядок погашения“»
```

## Переполнение (Overflow)

| Случай | Правило |
|---|---|
| Длинный текст в поле | Подпись типа усекается многоточием, полная — в тултипе (ReadOnlyField) |
| Много строк или записей | Видны три типа, остальные — числом в подсказке |
| Узкая ширина | Три колонки сохраняются, подписи усекаются; подсказка переносится |
| Полная ширина | Без изменений |

## Поведение (Behavior)

- Карандаш «Изменить порядок погашения» (`edit`) → окно «Порядок погашения» с перестановкой.
- «Посмотреть порядок погашения» (`view`) → то же окно только для чтения.
- После «Сохранить» в окне → поля и подсказка показывают новый порядок.
