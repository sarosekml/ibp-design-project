# Окно «Новые проценты»

## Описание (Purpose)

Артефакт тайла «Досрочные проценты». Заголовок окна — «Новые проценты» при внесении и
«Редактирование досрочных процентов» при правке, форма одна.

Досрочный платёж процентов — сумма, которая начиная с «Даты платежа» гасит процентную
задолженность по типам в порядке погашения инструмента (окно «Порядок погашения»). Дата —
одна из дат погашения процентов в «Плановых платежах». Платёж участвует в расчёте «Процентных
платежей» и «Плановых платежей». Подсказка внизу окна напоминает порядок, в котором сумма
погасит задолженность.

Страницу и таблицу окно не знает: даты, валюту и порядок берёт у страницы, проверенную запись
отдаёт ей же (`PostModalEarlyInterest.bind(scrim, { options, save })`,
`EarlyInterestPaymentModal.js`). Страница добавляет или правит строку и показывает тост.

## Раскладка (Layout)

```
Modal w4 (заголовок «Новые проценты» / «Редактирование досрочных процентов», IconButton L «Закрыть»)
├── modal__alert — Alert error (скрыт, пока ошибки нет)
├── тело
│   ├── форма в одну колонку
│   │   ├── ряд из двух колонок: «Дата платежа» (Select + DropdownList) · «Сумма платежа» (InputAmount)
│   │   ├── «Тип платежа» — InputText disabled, «Погашение процентов (досрочное)»
│   │   └── «Комментарий» — InputText multiline
│   └── Note — «Сумма гасит задолженность по порядку погашения: 1. …, 2. …, 3. … и далее.»
└── подвал: «Отменить» (transparent) · «Добавить» / «Сохранить» (accent)
```

Ширина — `modal--w4`. Раскладку формы задаёт `EarlyInterestPaymentModal.css`, остальное — Modal.

## Обязательность заполнения (Required)

- Компонент обязателен к заполнению целиком: не применимо — окно.
- Обязательные поля: «Дата платежа», «Сумма платежа».
- Что показывает, когда обязательное не заполнено: по «Добавить» / «Сохранить» — Alert «Выберите дату платежа и введите сумму платежа.», поля подсвечены `inp--error`.
- Что отдаёт наружу: запись `{ paymentDate, paymentAmount, comment }` через `save`.

## Переполнение (Overflow)

| Случай | Правило |
|---|---|
| Длинный текст в поле | Комментарий — многострочное поле, текст переносится |
| Много строк или записей | Список дат — `ddl--scroll`, прокрутка внутри |
| Узкая ширина | Ширина окна фиксирована `modal--w4` |
| Полная ширина | Без изменений |

## Поведение (Behavior)

| Триггер | Результат |
|---|---|
| Ввод в «Сумму платежа» | разряды неразрывным пробелом, запятая, два знака; знак «-» не вводится |
| Ручной ввод в «Дату платежа» | совпал с датой списка — выбор; иначе возврат к выбранной |
| «Добавить» / «Сохранить» с пустой датой или суммой | Alert «Выберите дату платежа и введите сумму платежа.», поля подсвечены |
| «Добавить» / «Сохранить» с суммой 0 | Alert «Сумма платежа должна быть больше нуля.» |
| «Добавить» / «Сохранить» без ошибок | окно закрывается, страница добавляет или правит строку, тост |
| «Отменить», крестик, Esc | окно закрывается без изменений; клик по скриму окно не закрывает (форма) |

Две записи на одну дату допустимы (ответ человека 12.10.2026) — окно их не запрещает.
