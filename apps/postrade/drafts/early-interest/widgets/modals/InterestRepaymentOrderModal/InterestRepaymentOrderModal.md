# Окно «Порядок погашения»

## Описание (Purpose)

Артефакт тайла «Порядок погашения». «Сумма платежа» из окна «Новые проценты» гасит процентную
задолженность по типам в этом порядке: сначала весь тип с приоритетом 1; если платёж погасил
его целиком, остаток идёт на тип с приоритетом 2, и так далее. Порядок один на весь
инструмент. В окне — все типы задолженности, их можно расставить в любом порядке; приоритет 1 —
сверху. Пример из требования: 1. Капитализированная задолженность, 2. Отложенная
задолженность, 3. Капитализированная отложенная задолженность.

Порядок окно не хранит: получает его при открытии, новый отдаёт странице по «Сохранить»
(`PostModalRepaymentOrder.bind(scrim, { labels, save })`, `InterestRepaymentOrderModal.js`).

## Раскладка (Layout)

```
Modal w4 (заголовок «Порядок погашения», IconButton L «Закрыть»)
├── тело
│   ├── Note — правило погашения
│   └── entity-list — строка Entity на каждый тип задолженности
│       ├── надзаголовок «Приоритет N» · подпись типа
│       └── действия: IconButton S «Выше» (arrow-narrow-up) · «Ниже» (arrow-narrow-down) — только edit
└── подвал: edit — «Отменить» (transparent) · «Сохранить» (accent); view — «Закрыть» (accent)
```

Ширина — `modal--w4`. Ось `data-mode` (`edit` · `view`) — на `.modal`.

## Переполнение (Overflow)

| Случай | Правило |
|---|---|
| Длинный текст в поле | Подпись типа — Entity Label, одна строка; длинная усекается (`entity__label--truncate` не стоит — допущение: подписи короткие, вопрос 4) |
| Много строк или записей | Тело окна прокручивается (Modal) |
| Узкая ширина | Ширина окна фиксирована `modal--w4` |
| Полная ширина | Без изменений |

## Поведение (Behavior)

| Триггер | Результат |
|---|---|
| «Выше» в строке | тип поднимается на одно место, номера «Приоритет N» пересчитываются, фокус остаётся на стрелке этой строки |
| «Ниже» в строке | тип опускается на одно место, то же |
| «Сохранить» | окно закрывается, тайл «Порядок погашения» показывает новые первые три типа, тост «Порядок погашения сохранён» |
| «Отменить», крестик, Esc | окно закрывается, порядок прежний |
| «Закрыть» (view) | окно закрывается |
