# Page: index — Спецификации на разработку

## 1. Назначение (Purpose)

Каталог спецификаций на разработку раздела Post (задача RE0016): карточка на каждую спеку. Спека
открывается отдельной страницей `Spec.html`; версии (этапы) одной спеки — в её карточке. В продукт
страница не переносится.

**Роль пользователя:** дизайнер, который передаёт сценарий разработке.

## 2. Адрес и навигация (Route)

- Хаб → «Концепты» → «Post — Спецификации на разработку».
- Пункт меню «Спецификации на разработку» — выбран; строка пользователя ведёт на хаб.

| Уровень крошек | Текст | Ссылка |
|---|---|---|
| 1 (текущий) | Спецификации на разработку | — |

## 3. Раскладка (Layout)

```
Page (Layout, nav--rail, screen--app)
├── PageHeader — заголовок, подзаголовок
```

## 4. Компоненты (Components)

| Компонент | Откуда | Где на экране | Варианты и ключевые параметры |
|---|---|---|---|
| Layout, NavPanel | ДС | каркас | `nav--rail`, `screen--app` |
| Breadcrumbs | ДС | крошки | одна текущая |
| PageHeader | ДС | шапка | заголовок и строка пояснения |
| Tile | ДС | карточка спеки | `col-4 colw-6`; в шапке название и стрелка на спеку; в теле модуль, версия, дата, число снимков |
| Buttons | ДС | тело карточки | «Открыть» — `btn--outline btn--s`; при нескольких версиях — по кнопке на версию |
| IconButton | ДС | шапка карточки | `arrow-right`, `ibtn--neutral ibtn--m`, ссылка на спеку |
| EmptyState | ДС | вместо карточек | `es--l`, `empty-folder` — когда спек нет |

## 6. Поведение (Behavior)

| Триггер | Результат |
|---|---|
| Стрелка в шапке карточки, «Открыть» | страница `Spec.html?spec=<id>` |
| Кнопка версии (если версий несколько) | страница этой версии |

Спеки с одним названием — версии одной спеки: одна карточка, в ней кнопка на каждую версию; стрелка
ведёт на последнюю.

## 10. Данные (Data dependencies)

`../data/dev-specs.js` — индекс, дописывает теги генератов `../data/<Spec>.dev-spec.js`; каждый кладёт
в `window.DEV_SPECS` запись `{ id, title, module, version, stage, date, designer, snaps, viewport,
taken, md, html }`. Генераты собирает `node .agents/tools/dev-spec.mjs` из
`refs/<Spec>/<Spec>.dev-spec.md`, руками не правятся.
