# Page: Spec — Спецификация на разработку

## 1. Назначение (Purpose)

Одна спецификация на разработку на отдельной странице: ровно тот автономный html, что уходит
разработчикам, и выгрузка папкой `<Spec>/` (`<Spec>.md` + `<Spec>.html`). Вкладки — только версии
(этапы) одной спеки: когда номер задачи один, а реализация разбита на этапы и каждый этап добавляет
часть функций. У спеки в одной версии вкладок нет. В продукт страница не переносится.

**Роль пользователя:** дизайнер, который передаёт сценарий разработке.

## 2. Адрес и навигация (Route)

- Из каталога «Спецификации на разработку» — карточка спеки или её версия.
- Адрес — `Spec.html?spec=<id>` (`?spec=EarlyInterestPayments`); без параметра или с неизвестным
  id — пустое состояние со ссылкой на каталог.
- Пункт меню «Спецификации на разработку» — выбран; строка пользователя ведёт на хаб.

| Уровень крошек | Текст | Ссылка |
|---|---|---|
| 1 | Спецификации на разработку | `index.html` |
| 2 (текущий) | название спеки | — |

## 3. Раскладка (Layout)

```
Page (Layout, nav--rail, screen--app)
├── PageHeader — название спеки, подзаголовок со сведениями, три кнопки выгрузки
├── Tab (horizontal) — версии спеки; скрыты, если версия одна
└── Tile headless — iframe со спекой на всю свободную высоту
```

## 4. Компоненты (Components)

| Компонент | Откуда | Где на экране | Варианты и ключевые параметры |
|---|---|---|---|
| Layout, NavPanel | ДС | каркас | `nav--rail`, `screen--app` |
| Breadcrumbs | ДС | крошки | каталог › спека |
| PageHeader | ДС | шапка | `phead__meta` — модуль, версия, дата, число снимков, дата съёмки |
| Buttons | ДС | шапка | «Скачать .md», «Скачать .html» — `btn--outline btn--m`; «Скачать папку (.zip)» — `btn--accent btn--m` |
| Tab | ДС | под шапкой | `tabs--horiz`, `tab--m`, `data-tabs`; подпись — `stage` спеки или «Версия N» |
| Tile | ДС | контент | `tile--headless`, внутри iframe `sandbox="allow-scripts"` |
| EmptyState | ДС | вместо спеки | `es--l`, `empty-folder` — спеки с таким id нет |

Нет.

## 6. Поведение (Behavior)

| Триггер | Результат |
|---|---|
| Вкладка версии | показывается эта версия, обновляются подзаголовок и адрес |
| «Скачать .md» / «Скачать .html» | файл `<Spec>.md` / `<Spec>.html` |
| «Скачать папку (.zip)» | `<Spec>.zip` с папкой `<Spec>/` и двумя файлами (zip без сжатия, собирается в странице) |

Версии — спеки с одним названием; порядок — по номеру версии.

## 7. Модальные окна (Modals)

Нет. Снимок на весь экран открывает сама спека внутри iframe.

## 8. Состояния (States)

| Состояние | Что показывается |
|---|---|
| Спека есть, версия одна | шапка, спека, кнопки выгрузки |
| Версий несколько | то же и вкладки версий |
| Спеки с таким id нет | EmptyState «Такой спецификации нет», «К списку» |

## 9. Тексты интерфейса (Texts)

Как в разделах 4 и 8.

## 10. Данные (Data dependencies)

`../data/dev-specs.js` — индекс, дописывает теги генератов `../data/<Spec>.dev-spec.js`; каждый кладёт
в `window.DEV_SPECS` запись `{ id, title, module, version, stage, date, designer, snaps, viewport,
taken, md, html }`. Генераты собирает `node .agents/tools/dev-spec.mjs` из
`refs/<Spec>/<Spec>.dev-spec.md`, руками не правятся.

## 11. Соответствие файлов (Implementation mapping)

| Файл | Роль |
|---|---|
| `pages/Spec.html` | страница |
| `refs/<Spec>/<Spec>.dev-spec.md` | исходники спек |
| `data/*.dev-spec.js`, `data/dev-specs.js` | генераты |

## 12. Доступность

Вкладки — `role="tablist"` / `role="tab"`, iframe с `title` спеки, кнопки выгрузки подписаны текстом.

## 13. Открытые вопросы и допущения (Open questions)

1. iframe без собственной рамки — `border: 0` в стиле экрана; рамку даёт Tile.
2. Пункт меню один — у служебной страницы нет разделов продукта; роль в строке пользователя —
   «Дизайнер» (допущение).
3. Версии спеки собираются по совпадению названия (`title`), подпись вкладки — необязательное поле
   `stage` в front matter спеки (допущение 16.10.2026; ни одной спеки с версиями пока нет).
