# Модальное окно финансовых метрик сделки

## Описание (Purpose)

Артефакт тайла «Финансовые метрики сделки». Не компонент: сам по себе не
существует и в плоском списке кита не числится — живёт подпунктом своего тайла.

Тайл — сводка: ВБС, резерв, обесценение, RWA и итог переоценки по PE. Окно
показывает то же целиком: рядом с ВБС — ОСЗ, под ними резервы по каждому ФИ и
переоценку по PE по каждому ФИ. Окно только для просмотра: метрики считает
система, править их негде и некому.

Ширина — `modal--w7` (1053px на 1920), ровно ширина макета. Окно, шапку,
подвал, бары, аккордеон разделов, поля и таблицы рисует ДС; в
`DealFinancialMetricsModal.css` — подложки, раскладка баров и карточек, колонки
таблиц.

Значения приходят из метрик сделки
(`apps/postrade/deals-app/data/mock-financial-metrics.js`,
`DealFinancialMetricsRsDto`). `DealFinancialMetricsModal.js` перерисовывает окно
при каждом открытии; бары рисует функция тайла
(`PostTileDealFinMetrics.albarHTML`) — бар ВБС в тайле и в окне один.

## Раскладка (Layout)

```
Modal (заголовок, IconButton «Закрыть» в шапке)
└── тело, сверху вниз как на макете
    ├── 1. ВБС и ОСЗ — два AllocationBar рядом, поровну, каждый на подложке (`--bg-page`)
    ├── 2. Резервы на {дата} — Tile Accordion с частичным коллапсом (сводка видна всегда,
    │   таблица раскрывается шевроном в шапке), свёрнут при открытии
    ├── 3. Переоценка по PE — тот же Tile Accordion, свёрнут при открытии
    └── Подвал — одна кнопка «Закрыть» справа, `btn--outline`
```

Итог над баром — сумма значений строк; строки — колонки 50 / 20 / 30% (AllocationBar 1.003).
При каждом открытии окна разделы свёрнуты — так на макете. ОСЗ нет в ответе — пустой бар ДС
(«—» и «Нет данных»), а не пропавшая подложка. Раздел «Переоценка по PE» есть только у сделки
с Private Equity (`data-pe` на `.modal`): без PE раздела нет совсем (решение человека
25.09.2026) — пустой раздел читался бы как «переоценки нет», а у сделки без PE её не бывает.

## Поля (Fields)

| Поле | Чем собрано | Источник |
|---|---|---|
| ВБС | AllocationBar, подпись «ВБС по сделке на {дата}, RUB» | `vbs` |
| ОСЗ | AllocationBar, подпись «ОСЗ по сделке на {дата}, RUB» | `osz` |
| Резерв (карточка, шире других) | карточка с обычной рамкой `--border-primary`, своя «Дата расчета» | `reserves` |
| Обесценение (карточка) | карточка | `reserves` |
| RWA (карточка) | карточка | `reserves` |
| Таблица резервов по ФИ | Table ДС; ФИ — Link на страницу финансового инструмента | `reserves.instruments` |
| Сумма переоценки по PE | поле сводки | `peRevaluation` |
| Δ переоценки по PE | поле сводки, тон ReadOnlyField (зелёным при росте, красным при падении) | `peRevaluation` |
| Дата последней оценки | поле сводки | `peRevaluation` |
| Дата ближайшей оценки | поле сводки | `peRevaluation` |
| Таблица PE по ФИ | Table ДС; ФИ — Link | `peRevaluation.instruments` |

Позиции бара ВБС — продукты сделки, цвета постоянные по продукту (таблица в паспорте
тайла); ОСЗ — Основной долг (`--ch-indigo`), Проценты (`--ch-shiny-green`), Комиссии
(`--ch-light-blue`) — цвета с макета.

Сводка резервов — три карточки, у каждой своя «Дата расчета»: Резерв (шире других) — Сумма
резерва (RUB) + Ставка резерва (%), Обесценение — Ставка обесценения (%), RWA — RWA (%).
Подписи с пояснениями — те же тексты, что в тайле (паспорт тайла, «Поля»).

У ОСЗ два своих состояния:

- **рассчитывается** (`osz.calcStatus = CALCULATING`) — подпись без итога и плашка ДС
  «Данные рассчитываются / Это может занять несколько секунд» (первый вариант окна на
  макете);
- **просрочка** (`osz.overdueAmount > 0`) — сразу за подписью иконка
  `alert-triangle-filled` в тоне `--warning` с тултипом «Просроченная задолженность на
  сумму {сумма коротко} RUB» (второй и третий варианты; место иконки — AllocationBar
  1.003). Иконка в таб-порядке, тултип открывается и по фокусу. Начальный фокус окна — на
  крестике (`autofocus`): иначе рантайм Modal ставил его на иконку, и окно открывалось с
  поднятым тултипом (урок ДС Л149).

Таблица резервов по ФИ: ФИ | Сумма резерва | Ставка резерва | Ставка обесценения | RWA.
ФИ — Link ДС на страницу финансового инструмента (в прототипе её нет — `href="#"`). Числа
справа, единица — постфиксом ячейки.

Таблица PE по ФИ: Финансовый инструмент (Link) | Дата оценки | Периодичность | Оценка на
дату (RUB) | Δ переоценки (со знаком, зелёным / красным) | Кем определена. Подписи
периодичности и оценщика — по кодам из `DEAL_FIN_METRICS_LABELS`.

Таблицы обоих разделов — Table ДС: полоса прокрутки тела — бегунок, в покое скрыт
(Table 1.019), суммы в ячейках не переносятся, а усекаются с тултипом (TableCell 2.023).

Equity или нет, число строк в баре ВБС (1–5, 7), ОСЗ рассчитывается,

`PostDealFinMetricsModal.render`, та же, что на странице сделки.

## Обязательность заполнения (Required)

- Окно обязательно к заполнению целиком: не применимо — метрики считает система, править их
  негде и некому.
- Обязательные поля внутри: не применимо.

## Переполнение (Overflow)

| Случай | Правило |
|---|---|
| Много продуктов в ВБС | как в тайле: пять строк и «Показать ещё N» (AllocationBar) |
| Много ФИ в таблице | строки идут подряд, тело окна прокручивается (Modal); шапка и подвал окна на месте |
| Колонки таблицы шире окна | горизонтальный скролл тела таблицы, бегунок ДС (Table 1.019) |
| Длинная сумма в ячейке | одна строка, многоточие, полное значение тултипом (TableCell 2.023) |
| Длинное имя ФИ, оценщика, периодичности | усечение с троеточием в ячейке, полный текст — тултипом (TableCell) |
| Узкая ширина | окно фиксированной ширины `modal--w7`; подписи баров и полей усекаются внутри своих колонок |

## Открытые вопросы (Open questions)

1. Владелец окна — `не решено (25.09.2026)`.
2. Кто видит ОСЗ — `не решено (25.09.2026)`.
3. Коды и цвета частей ОСЗ (`PRINCIPAL`, `INTEREST`, `COMMISSIONS`) названы в
   прототипе; цвета — с макета, в доменном маппинге спеки AllocationBar их нет.
4. Плашка «Данные рассчитываются» в ДС залита `--bg-page` — тем же, что
   подложка бара, и на подложке пропадает. В CSS окна она внутри подложки
   залита `--cgrey-100` (ближайший к макету токен) — до правки ДС.
5. Подложка бара и подложка раздела — своего компонента в ДС нет, собраны на
   токенах (`--bg-page`, `--radius-m`). Карточки сводки резервов — рамка
   `--border-primary` на подложке; Card ДС не подошла: у неё свои интерактивные
   состояния, а карточки не нажимаются.
6. Тон текста в ячейке таблицы (Δ зелёным / красным) — у TableCell его нет,
   цвет задан классом окна на токенах `--success-dark` / `--error-dark`, как у
   ReadOnlyField.
7. Ссылка ФИ ведёт на страницу финансового инструмента — в прототипе её нет,
   `href="#"`.
8. В ДС нет правила для ячейки-ссылки таблицы — стоит Link ДС внутри ячейки.
9. Привязка к данным — следующий шаг, как у тайла (паспорт тайла, «Открытые
   вопросы»).

Закрыт 25.09.2026 правкой ДС: иконка просрочки стоит сразу за подписью ОСЗ,
как на макете (AllocationBar 1.003).
