# Окно «ФИ — изменение» (DealFinancialInstrumentEditModal)

## Описание (Purpose)

Артефакт тайла «Финансовые инструменты»: правка собственных параметров карточки ФИ.
Заголовок — «ФИ: <номер>. <тип>» («ФИ: 1. Кредит»). Состав полей зависит от типа ФИ — его
задаёт стор (`FinInstrumentsStore.fieldsOf`), окно только прячет лишнее:

| Тип ФИ | Поля |
|---|---|
| Кредит | наименование, контрагент, FV/AC, контрагент для целей резервирования, контрагент для аллокации финансового результата, «Участие ДККК» |
| Акции | то же + IRR (рядом с FV/AC), «Private Equity», «Связанный безусловный опцион» |
| Доп. доходность, РЕПО | то же, что у кредита + «Номер связанного договора», «Опцион включенный в расчет МСФО» |
| Дебиторская задолженность | то же, что у кредита + IRR |

Баланс, валюта, суммы и даты окно не правит: они приходят из узлов дерева продуктов,
прикреплённых к карточке. Тип ФИ и тип отчётности задаются при создании и здесь не меняются
(на макете их в окне нет).

Окно только правки; открывается временным пунктом «Изменить» меню карточки — состав меню не
решён (02.10.2026). Поля собраны общим слоем `PostFinInstrumentForm` окна создания ФИ.


## Поля

| Поле | Смысл | Тип | Источник | Обязательное |
|---|---|---|---|---|
| `name` | наименование ФИ | строка | карточка ФИ | да |
| `counterpartyId` | контрагент | список: база контрагентов, участники сделки первыми | `FinInstrumentsStore.counterpartyOptions()` (допущение агента — из кого выбирают, не решено) | нет |
| `fvAcCode` | FV/AC | список `FIN_INSTRUMENT_FV_AC_LABELS` | `fvAcOptions()` | нет |
| `targetIrr` | IRR, % | число: цифры и одна запятая | карточка ФИ (акции, ДЗ) | нет |
| `reserveCounterpartyId` | контрагент для целей резервирования | список, как у контрагента | `counterpartyOptions()` | нет |
| `allocationCounterpartyId` | контрагент для аллокации финансового результата | список, как у контрагента | `counterpartyOptions()` | нет |
| `linkedContractNumber` | номер связанного договора | строка | карточка ФИ (доп. доходность, РЕПО) | нет |
| `ifrsOptionNodeId` | опцион, включённый в расчёт МСФО | список: «Пут: РЕПО» и «Колл: РЕПО» дерева сделки, «номер название» | `optionNodes()` | нет |
| `isPE` | Private Equity | чекбокс | карточка ФИ (акции) | нет |
| `isDkkk` | участие ДККК | чекбокс | карточка ФИ | нет |
| `hasLinkedUnconditionalOption` | связанный безусловный опцион | чекбокс | карточка ФИ (акции) | нет |

Поля чужого типа стор при сохранении сбрасывает: значение, которого у типа нет, в карточке не
живёт.

### Скрипт окна

`DealFinancialInstrumentEditModal.js`, глобал `PostModalFinInstrumentEdit`:

| Функция | Что делает |
|---|---|
| `open(id)` | заполнить по карточке и открыть |

«Сохранить» — `FinInstrumentsStore.update(id, поля типа)` и `commit`.

## Открытые вопросы (Open questions)

1. **Откуда открывается окно** — пункт «Изменить» меню карточки временный: что делают действия
   карточки, человек опишет позже (02.10.2026).
2. **Из кого выбирают контрагентов** — база контрагентов, участники сделки первыми; допущение
   агента (02.10.2026): у демо-сделок участник один.
3. **Справочник FV/AC** — в окне «FV», на карточке «Инвестиции в АК»; пока коды FV и AC
   (02.10.2026).
4. **Наименование в окне** — на макете «1. Кредит», а у карточки «1-Кредит-199»; окно правит
   то наименование, что показывает карточка (02.10.2026).
5. **Опцион МСФО** — в списке «Пут: РЕПО» и «Колл: РЕПО» всего дерева сделки, а не только
   прикреплённые к этой карточке; допущение агента (02.10.2026).
6. **Проверки IRR** — только формат числа; диапазон не задан (02.10.2026).
