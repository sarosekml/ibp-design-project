# Widget: DealDescriptionModal — Модальное окно описания сделки

## Описание (Purpose)

Артефакт тайла «Описание сделки». Не компонент: сам по себе не существует и в
плоском списке кита не числится — живёт подпунктом своего тайла.

Одно окно на два режима. В правке — всё, что показывает тайл, плюс
дополнительные доходы: их тайл не показывает. В просмотре окно — место, где
длинное описание и комментарий читаются целиком, без усечения тайла.

Ширина — `modal--w7` (1053px на 1920), ровно ширина макета. Две колонки с
вертикальным разделителем в пропорции 7 : 3 — с макета.

## Раскладка (Layout)

```
Modal w7 «Описание сделки»
├── тело: две колонки + Divider vertical
│   ├── слева: Суть сделки · Комментарий Operations · Дополнительные доходы · Группа связанных заемщиков
│   └── справа: Участие ЦЭ · Участие Деска ИФ · Реструктуризация · Совместность · Категория риска ЦУП · Фин. расчеты в Excel
└── подвал: «Сохранить» (правка) | «Закрыть» (просмотр)
```

## Права (Permissions)

Окно роль не вычисляет: режим приходит с тайла, который его открыл
(`data-mode` тайла → `data-mode` модалки). Матрица ролей — в паспорте тайла.

## Состояния (States)

| Состояние | Есть в продукте | Вид |
|---|---|---|
| Правка | да | поля ввода со значениями сделки, подвал «Сохранить» |
| Только просмотр | да | те же поля в том же порядке как ReadOnlyField (прочерк у пустого), признаки — выключенные чекбоксы, подвал с аутлайновой «Закрыть» |
| Ошибка ввода | да | значение списка, набранное руками и не найденное в справочнике: поле `inp--error`, под ним «Выберите значение из списка»; окно не закрывается, фокус — на первое поле с ошибкой |
| Загрузка | нет | окно заполняется из записи сделки, уже загруженной страницей |
| Сохранение (Обновление) | не решено (24.09.2026) | запись сделки в прототипе мгновенная, в памяти вкладки |

## Проверка и сохранение

- Обязательных полей нет: окно сохраняет любой набор, в том числе пустой — тайл
  тогда встаёт в «Данных нет».
- Значение списка — только из справочника. Пустое допустимо.
- «Сохранить» закрывает окно само, когда проверка прошла; крестик и Esc закрывают
  без сохранения, клик мимо окна в правке не закрывает (`data-modal-guarded`).
- Правка уходит странице одним патчем (`opts.save`), страница пишет его в
  `DealsStore`, тайл и поповер «Связанные сделки» перерисовываются по событию
  стора.

## Связанные артефакты (Behavior)

| Триггер | Тип | Что меняется после |
|---|---|---|
| «Сохранить» | закрытие окна | новые значения в записи сделки и в тайле; фокус — на кнопку, открывшую окно |
| Крестик, Esc, «Закрыть» | закрытие окна | ничего |
