# Окно «Перенос инструмента» (InstrumentTransferModal)

## Описание (Purpose)

Окно переноса инструмента в другой подходящий продукт или продукт ДИД этой же сделки
(ответ человека 30.09.2026, 3). Открывается пунктом «Перенести» в меню инструмента в тайле
«Продукты сделки». Транш перенести нельзя — у него пункта нет.

- Пояснение: «Выберите продукт, в который вы хотите переместить 1.1.1. Договор займа» —
  номер и название инструмента.
- «Откуда» — продукт ДИД и продукт, где инструмент сейчас; строка продукта выключена.
- «Куда» — все продукты ДИД сделки и их продукты. Текущий продукт и продукты, в состав
  которых тип инструмента не входит, выключены; подходящим может быть продукт другого
  продукта ДИД (правило — допущение агента, вопрос 41 задачи). Строка продукта ДИД
  сворачивается шевроном справа.
- Клик по доступному продукту выбирает его: подложка и зелёная рамка (состояние ProductRow
  «выбрана», как на макете). Выбрать можно один продукт; клик по другому переносит выбор.
- «Сохранить» становится доступна после выбора. Во время сохранения — индикатор на кнопке.
  Инструмент уходит в выбранный продукт вместе с траншами и связью с ФИ, номера в дереве
  пересчитываются, правка сохраняется.

Крестик, Esc и клик по подложке закрывают окно без изменений.

Место на странице задаёт страница: скрим вшивается отдельной меткой `<ds-include>` в конце
`body`.

## Раскладка (Layout)

```
Modal modal--w4 (595px — ширина макета), высота по контенту, тело прокручивается
├── шапка: «Перенос инструмента» + крестик
├── тело
│   ├── пояснение Body M --text-secondary
│   ├── «Откуда» (H6 Strong) — продукт ДИД (корневая строка, шеврон справа) и продукт (выключен)
│   └── «Куда» (H6 Strong) — продукты ДИД (корневые строки) и их продукты (радиокнопки)
└── подвал справа: Button accent M «Сохранить»
```

## Обязательность заполнения

- Выбор продукта обязателен: без него «Сохранить» недоступна.
- Что отдаёт наружу: инструмент в новом продукте; производные поля записи сделки
  пересчитываются и сохраняются.

### Скрипт окна

`InstrumentTransferModal.js`, глобал `PostModalInstrumentTransfer`:

| Функция | Что делает |
|---|---|
| `open(instrumentId)` | открыть окно для инструмента |
| `use(instrumentId)` | нарисовать без открытия — для витрины |
| `listHTML(targets, section)` | разметка «Откуда» (`from`) и «Куда» (`to`) из `ProductTreeStore.moveTargets` |
| `select(productId)` | выбрать продукт — для витрины |
| `mirror(scrim)` | `data-state="updating"` → `.modal--saving` и `btn--loading` |

Выбор — радиогруппа: клик, Пробел и Enter выбирают строку, стрелки переходят по доступным
строкам; в порядке Tab — выбранная (или первая доступная). «Сохранить» —
`ProductTreeStore.moveInstrument(id, productId)` и `commit`.
