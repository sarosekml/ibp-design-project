# Widget: CounterpartiesEcmModal — Модальное окно «Документы по сделке»

## Описание (Purpose)

Артефакт тайла «Описание сделки». Документы ЭКД ведутся по контрагенту, поэтому
просмотр идёт в два шага, двумя окнами одного сценария — оба с заголовком
«Документы по сделке»:

1. **Выбор участника** (`CounterpartiesEcmModal.html`) — «Выберите участника
   сделки» и карточки участников. Выбранная карточка подсвечена, «Открыть»
   недоступна, пока участник не выбран.
2. **Документы** (подчасть окна — `EcmModal/EcmModal.html`, свой скрим) — полное
   наименование участника и его документы. «К списку контрагентов» возвращает к
   первому шагу с тем же выбором.

Паспорт общий для обоих шагов — подчасть отдельного паспорта не получает, как
окно подтверждения в окне «КНР».

## Раскладка (Layout)

```
Modal w4 «Документы по сделке»
├── тело: «Выберите участника сделки» (H6 Strong) · стопка карточек CounterpartyCard (select), зазор 8
└── подвал справа: «Открыть» (accent, недоступна без выбора)

Modal w8 «Документы по сделке»
├── тело: наименование участника (H6 Strong) · документы (в прототипе — EmptyState)
└── подвал: слева «К списку контрагентов» (transparent, иконка arrow-left слева) · справа «Закрыть» (outline)
```

## Поля (Fields)

Карточка показывает то же, что в окне «КНР» у участника сделки: наименование,
сабхедер, реквизиты (состав у разных контрагентов разный), ГСЗ, контакты физлица,
риск-метрику. Источник — `CounterpartiesStore.members()`, участники текущей сделки;
окно перечитывает состав при каждом открытии, поэтому правка в окне «КНР» видна
сразу. Паспорт полей — `CounterpartyCard.md`.

## Права (Permissions)

Окно открывается в обоих режимах тайла: смотреть документы — не правка. Кому
документы ЭКД недоступны — `не решено (24.09.2026)`.

## Состояния (States)

| Состояние | Есть в продукте | Вид |
|---|---|---|
| Загрузка | да | состав сделки ещё читается (`data/API.md`) — каркас двух карточек; «Открыть» недоступна |
| Данные есть, выбора нет | да | карточки, «Открыть» недоступна (макет, первый кадр) |
| Участник выбран | да | карточка в состоянии Selected, «Открыть» доступна (макет, второй кадр) |
| Данных нет | да | строка «У сделки пока нет участников — документы смотреть не по кому» серым Body M; «Открыть» недоступна. Действия нет: состав правят в окне «КНР» |
| Документы | да | второе окно: наименование участника и пустое состояние «Просмотр документов» — в прототипе просмотра нет (макет, третий кадр) |
| Ошибка | не решено (24.09.2026) | |

## Обязательность заполнения (Required)

- Окно обязательно к заполнению целиком: не применимо — окно только для просмотра документов.
- Обязательные поля внутри: нет — «Открыть» доступна только после выбора участника, но сам
  выбор никуда не сохраняется.
- Что показывает, когда обязательное не заполнено: не применимо.
- Что отдаёт наружу: ничего — окно данных не меняет.

## Переполнение (Overflow)

| Случай | Правило |
|---|---|

| Узкая ширина | не встречается: ширина фиксирована шагом ДС (`modal--w4` — выбор, `modal--w8` — документы) |
| Полная ширина | — |

## Поведение (Behavior)

### Поведение выбора

- Список — `role="radiogroup"`, карточка — `role="radio"` с `aria-checked`.
- Выбор — клик по карточке, Enter или Space на ней; стрелки переводят выбор на
  соседнюю карточку. В порядке Tab одна карточка — выбранная, без выбора первая.
- Клик по чипу риск-метрики открывает её поповер и выбора не делает.

### Связанные артефакты

| Триггер | Что меняется после |
|---|---|
| «Открыть» | первое окно закрывается, открывается второе с наименованием участника |
| «К списку контрагентов» | второе окно закрывается, первое открывается с тем же выбором |
| Крестик, Esc, «Закрыть», клик мимо окна | окно закрывается, в данных ничего не меняется |
