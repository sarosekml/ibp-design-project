# Описание сделки — журнал изменений

Формат записи: что изменилось · почему · по какому требованию.

## Поповер 1.002 · окно «Документы по сделке» 1.002 — 27.09.2026

**Сняты классы без стилей** — `lc-related-deals` у корня поповера «Связанные сделки» и
`lc-deal-ecm-docs` у второго шага окна «Документы по сделке» (`EcmModal.html`). Они ничего
не оформляли, скрипты по ним ничего не ищут. *Почему:* сенсор экрана с 26.09.2026 читает CSS
тайлов из подключённых файлов, и классы, которых нет ни в одном CSS, помечает как ошибку
(Б4). *Требование:* решение человека 27.09.2026. Тайл остаётся 1.003, вид не изменился.

## 1.003 — 25.09.2026

**Кнопка «Заполнить» в пустом состоянии — размер S** (`btn--s`, 32px), была M
(`btn--m`, 40px). *Почему:* кнопки в контенте Tile — размер S, если макет или ТЗ не
задают иное; M — размер кнопок модальных окон (правило Tile, 25.09.2026). *Требование:*
решение человека 25.09.2026.

## 1.002 — 25.09.2026

**Признаки разложены по колонкам заново:** 1 — Категория риска ЦУП, Фин.расчеты в
шаблоне; 2 — Совместность, Реструктуризация; 3 — Участие Деска ИФ, Участие ЦЭ.
«Связанные сделки», когда они есть, — третьей строкой первой колонки. На макете было
3 + 2 + 2 (ЦЭ и Деск ИФ в первой колонке, связанные сделки во второй). *Требование:*
решение человека 25.09.2026.

## 1.001 — 25.09.2026

Правки после первого показа. *Требование:* решения человека 25.09.2026, референс
`refs/описание/Документы по сделке (ЭКД).png` модуля и экран текущей системы со списками
«Совместности» и «Категории риска ЦУП».

- **«Связанные сделки» без связанных сделок не показываются вовсе** — строка признака
  прячется атрибутом `hidden`; раньше была строкой без ссылки с пустым кругом. *Почему:*
  человек — «пункт не может быть пустым».
- **Признаки — в две колонки от 720px ширины тайла** (было от 590px — на реальной
  странице порог почти не срабатывал). *Почему:* на экранах 1366–1680 три колонки по
  ≈190px переносили подписи; человек попросил две колонки на меньших экранах.
- **Зазор между «Документы ЭКД по сделке» и карандашом — 12px** — правка Tile в ДС
  (1.015), у тайла своего правила нет.
- **Справочники:** «Совместность» — 11 кодов территориальных банков в порядке текущей
  системы, полные имена хелпером в окне; «Категория риска ЦУП» в окне — «Не определена»,
  «Категория A» … «Категория D». Текст признака в тайле прежний («Категория риска ЦУП: C»).
- **Поповер «Связанные сделки»** — ширина M, без подвала, список ссылок «№ · наименование»
  вместо таблицы.
- **Окна «Документы по сделке»** — по макету: участник карточкой контрагента (режим
  `select` у `CounterpartyCard`, выбранная — Selected у Card из ДС 1.015), «Открыть»; во
  втором окне «К списку контрагентов» со стрелкой слева в подвале, «Закрыть» аутлайновая
  справа.

## 1.000 — 24.09.2026

Компонент наполнен: из заглушки («Данные ещё не заведены») стал тайлом со всеми
состояниями и тремя связанными артефактами. *Требование:* макеты
`refs/описание/` модуля — `Tile-Deal-Description.png` (четыре состояния тайла),
`Section 1.png` (пояснения к признакам), `Modal_Tile_Deal_Description.png` (окно
правки); решения человека 24.09.2026.

**Тайл (1.000)**
- **Состав полей закрыт.** Суть сделки, комментарий Operations, семь признаков на
  подложке, группа связанных заемщиков. *Почему:* до 24.09.2026 состав стоял как
  `не решено (19.09.2026)`; макет его назвал.
- **Признаки — текст с иконкой на подложке, своей разметкой на токенах.** *Почему:*
  решение человека 24.09.2026 — это не компонент ДС, а подложка — окрашенный
  контейнер со скруглением. Тон иконки несёт категорию риска ЦУП (A — error,
  B — warning, C — success, D — тёмный) и признак «Фин.расчеты в шаблоне»
  (warning).
- **Пустое состояние как на макете:** «Заполнить» в правке, «Не заполнено» в
  просмотре; «Документы ЭКД по сделке» в шапке остаётся. Строка-заглушка по
  центру снята.
- **Четыре состояния данных** (`loading`, `data`, `partial`, `empty`) и два режима
  прав — разметка держит все сразу, CSS показывает нужное.
- **Скрипт** `DealDescriptionTile.js` (`PostTileDealDescription`) раскладывает
  запись сделки по местам, не пересоздавая разметку, — триггер поповера
  переживает перерисовку.

**Артефакты**
- Окно правки и просмотра `widgets/modals/DealDescriptionModal/` — по макету, две
  колонки с разделителем.
- Окно «Участники сделки» → «Документы ЭКД»
  `widgets/modals/CounterpartiesEcmModal/` (+ подчасть `EcmModal/`) — без макета,
  на компонентах ДС (решение человека 24.09.2026).
- Поповер `widgets/popovers/RelatedDealsPopover/` — вместо окна, по решению
  человека 24.09.2026.

**Данные**
- `jointness` («Совместность») — теперь краткое имя территориального банка, а не
  «Совместная» / «Не совместная». *Почему:* макет тайла показывает «Совместность:
  МБ» и поясняет значение как банк. Фильтр портфеля берёт варианты из того же
  справочника.
- Новые поля записи сделки — typedef `DealDescriptionFields` в `data/mock-deals.js`.
