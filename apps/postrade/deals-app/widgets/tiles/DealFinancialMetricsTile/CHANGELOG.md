# Финансовые метрики сделки — журнал изменений

Формат записи: что изменилось · почему · по какому требованию.

## 1.003 — 04.10.2026

**Плашка «Переоценка по PE» залита `--tertiary-bg-light` (полупрозрачная, 4 %).**
*Почему:* светлая заливка с альфа-каналом, как в legacy, и менее светлая (решение человека
04.10.2026). В legacy цвет близок к прежнему. *Требование:* задача RE0010 (пост-приёмка).

## Паспорт — 04.10.2026

**В паспорте обновлён раздел «Данные».** Виджет не менялся. *Почему:* метрики сделок
целевых статусов теперь собираются по прикреплённым карточкам ФИ (`mock-deal-trees.js`),
а не из фиктивных ФИ демо-файла; открытый вопрос №7 закрыт в мок-части. *Требование:*
решение человека 04.10.2026.

## Паспорт — 02.10.2026

**Паспорт приведён к правилам 2.000.** Виджет не менялся. *Почему:* один канон разделов
паспорта для всех локальных компонентов — 13 разделов шаблона ДС. *Требование:* задача

## 1.002 — 27.09.2026

Тайл и окно `DealFinancialMetricsModal` (1.002). **Сняты классы без стилей.** *Почему:*
сенсор экрана с 26.09.2026 читает CSS тайлов из подключённых файлов, и классы, которых нет
ни в одном CSS, помечает как ошибку (Б4). *Требование:* решение человека 27.09.2026.

- **Хост бара в тайле** — атрибут `data-fin-bar="vbs"` вместо класса `lc-deal-metrics__vbs`,
  как у баров окна. По нему `DealFinancialMetricsTile.js` находит, куда рисовать бар.
- **Таблицы окна** — без класса `lc-deal-metrics-modal__table`: он ничего не оформлял.
- Вид тайла и окна не изменился.

## 1.001 — 25.09.2026

Правки человека после просмотра первой сборки. *Требование:* решения человека 25.09.2026.

- **Итог над баром — сумма строк.** Поле итога убрано из данных (`AllocationRsDto`),
  итог считает `DealFinancialMetricsTile.js`. *Почему:* «значение над баром — сумма
  всех значений каждой строки»; у итога один источник.
- **Бар по новому AllocationBar 1.003:** строки во всю ширину, колонки 50 / 20 / 30%,
  значения друг под другом, иконка просрочки сразу за подписью. Правки сделаны в ДС,
  локальная пара `[hidden]` для строк снята — она теперь в ДС. У имени позиции снят
  `title`: полное имя при усечении показывает тултип ДС.
- **Окно:** начальный фокус — на крестике (`autofocus`), тултип просрочки больше не
  поднимается при открытии; рамка карточек сводки — `--border-primary`; разделы
  сворачиваются при открытии, а не при каждой отрисовке. Таблицы — полоса прокрутки
  и усечение сумм из ДС (Table 1.019, TableCell 2.023).
- **Витрина:** у окна — «Конструктор» с переключателями (PE, строки ВБС, ОСЗ
  рассчитывается, знак Δ, просрочка); у тайла — переключатель «Δ переоценки
  отрицательная».
- **Источник значений записан:** метрики складываются из финансовых инструментов
  сделки; в прототипе — демо-данные, привязка к бэкенду и мок-данным ФИ — позже.
