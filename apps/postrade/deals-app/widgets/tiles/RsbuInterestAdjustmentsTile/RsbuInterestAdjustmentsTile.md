# Корректировки процентов РСБУ

## Описание (Purpose)

Тайл страницы транша. Показывает, внесены ли ручные корректировки процентов РСБУ,
и ведёт на страницу `RsbuInterestAdjustments.html`, где их смотрят и правят.
Корректировка — сумма, которая прибавляется или вычитается начиная с начальной даты
(одной из дат процентных платежей). Пока процентные платежи не рассчитаны, вносить
нечего — тайл просит расчёт.

Место на странице и ширину в колонках задаёт экран (`pages/Tranche.html`), не компонент.
Число корректировок экран берёт из `data/tranche-data.js` (`MOCK_RSBU_ADJUSTMENTS`).

## Раскладка (Layout)

```
Tile (заголовок «Корректировки процентов РСБУ»)
├── шапка: IconButton arrow-right → страница корректировок (кроме locked)
└── тело
    ├── текст по виду: «Требуется расчёт…» / «Корректировки отсутствуют» / «Внесено корректировок: N»
    └── кнопка «Внести корректировку» (none, filled)
```

## Поведение (Behavior)

- Стрелка в шапке → страница `RsbuInterestAdjustments.html` (в `locked` стрелки нет).
- «Внести корректировку» → та же страница с `?open=add`, окно добавления открывается сразу.

### Связанные артефакты

Окно внесения корректировки — [RsbuAdjustmentModal.md](../../modals/RsbuAdjustmentModal/RsbuAdjustmentModal.md).
Сам тайл окно не открывает: он ведёт на страницу корректировок (`?open=add` для кнопки
«Внести корректировку»), а страница поднимает это окно.
