# Page: FinInstrument — Финансовый инструмент

## 1. Назначение (Purpose)

Страница одного финансового инструмента (ФИ) сделки: данные по ФИ, прикреплённые
инструменты дерева продуктов, идентификаторы и переходы в подразделы. Пользователь
попадает сюда стрелкой «→» в шапке карточки ФИ на странице сделки и возвращается
кнопкой «В сделку».

Собрана **по макету, без локальных компонентов**: тайлы собраны прямо на странице
из компонентов ДС и помечены Chip «Demo» в шапке. Локальные компоненты — следующий
шаг (решение человека 09.10.2026).

**Роль пользователя:** финансист ДИД
**Права:** как на странице сделки; правка данных ФИ — окном изменения ФИ.

## 2. Адрес и навигация (Route)

- **Адрес в продукте:** не решено (09.10.2026) — вопрос 1.
- **Параметры прототипа:** `FinInstrument.html?id=<номер сделки>&fi=<id карточки ФИ>`;
  без параметров — первая сделка с карточками и её первая карточка.
- **Пункт бокового меню** в состоянии `nav__item--selected`: «Текущий портфель».

| Уровень крошек | Текст | Ссылка |
|---|---|---|
| 1 | Текущий портфель ДИД | `Portfolio.html` |
| 2 | `<номер>. <наименование сделки>` | `Deal.html?id=<номер>` |
| 3 (текущий) | ФИ: `<наименование ФИ>` | — |

## 3. Раскладка (Layout)

```

├── PageHeader            — «ФИ: <наименование>», «В сделку», кнопка «Ещё действия»
└── «Общая информация»
    ├── ряд 1:  Данные по ФИ (6) · Инструменты ФИ (3) · Корректировки KPI (3)
```

| № | Блок | Компонент | Колонок из 12 | Содержимое |

| 1 | Данные по ФИ | Tile + ReadOnlyField | 6 (`colw-12`) | наименование, баланс, валюта, тип отчётности, FV/AC, целевой IRR (акции), сумма по типу ФИ, дата подписания, плановая дата погашения, три контрагента с риск-метрикой, признаки ДККК и опциона; чип «Требуется переоценка» в шапке |
| 2 | Инструменты ФИ | Tile + ProductRow | 3 (`colw-6`) | прикреплённые узлы дерева продуктов: номер и название, дата подписания, сумма |

| 5 | Дефолтные сделки | Tile | 3 (`colw-6`) | как блок 3 |

у тайла нет локального компонента, разметка собрана на странице.

Вертикальный скролл есть, горизонтального нет.

## 5. Поведение (Behavior)

| Триггер | Результат |
|---|---|
| «→» в шапке карточки ФИ на странице сделки | открывается эта страница с `id` и `fi` |
| «В сделку», крошка сделки | страница сделки `Deal.html?id=<номер>` |
| Карандаш «Данные по ФИ» | окно изменения ФИ; после «Сохранить» тайлы перерисовываются по событию `commit` стора |
| Стрелки у «Корректировки KPI», «Дефолтные сделки», «Счета для 1С»; карандаш «ID ФИ»; кнопка «Ещё действия» | нарисованы по макету, ничего не делают — вопрос 3 |

## 6. Состояния (States)

Состояния данных не прорабатывались: страница показывает данные сразу после
загрузки сторов. Нет карточки — пустой каркас. Незаполненные значения — прочерк `—`.
Загрузка, ошибка и права по ролям — следующий шаг вместе с локальными компонентами.

Поля карточки ФИ — те же, что в `FinInstrumentCardRsDto` (`data/mock-fin-instruments.js`);
блок «ID ФИ» и подразделы — `FinInstrumentDetailsRsDto` (`invented`, 09.10.2026).

| Поле | Тип | Смысл |
|---|---|---|

| `sections[].isFilled` | boolean | подраздел заполнен |
