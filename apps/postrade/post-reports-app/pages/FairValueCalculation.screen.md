# Page: FairValueCalculation — Расчет FV

## 1. Назначение (Purpose)

Расчет справедливой стоимости на дату: список финансовых инструментов (ФИ) с их
статусами, значениями и файлами инструментов. Отсюда отправляют расчет в Loan
Pricing (LP), обновляют и пересчитывают его, утверждают, выгружают в XML и xlsx,
переходят к правке отдельного ФИ. Попадают сюда из реестра расчетов FV двойным
кликом по строке.

**Роль пользователя:** «Финансист и другие» и «Риск-менеджер». Риск-менеджеру
дополнительно доступна кнопка «Утвердить».
**Права:** остальные действия одинаковы для обеих ролей — не решено (08.10.2026).

## 6. Поведение (Behavior)

Правила «статус расчета × роль → кнопки, меню, массовые действия» хранятся один раз — в
`window.FV_CALCULATION_ACTIONS` (`../data/fv-dictionaries.js`); экран и эта спека не копируют матрицу.

| Статус расчета | «Отправить в LP» | «Утвердить» | Меню «⋮» |
|---|---|---|---|
| Формируется | нет, всё выключено | нет | пусто, кнопка выключена |
| Сформирован | есть; выключена, пока нет ФИ «Сформирован» с отметкой «Передавать в LP» | нет | Обновить · Пересчитать · Выгрузить в XML · Выгрузить в xlsx |
| Отправлен в LP, Рассчитывается LP | нет | нет | Обновить · XML · xlsx |
| Рассчитан | есть, включена (повторная отправка) | риск-менеджер | Обновить · XML · xlsx |
| Ошибка | нет | нет | Пересчитать · XML · xlsx |
| Утвержден | нет | нет | Пересчитать · XML · xlsx |

| Триггер | Результат |
|---|---|
| Чип статуса в шапке («Отправлен в LP», «Рассчитывается LP») | демо-триггер: имитирует ответ LP. «Отправлен в LP» → «Рассчитывается LP» → «Рассчитан» (ФИ и инструменты из отправки двигаются вместе, у «Рассчитан» появляются суммы FV). Чип фокусируется и срабатывает по клику, Enter и пробелу; тултип объясняет, что это демо |
| «Отправить в LP» | окно «Отправка данных в Loan Pricing»; после «Подтвердить» ФИ «Сформирован» с отметкой «Передавать в LP» → «Отправлен в LP», расчет → «Отправлен в LP»; нет таких ФИ — снекбар «Нет данных для отправки в LP» |
| «Утвердить» | окно «Утверждение расчета FV на ДД.ММ.ГГГГ»; после «Подтвердить» расчет → «Утвержден» |
| «⋮» → «Обновить» | окно «Обновление данных расчета…»; новые ФИ придут «Сформирован», текущие не меняются; в демо новых ФИ нет — снекбар «Расчет обновлен» |
| «⋮» → «Пересчитать» | окно «Пересчет расчета…»; все ФИ и инструменты → «Сформирован», расчет → «Формируется», через 2 с (прототип) → «Сформирован» |
| «⋮» → «Выгрузить в XML / xlsx» | `DownloadReportModal`: сеть Сигма — окно «Выгрузка расчета на ДД.ММ.ГГГГ» с выбором сотрудников и «Выгрузить»; сеть Альфа — «Подтверждение действия» с «Подтвердить». Ошибка (`?download=fail`) — снекбар «Не удалось выгрузить файл» |
| Чекбоксы строк | над пагинацией появляется панель «Выбрано строк: N» с кнопками: «Пересчитать», «Передавать в LP», «Не передавать в LP» (в «Утвержден» — только «Пересчитать»; в «Формируется» кнопки выключены) |
| «Пересчитать» в панели или в строке | окно «Пересчет выбранных ФИ» / «Пересчет ФИ «…»»; расчет → «Формируется», затем «Сформирован» |
| «Передавать в LP» / «Не передавать в LP» | окно подтверждения «Включение / Отключение передачи в LP для выбранных ФИ.»; после «Подтвердить» меняется колонка «Передавать в LP» у выбранных строк |
| Двойной клик по строке, клик по наименованию ФИ или по «Редактировать ФИ» | открывается `FairValueUserMetricsModal` (правка доступна в любом статусе расчета). После «Сохранить» с подтверждением или действия над файлом инструмента строка таблицы перерисовывается, выбор строк и шапка сохраняются |
| Выгрузка шаблона файла инструмента в окне ФИ | `DownloadReportModal` в виде «Подтверждение действия» (как окно без шифрования, сеть не важна), вложенным слоем поверх окна ФИ; ошибка (`?download=fail`) — Alert «Не удалось выгрузить файл» в окне ФИ |
| «Фильтр» → «Применить» | выборка по заполненным полям, чип «Применено: N» |
| Крестик на чипе «Применено» или «Очистить фильтр» | фильтр сбрасывается целиком |
| «Настроить колонки» (шестерёнка справа в тулбаре) | стандартное окно ДС «Настройка таблицы»: видимость, порядок и закрепление колонок; перерисованные строки повторяют текущую шапку |
| Клик по «Сортировать» | сортировка по колонке, страница сбрасывается на первую |

Счётчик раздела фильтра и чип «Применено» считают **заполненные поля** (решение человека 08.10.2026, вопрос 8).

## 8. Состояния (States)

### Loading
Не решено (08.10.2026): в прототипе данные есть сразу. Статус «Формируется» — отдельное состояние: кнопки и меню выключены.

### Empty
После «Применить» без совпадений — EmptyState «ФИ не найдены» с кнопкой «Очистить фильтр». Расчет без ФИ в макетах не нарисован — не решено (08.10.2026).
У ФИ без инструментов окно ФИ показывает в таблице строку «Нет данных».

### Error
Ошибка выгрузки всего расчета — снекбар «Не удалось выгрузить файл», файла инструмента — Alert в окне ФИ. «Нет данных для отправки в LP» — снекбар. ФИ с ошибкой — статус «Ошибка» в строке.

### Disabled
Статус «Формируется»: «Пересчитать» в строках и панели, меню «⋮» и «Отправить в LP» выключены.
