# Page: FairValueRegister — Реестр расчетов FV

## 1. Назначение (Purpose)

Список расчетов справедливой стоимости (FV) по датам. Отсюда формируют новый
расчет, загружают файлы FV и переходят на страницу расчета. Попадают сюда с
плитки «Расчет FV» на главной.

**Роль пользователя:** «Финансист и другие» и «Риск-менеджер» — реестр для них одинаков.
**Права:** формирование расчета и загрузка файлов доступны обеим ролям — не решено (08.10.2026).

## 5. Таблицы (Tables)

| Ключ | Заголовок | Тип | Ширина | Выравн. | Сортировка | В фильтре |
|---|---|---|---|---|---|---|
| `calculationId` | № | число | 96px | слева | да | нет |
| `formedDate` | Дата формирования | дата | 200px | слева | да | да, диапазон дат |
| `calculationDate` | Дата расчета | дата | 200px | слева | да | да, диапазон дат |
| `totalFvAmount` | Сумма FV, RUB | число | 220px | справа | да | да, диапазон сумм |
| `statusCode` | Статус | Chip | 220px | слева | нет | да, множественный выбор |

**Формат значений:** суммы — `3 900 500 000,00` с неразрывными разрядами; даты — `ДД.ММ.ГГГГ`;
пустое значение — прочерк `—`. Сумма FV есть только у «Рассчитан» и «Утвержден» (решение
человека 08.10.2026, вопрос 17).

**Статусы и тона чипов** — словарь `FV_STATUS_TONES` в `../data/fv-dictionaries.js`:
Формируется и Рассчитывается LP — серый, Сформирован — голубой, Отправлен в LP — оранжевый,
Рассчитан — фиолетовый, Утвержден — зелёный, Ошибка — красный. Везде «Утвержден», не
«Утвержден РМ» (вопрос 1).

## 6. Поведение (Behavior)

| Триггер | Результат |
|---|---|
| Клик «Новый расчет» | открывается `CreateFairValueCalculationModal`, поле даты пустое |
| «Сформировать» с новой датой | окно закрывается, строка появляется сверху со статусом «Формируется»; через 2 с (в прототипе) — «Сформирован» |
| «Сформировать» с датой, на которую расчет есть | окно остаётся открытым, над телом Alert «Не удалось сформировать расчет» |
| Меню «⋮» → «Загрузить FV» / «Загрузить компоненты FV» | открывается заглушка системного выбора файла (`upload-stub-scrim`); «Выбрать файл» закрывает её и открывает `ReservesFvModal` / `ReservesFvComponentsModal` с предпросмотром; «Отмена» предпросмотр не открывает |
| «Выбрать файл» при ошибке файла (демо `?file=format|empty|structure|size`) | окно предпросмотра не открывается, показывается снекбар с ошибкой: неверный формат, пустой файл, нет обязательных колонок, слишком большой файл |
| Клик по «Фильтр» | открывается окно фильтра |
| «Применить» | выборка по заполненным полям, чип «Применено: N», страница сбрасывается на первую |
| Крестик на чипе «Применено» или «Очистить фильтр» | фильтр сбрасывается целиком |
| Двойной клик по строке (номер — не ссылка) | страница расчета `FairValueCalculation.html?id=<номер>` ; у расчета в статусе «Формируется» переход закрыт — открыть можно после «Сформирован» |

Счётчик раздела «Основная информация» и чип «Применено» считают **заполненные поля**: пара «От/До»
— одно поле диапазона (вопрос 8 — «9» на макете признано ошибкой).
