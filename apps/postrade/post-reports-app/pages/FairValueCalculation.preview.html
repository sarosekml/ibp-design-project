    Выгрузка расчета
    
      
    
    

    
    
      
    
        
        
    
          
    Вы выгружаете документ, содержащий данные K2
    
          
    Нажимая кнопку «Выгрузить», вы подтверждаете, что осведомлены о следующих ограничениях:
    
          
      
            
    • данные только для внутреннего использования;
      • 
            
    • данные необходимо использовать строго в соответствии с бизнес-процессом;
      • 
            
    • данные нельзя передавать лицам, не задействованным в бизнес-процессе.
      • 
          
    
          
    Информация о выгрузке документа будет зафиксирована и направлена в службу безопасности.
    
        
    
      
    
    
    

    
    
      
    Выберите сотрудников, которым будет доступен файл после его создания. Данный файл будет доступен для работы в доменах Сигма и Альфа/ Омега только у указанных ниже сотрудников. Если вы добавили сотрудника по e-mail, то файл будет доступен только в том домене, которому соответствует e-mail.
