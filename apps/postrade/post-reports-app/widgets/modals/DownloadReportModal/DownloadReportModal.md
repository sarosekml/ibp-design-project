# Widget: DownloadReportModal — Выгрузка расчета FV

## Описание (Purpose)

Окно перед скачиванием файла с данными K2. В сети Сигма (внешний интернет) файл шифруется:
окно «Выгрузка расчета на ДД.ММ.ГГГГ» просит выбрать сотрудников, которым файл будет доступен.
В сети Альфа (внутренняя сеть банка) шифрования нет: окно «Подтверждение действия» только
предупреждает об ограничениях. Окно с шифрованием открывает только выгрузка расчета (XML, xlsx). Выгрузка шаблона файла инструмента из окна ФИ всегда идёт через окно «Подтверждение действия», сеть не важна.
шаблона файла инструмента из окна ФИ.

## Поведение (Behavior)

### Правила

1. Сеть — откуда пользователь входит в систему: Сигма (сеть банка с доступом в интернет) — окно с шифрованием; Альфа и Омега (внутренняя сеть банка без доступа в интернет) — окно подтверждения. В продукте сеть определяется автоматически по логину (на каждую сеть свой логин); в демо переключается на панели прототипа. По умолчанию Альфа; на странице — `?net=sigma`.
2. Изначально таблица пустая, «Выгрузить» выключена. Добавленные получатели остаются в таблице при следующих открытиях, пока открыта страница.
3. «Добавить» у «Сотрудника» включена после выбора из списка; повторно добавленный получатель не дублируется: его строка отмечается и подсвечивается. Enter в поле работает как «Добавить». «Добавить» у e-mail включена после ввода корректного адреса; адрес не из справочника попадает в колонку своего домена.
4. «Выгрузить» выключена, пока нет отмеченных получателей. «Выгрузить» и «Подтвердить» закрывают окно и запускают выгрузку.
5. Успешная выгрузка завершается тостом «Файл выгружен». Ошибка выгрузки (демо `?download=fail`): расчет — снекбар «Не удалось выгрузить файл», файл инструмента — алерт «Не удалось выгрузить файл» в окне ФИ.
6. Крестик, «Отменить» и Esc ничего не запускают.

## Открытые вопросы (Open questions)

1. **Текст предупреждения** ссылается на кнопку «Скачать», а кнопка называется «Выгрузить» (с шифрованием) и «Подтвердить» (без) — текст оставлен как в макете, не решено (08.10.2026). **Решено 08.10.2026:** в тексте «Выгрузить».
2. **Начальный список получателей** — изначально таблица пустая; сотрудники добавляются в окне (решение человека 08.10.2026).
3. **Определение домена по e-mail** — у внутренних доменов (Альфа, Омега) есть соответствующее доменное имя, все остальные внешние; в прототипе адрес с «omega» или «alfa» — внутренний (решение человека 08.10.2026).
4. **Название выгрузки шаблона** — у выгрузки файла инструмента окно с тем же заголовком «Выгрузка расчета на …», хотя выгружается шаблон; не решено (08.10.2026). **Решено 08.10.2026:** выгрузка шаблона — просто подтверждение действия, как окно без шифрования.
5. **Результат успешной выгрузки** — в макетах не показан; в прототипе окно просто закрывается (08.10.2026). **Решено 08.10.2026:** тост «Файл выгружен».
