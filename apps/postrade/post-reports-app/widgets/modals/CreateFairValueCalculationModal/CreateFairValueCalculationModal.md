# Widget: CreateFairValueCalculationModal — Окно формирования нового расчета

## Описание (Purpose)

Окно открывается кнопкой «Новый расчет» в реестре расчетов FV. Пользователь вводит дату расчета и
нажимает «Сформировать». Если расчет на эту дату уже есть, окно не закрывается и показывает ошибку.

## Раскладка (Layout)

```
Modal w3
├── шапка: «Формирование нового расчета» + IconButton L «Закрыть»
├── Alert error flush (modal__alert) — только при ошибке
├── тело: InputDate M во всю ширину — «Дата расчета»
└── подвал справа: Button accent M «Сформировать» (выключена, пока дата не введена)
```

Высота по контенту. Своего CSS у окна нет.

## Поведение (Behavior)

### Правила

1. «Сформировать» включается, когда введена полная дата `ДД.ММ.ГГГГ`, существующая в календаре.
2. Правка даты снимает Alert ошибки.
3. «Сформировать»: расчет на эту дату есть — Alert с текстом «Расчет на эту дату уже сформирован,
   его можно пересчитать или сформировать новый на новую дату.», окно открыто. Расчета нет — дата
   уходит странице, окно закрывается.
4. При каждом открытии окно пустое, Alert снят.
5. Маску даты и календарь даёт InputDate ДС.
