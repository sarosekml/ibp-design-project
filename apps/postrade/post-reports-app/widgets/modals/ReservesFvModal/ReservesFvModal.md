# Widget: ReservesFvModal — Окно «Данные FV»

## Описание (Purpose)

После выбора файла в «Загрузить FV» пользователь видит первые 100 строк загруженных данных: номер
строки, дата, финансовый инструмент, FV. «Сохранить» подтверждает загрузку. К какому расчету
относится загрузка — не решено (вопрос 13 задачи: это альтернатива «Новому расчету», рисуем только
интерфейс).

## Раскладка (Layout)

```
Modal w6
├── шапка: «Данные FV» + IconButton L «Закрыть»
├── Alert info flush: «Для предпросмотра загруженных данных доступно не более 100 первых строк»
├── тело (flush): Table — №, Дата, Финансовый инструмент, FV, RUB
└── подвал справа: Button accent M «Сохранить»
```

## Поведение (Behavior)

1. Страница при открытии рисует строки таблицы из демо-данных в таблицу `[data-fv-preview-rows]`.
2. «Сохранить», крестик и Esc закрывают окно. Данные прототип не сохраняет.
