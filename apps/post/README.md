# post — проект направления Post

Экраны направления Post (Operations / финансисты), соответствующие настоящей системе:
приложение трека `product` (`app.json`). Каталог `apps/post/` целиком — одно приложение и
один `root` записи в реестре хаба `../../hub.js` (`id: 'post'`). Агент правит его только с
подтверждением человека; черновые экраны и концепты направления агент собирает в
отдельном приложении трека `rnd` (`apps/<Имя>/`).

## Состав

| Папка или файл | Что внутри |
|---|---|
| `app.json` | запись приложения: `id`, трек `product` |
| `pages/` | экраны и их спеки: главная `MainPage`, реестр «Текущий портфель ДИД» `Portfolio`, страница сделки `Deal` (источник и собранный `Deal.preview.html`) |
| `components/` | локальные компоненты направления — тайлы, их модалки и прочие модули |
| `data/` | общая мок-база сделок: `mock-deals.js` + `DealsStore` (`deals-store.js`), дерево продуктов сделок `mock-deal-trees.js` |
| `refs/` | входящие материалы: ТЗ страницы «Текущий портфель ДИД» |
| `tools/assemble.mjs` | ассемблер модульных страниц: источник с метками → собранный `*.preview.html` |

Экраны лежат **на одном уровне** — прямо в `pages/`, папок под роль нет. Копии страниц под
каждую роль не делаются: различия ролей закрываются сменой состояний одной страницы.
Механизм такой смены пока не спроектирован.

Глубина экрана — `apps/post/pages/`: ДС подключает загрузчик проекта
(`../../../boot/ds-head.js` и `../../../boot/ds-body.js` с `data-ds="scripts/ibp-home.js"`),
а строка пользователя в футере меню ведёт на `../../../index.html`. До 22.09.2026 экраны лежали по
своим папкам (`mainPage/`, `Portfolio-did/`, `deal_post/`) в `Projects/post/`.

## Какой файл открывать

| Экран | Открывать двойным кликом |
|---|---|
| Главная | `pages/MainPage.html` |
| Текущий портфель ДИД | `pages/Portfolio.html` |
| Сделка | `pages/Deal.preview.html` — **собранный**, не `Deal.html` |

Страница сделки модульная: `pages/Deal.html` — это источник, он держит перечень тайлов
метками `<ds-include>`, а разметку тайлов вшивает ассемблер. После правки любого модуля или
источника:

```bash
node apps/post/tools/assemble.mjs
```

Почему сборка, а не рантайм ДС `ds-include.js`, и как устроены модули — в
`components/README.md`.

## Данные

`data/` — единственная точка доступа к базе сделок для всех экранов направления: таблица
портфеля и страница сделки читают один и тот же `window.DealsStore`, поэтому правила
валидации, уникальности и тоны статусных чипов (`DealsStore.statusTone`) живут в одном
месте. Состояние — только в памяти вкладки.
