Описание

Компактная дата «09 / окт» в ведущем слоте Entity M: список встреч читается по датам, не открывая каждую строку. Габарит — 40 × 40, как ведущая иконка Entity M, поэтому строки с датой стоят в линию с остальными строками-сущностями. Сегодняшняя дата выделена тоном accent — та же пара подложка/текст, что у выбора Entity.

Кандидат в ДС: у Entity нет ведущего элемента «дата». Блок декоративен для чтения с экрана — полную дату называет aria-label.

Блок рисует скрипт тайла функцией LcDateBadge.render(iso, { today }) из шаблона #lc-date-badge-tpl; страница вшивает шаблон один раз.

Раскладка

span.lc-date[role=img][aria-label=ДД.ММ.ГГГГ]
├── .lc-date__day    — число месяца, две цифры
└── .lc-date__month  — месяц, три буквы
