Описание

Первый тайл главной: сотрудник, который вошёл. Entity L — фото с точкой «в сети», приветствие по времени суток, имя, должность и деск, кнопки связи: скопировать телефон, написать письмо, открыть профиль. Под профилем (в широком тайле — справа) — быстрые действия «Новая встреча» и «Новая задача».

Фото нет или не загрузилось — инициалы (цепочка Avatar: фото → инициалы → иконка). Пара во фронтенде — new; ближайшая — employees-app/widgets/tiles/ProfileInfoTile.
