Описание

Показатель-фильтр: число записей выборки, подпись и, у размера M, короткое пояснение. Клик включает выборку в списке своего тайла, повторный — снимает; выбранная карточка несёт рамку в своём тоне. Тон кодирует смысл выборки, а не украшает: «Просрочено» — error, «Сегодня» — warning, «Новые» — accent.

Кандидат в ДС: в ДС нет компонента «показатель с тоном и выбором». Состояния сделаны по образцу Card (.tile--card), тоновые подложки — те же, что у Alert и SnackBar, поэтому при переносе в ДС меняется только имя класса.

Карточку рисует скрипт тайла функцией LcStatCard.render() из шаблона #lc-stat-card-tpl; страница вшивает шаблон один раз.

Раскладка

button.lc-stat (или span.lc-stat--static)
├── .lc-stat__label    — подпись
├── .lc-stat__value    — число
└── .lc-stat__caption  — пояснение (только M)

У размера S число стоит над подписью, пояснения нет.

Обязательность заполнения

  • Компонент обязателен к заполнению целиком: нет — это показатель.
  • Обязательные поля внутри: label, value.
  • Что показывает, когда обязательное не заполнено: прочерк вместо числа.
  • Что отдаёт наружу: data-stat — ключ выборки для тайла.
