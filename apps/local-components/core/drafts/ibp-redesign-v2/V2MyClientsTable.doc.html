Описание

Реестр «Мои клиенты» по ТЗ MS0014 §4.7: колонки Клиент · Полное наименование · ИНН · Статус (чип «Активен») · Дата (чип квартала с calendar) · Компания роста (чип trend-up) · Цели клиента (чип «Цели зафиксированы» с ⓘ) · Отрасль · Макроотрасль · Подотрасль · Сегмент · ТБ · ГОСБ · ГКМ · CRM ID; по наведению — «в избранное». Колонка сопоставляется с полем по ключу (ревью MS0014, Б6). Пустая вкладка — пустое состояние с текстом макета.

Поведение

  • «Клиент» → ClientInfoPage.
  • Фильтр, «Краткий отчет», пагинация — общий рендер.
  • SegmentControl → onView(view): страница показывает дерево V2MyClientsHierarchicalTree.
  • «Добавить клиента», «в избранное», ⓘ — по клику ничего (Р6).
