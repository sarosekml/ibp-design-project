Поведение

Действие → изменение через LEADS, затем обновление всех представлений. Перенос и решения отменяются SnackBar. Путь: раскрыть / свернуть / скрыть; Escape сворачивает, состояние сохраняется отдельно от данных лида. Модальные слои и фокус обслуживает DSModal.
