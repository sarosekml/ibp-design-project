Описание

Тайл «Финансовые метрики» по ТЗ MS0014 §4.3. Два блока ValuesBlock: «Всего по сделке» (общий объём, валюты) и «Продукты УСИ» (объём инвестиций, ВМ Мезонин, итоговый, процентный, комиссионный и дополнительный доход). Каждое поле — ReadOnlyField с подписью над значением; ⓘ — IconButton S в слоте иконок Label с тултипом (ревью MS0014, С7). У проекта продаж CIB метрик нет — прочерки.
