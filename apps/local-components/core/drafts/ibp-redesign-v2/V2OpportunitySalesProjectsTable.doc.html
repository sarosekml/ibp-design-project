Описание

Реестр раздела «проектов продаж CIB» — «Продуктовые предложения ДКК, ДККК, ДГР и ДИД». Вкладка — подфильтр одной таблицы (Р4 MS0014): колонки общие, строки отбираются по вкладке; адрес вкладки — имя страницы фронтенда (?tab=). Строка ведёт на страницу сделки; иконки «Действия» открывают окна «Взять в работу» и «Отказаться». Непросмотренная строка источника подсвечена модификатором tbl__row--accent и снимается после открытия сделки.

Поведение

  • клик по ID → страница сделки (Opportunity.preview.html?source=&id=&tab=), строка помечается просмотренной;
  • «Взять в работу» → окно подтверждения → сделка уходит в Pipeline «Сделки моего деска»; «Отказаться» → окно с причиной → вкладка «В архиве» (Р7);
  • «Фильтр» → модалка .tfm; «Применить» отбирает строки подстрокой по полю и показывает чип «Применено: N»; крестик чипа сбрасывает фильтр целиком;
  • «Краткий отчет» → Toast «Файл выгружен»;
  • вкладка → подфильтр строк, ?tab=<страница фронтенда>.
