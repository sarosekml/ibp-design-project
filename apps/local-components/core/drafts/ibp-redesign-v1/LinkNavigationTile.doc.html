Описание

Плитка со ссылками страницы «Администрирование» по ТЗ MS0014 §4.11: заголовок, пояснение, ссылки — плоским списком или группами с подписью («Сотрудники», «Задачи», «География»). Живая ссылка одна — «Статусы задач»; остальные вне объёма (Р5): выглядят как живые, клик гасится (ревью MS0014, З1).

└── сетка групп (1–4 колонки): подпись группы · ссылки столбцом
