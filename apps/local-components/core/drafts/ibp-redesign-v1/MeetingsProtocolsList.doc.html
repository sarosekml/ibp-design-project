Описание

Левая панель раздела «Встречи». Колонки — снимок системы: ID встречи, Статус, Клиент, Отраслевой деск, Дески, Источник встречи, ID источника встречи; на вкладке клиента — колонки Pixso. Клик по строке выбирает встречу, её карточку показывает MeetingsProtocolsDetails справа. Чип статуса: «Запланирована» — info, у просроченной (needsAttention) — error, «Завершена» — success, «Отменена» — grey.
