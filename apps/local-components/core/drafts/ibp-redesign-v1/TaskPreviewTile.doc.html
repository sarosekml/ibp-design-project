Описание

Правая панель реестра задач. Поля — снимок системы (Задачи.png): приоритет, тип, категория, срок, исполнитель, клиент, дата создания, инициатор, холдинг; ниже описание, связанный объект со ссылкой на его страницу и история изменений. Из Pixso — статус в шапке и блок «Комментарий». Сырой код статуса стенда (ADJUSTMENT_REQUIRED) показывается подписью «Требуется корректировка».

Раскладка

Tile
├── шапка: «№. Название» + чип статуса · правка · закрыть
└── тело
    ├── действия: Исполнить · Переназначить · Отменить (Buttons outline XS)
    ├── tile__grid 3 колонки: ReadOnlyField × 9 (приоритет — чип)
    ├── Комментарий (Tile Inset, если есть)
    ├── Описание задачи
    ├── Связанный объект: тип (чип) · номер · наименование (Link)
    └── История: TaskHistoryTable (вшитый виджет)

Поведение

  • «Исполнить», «Отменить» → onAction(...): страница открывает ChangeTaskStatusModal и меняет статус (Р7);
  • «Переназначить» — по клику ничего (Р6, Б7 MS0014a);
  • крестик → onAction(close);
  • карандаш — по клику ничего (Р6);
  • наименование связанного объекта → его страница.
