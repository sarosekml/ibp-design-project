Описание

История задачи из MS0014 §4.10 и MS0014a §4.2. Содержит события выбранной задачи; изменения статуса добавляют событие через общий store. Отдельный виджет с именем фронтенда вшивается в TaskPreviewTile и используется на странице задач и вкладке клиента.

Tile headless + Table
└── dtable__body (внутренняя прокрутка)
    └── TableCell: шапка + строки событий

Осознанные отклонения

Отклонений нет. Пагинация не нужна: история — часть предпросмотра, её прокрутку ведёт родительская панель.

Открытые вопросы

Контракт API и права вне роли Аналитик ДИД не предоставлены. Имена полей демо-данных — invented, окончательные определяет разработка.
