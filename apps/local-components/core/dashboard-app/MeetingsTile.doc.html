Описание

Ближайшие встречи сотрудника с клиентами (сотрудник — организатор или участник), начиная с сегодняшних: дата с днём недели, клиент (тултип с полным именем при усечении), контакт — с «+N» других участников и тултипом-списком скрытых участников, время начала и статус. Три счётчика — выборки списка: «Сегодня», «На неделе» (семь дней с сегодняшнего), «Требует внимания»; клик по счётчику показывает только его выборку, повторный — снимает фильтр.

Тайл показывает до шести встреч; остальные — в разделе «Встречи» (в прототипе раздела нет, переход показывает уведомление). Точек входа в создание встречи в тайле нет — создание из быстрых действий профиля.

Раскладка

Tile («Встречи»; действия: Spinner в обновлении, стрелка «Перейти в раздел Встречи»)
└── тело (колонка)
    ├── 3 × StatCard S — Сегодня (info) · На неделе · Требует внимания (warning)
    ├── .entity-list — до 6 строк Entity M: DateBadge «день недели + дата» · клиент ·
    │   контакт [, «+N» участников с тултипом] · время с иконкой часов ·
    │   Chip статуса справа строки
    ├── строка «выборка пуста»
    └── подвал: Divider · «Смотреть все…»
