Описание

Задачи в порядке срочности: просроченные (самая старая первой), со сроком сегодня (по приоритету), будущие (по сроку); выполненные — рядом с остальными, статус читается по чипу. Строка — приоритет (прописными) и срок, формулировка, статус-чип, сделка и клиент. В выборке «Задачи моего деска» строка показывает исполнителя: имя, первая его группа — чипом, остальные свёрнуты в «+N» с тултипом-списком групп (макет 15.10.2026). Переключатель — свои задачи или все задачи деска.

Смена статуса — через меню строки: «Взять в работу», «Вернуть в ожидание исполнения», «Отметить выполненной», «Открыть в разделе «Задачи»». Подтверждение — уведомлением с отменой. Меню шапки — один пункт-переключатель «Скрыть выполненные»: выполненные убираются из списка и возвращаются (решение человека 15.10.2026); окно «Новая задача» открывает быстрое действие профиля. Тайл показывает до пяти задач; пара во фронтенде у раздела — tasks-app (TasksPage, TasksOfMyDeskPage).

Раскладка

Tile («Задачи»; действия: Spinner в обновлении, стрелка «Перейти в раздел Задачи», меню «Скрыть выполненные»)
└── тело (колонка)
    ├── SegmentControl S fullwidth — Мои задачи · Задачи моего деска
    ├── .entity-list — до 5 строк Entity M без ведущего элемента:
    │     Header: Badge dot + приоритет прописными · иконка calendar + срок
    │     Label: формулировка (тултип при усечении)
    │     [деска] строка исполнителя: имя · чип группы · «+N» с тултипом групп
    │     Chips: статус
    │     Subs: Сделка D-… · клиент (с иконками link и bank)
    │     Actions: меню строки
    ├── строка «Выполненные задачи скрыты» — когда фильтр меню убрал все строки
    ├── ContextMenu #lc-tasks-menu — один пункт-чекбокс «Скрыть выполненные»
    ├── ContextMenu #lc-tasks-row-menu — одно на все строки
    └── подвал: Divider · «Смотреть все…»
