Описание

Окно открывается со страницы расчета кликом по наименованию ФИ или кнопкой «Редактировать ФИ». Показывает данные ФИ, позволяет вручную задать рейтинг, LGD и индивидуальную ставку резерва ПАО (рядом — расчетное значение), отметку «Передавать в LP» и комментарий, а в таблице «Инструменты в составе ФИ» — выгрузить, загрузить, удалить файл инструмента или вернуть его с ошибкой. Правка доступна в любом статусе расчета.

Поведение

Правила

  1. Окно открывается на ФИ из страницы; правки попадают в данные ФИ только после подтверждения.
  2. Поле ввода: только цифры и разделитель. Пустое поле (крестик очистки) — откат к расчетному значению. Значение, равное расчетному, правкой не считается.
  3. «Сохранить» без изменений закрывает окно. С изменениями — окно «Подтвердите действие» (тексты — в спеке страницы расчета, §9); после «Подтвердить» ФИ и все его инструменты — «Сформирован», XML-файлы — «Сформирован», значения правок записаны, окно закрыто, строка расчета перерисована. В «Утвержден» пересчитывается только этот ФИ.
  4. Действия над файлом инструмента — по FV_INSTRUMENT_FILE_ACTIONS (data/fv-dictionaries.js): «Сформирован» — выгрузить шаблон, загрузить, удалить; «Отправлен в LP» и «Рассчитывается LP» — выгрузить, вернуть с ошибкой; «Рассчитан» — только выгрузить. «Удалить» включена только у загруженного файла.
  5. «Загрузить» → общее окно подтверждения страницы → FairValueInstrumentablesUploadFileModal; «Сохранить» там ставит файлу состояние «Загружен». Загрузка не удалась — окно файла закрывается, здесь Alert «Не удалось загрузить файл».
  6. «Удалить» → подтверждение → файл «Удалён», инструмент и ФИ — «Нет данных». «Вернуть с ошибкой» → подтверждение → инструмент «Ошибка», ФИ «Ошибка».
  7. «Выгрузить» — хук страницы exportFile (подключает Э5); ошибка выгрузки одного файла — Alert здесь (api.showError).
