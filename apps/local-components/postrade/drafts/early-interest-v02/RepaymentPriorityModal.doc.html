Описание

Артефакт тайла «Приоритет погашения». «Сумма платежа» из окна «Новый платеж» гасит процентную задолженность по видам в этом порядке: сначала весь вид с приоритетом 1; если платёж погасил его целиком, остаток идёт на вид с приоритетом 2, и так далее. Порядок один на весь инструмент. В окне — все виды задолженности, их можно расставить в любом порядке; приоритет 1 — сверху. Подсказка окна (макет): «Досрочный платёж гасит задолженность сверху вниз: сначала тип с приоритетом 1, остаток — следующий по порядку. Порядок один на весь инструмент.»

Порядок окно не хранит: получает его при открытии, новый отдаёт странице по «Сохранить» (PostModalRepaymentOrder.bind(scrim, { labels, save }), RepaymentPriorityModal.js).

Раскладка

Modal w4 (заголовок «Приоритет погашения», IconButton L «Закрыть»)
├── тело
│   ├── Note — правило погашения
│   └── entity-list — строка Entity в рамке на каждый вид задолженности
│       ├── номер приоритета в сером квадрате · название вида
│       └── действия: IconButton S «Выше» (chevron-up) · «Ниже» (chevron-down) — только edit
└── подвал: edit — «Отменить» (transparent) · «Сохранить» (accent); view — «Закрыть» (accent)

Ширина — modal--w4. Ось data-mode (edit · view) — на .modal.
