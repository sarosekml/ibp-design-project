Описание

Артефакт тайла «Досрочные проценты». Заголовок окна — «Новые проценты» при внесении и «Редактирование досрочных процентов» при правке, форма одна.

Досрочный платёж процентов — сумма, которая начиная с «Даты платежа» гасит процентную задолженность по типам в порядке погашения инструмента (окно «Порядок погашения»). Дата — одна из дат погашения процентов в «Плановых платежах». Платёж участвует в расчёте «Процентных платежей» и «Плановых платежей». Подсказка внизу окна напоминает порядок, в котором сумма погасит задолженность.

Страницу и таблицу окно не знает: даты, валюту и порядок берёт у страницы, проверенную запись отдаёт ей же (PostModalEarlyInterest.bind(scrim, { options, save }), EarlyInterestPaymentModal.js). Страница добавляет или правит строку и показывает тост.

Каждая комбинация состояния данных и режима прав — копия фрагмента виджета.

Обязательность заполнения

  • Компонент обязателен к заполнению целиком: не применимо — окно.
  • Обязательные поля: «Дата платежа», «Сумма платежа».
  • Что показывает, когда обязательное не заполнено: по «Добавить» / «Сохранить» — Alert «Выберите дату платежа и введите сумму платежа.», поля подсвечены inp--error.
  • Что отдаёт наружу: запись { paymentDate, paymentAmount, comment } через save.
