Описание

Артефакт тайла «Порядок погашения». «Сумма платежа» из окна «Новые проценты» гасит процентную задолженность по типам в этом порядке: сначала весь тип с приоритетом 1; если платёж погасил его целиком, остаток идёт на тип с приоритетом 2, и так далее. Порядок один на весь инструмент. В окне — все типы задолженности, их можно расставить в любом порядке; приоритет 1 — сверху. Пример из требования: 1. Капитализированная задолженность, 2. Отложенная задолженность, 3. Капитализированная отложенная задолженность.

Порядок окно не хранит: получает его при открытии, новый отдаёт странице по «Сохранить» (PostModalRepaymentOrder.bind(scrim, { labels, save }), InterestRepaymentOrderModal.js).

Раскладка

Modal w4 (заголовок «Порядок погашения», IconButton L «Закрыть»)
├── тело
│   ├── Note — правило погашения
│   └── entity-list — строка Entity на каждый тип задолженности
│       ├── надзаголовок «Приоритет N» · подпись типа
│       └── действия: IconButton S «Выше» (arrow-narrow-up) · «Ниже» (arrow-narrow-down) — только edit
└── подвал: edit — «Отменить» (transparent) · «Сохранить» (accent); view — «Закрыть» (accent)

Ширина — modal--w4. Ось data-mode (edit · view) — на .modal.
