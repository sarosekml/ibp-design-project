Описание

Артефакт тайла «Описание сделки». Не компонент: сам по себе не существует и в плоском списке кита не числится — живёт подпунктом своего тайла.

Одно окно на два режима. В правке — всё, что показывает тайл, плюс дополнительные доходы: их тайл не показывает. В просмотре окно — место, где длинное описание и комментарий читаются целиком, без усечения тайла.

Ширина — modal--w7 (1053px на 1920), ровно ширина макета. Две колонки с вертикальным разделителем в пропорции 7 : 3 — с макета.

Все состояния рядом

Каждая комбинация состояния данных и режима прав — копия фрагмента виджета.

Обязательность заполнения

  • Окно обязательно к заполнению целиком: нет — сохраняет любой набор, в том числе пустой (тайл тогда встаёт в «Данных нет»).
  • Обязательные поля внутри: нет.
  • Что показывает, когда обязательное не заполнено: не применимо — обязательных полей нет.
  • Что отдаёт наружу: значения полей — странице одним патчем (opts.save).

Поведение

Проверка и сохранение

  • Обязательных полей нет: окно сохраняет любой набор, в том числе пустой — тайл тогда встаёт в «Данных нет».
  • Значение списка — только из справочника. Пустое допустимо.
  • «Сохранить» закрывает окно само, когда проверка прошла; крестик и Esc закрывают без сохранения, клик мимо окна в правке не закрывает (data-modal-guarded).
  • Правка уходит странице одним патчем (opts.save), страница пишет его в DealsStore, тайл и поповер «Связанные сделки» перерисовываются по событию стора.
