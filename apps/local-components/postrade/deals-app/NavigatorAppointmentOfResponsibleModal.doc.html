Описание

Окно, в котором ЦУП назначает ответственного по сделке. Открывается кнопкой «Назначить ответственного» на вкладке «ЦУП» тайла «Заведение сделки», когда сделку передали на сопровождение и ЦУП «Ожидает назначения ответственного».

По пояснению макета, «кроме выбора ответственного, указан ГСЗ (тот, что выбран в описании сделки) и связанные с этим ГСЗ сделки и ответственные по этим сделкам»: по таблице видно, кто из ЦУП уже ведёт сделки этой группы заемщиков.

По «Назначить» ЦУП переходит в «Ожидает подтверждения», выбранный сотрудник становится сотрудником ЦУП в команде сделки (tsupEmployee, тайл «Команда сделки»).

Крестик и Esc закрывают окно без назначения. Клик мимо окна не закрывает — в окне поле ввода (правило Modal ДС).

Поведение

Открытие и заполнение

Кнопка тайла → openModal страницы → open({ deal, transition }, done). В поле — нынешний сотрудник ЦУП сделки («ФИО номер»), ГСЗ — из записи, таблица — другие сделки той же ГСЗ из DealsStore в порядке реестра. Список сотрудников подставляется один раз на окно.

Назначение

«Назначить» → done({ patch }) → тайл применяет переход tsup_appoint вместе с tsupEmployee и tsupEmployeeTab; тайл «Команда сделки» видит нового сотрудника ЦУП. Крестик и Esc — done не вызывается.

Открытые вопросы

Решение человека 29.09.2026: вопросы не закрываются догадкой и не удаляются, пока человек не разберёт каждый.

  1. Список ответственных — взят весь справочник сотрудников команды сделки (mock-team.js); фильтруется ли он по подразделению ЦУП — не решено (23.09.2026, как в окне «Команда сделки»).
  2. Состав таблицы «Сделки ГСЗ» — текущая сделка в таблицу не входит, порядок — как в реестре; входят ли погашенные и удалённые сделки, нужна ли сортировка — допущение 10.10.2026.
  3. Обязательность — без ответственного «Назначить» недоступна — допущение 10.10.2026.
  4. Номер сделки — на макете номера вида «987179fh0q906…»; в прототипе номер — id записи сделки. Какой номер показывать — не решено (10.10.2026).
  5. Повторное назначение — после «Назначить» кнопки на вкладке ЦУП нет; как сменить ответственного позже (окно «Команда сделки»?) — не решено (10.10.2026).
