# HomeProfileTile — журнал изменений

Формат записи: что изменилось · почему · по какому требованию. Новая запись — сверху.

## 1.003 — 15.10.2026

**Отступы — компактная полоса профиля.** Нижнее поле tile--headless (32px)
локально ужато до 20px — симметрично верхнему: в макете профиль — плотная
полоса над тайлами, а стандартный низ headless рассчитан на контентные тайлы
и раздувал блок. Отклонение задокументировано в паспорте, кандидат в ДС —
модификатор Tile. *Требование:* правка человека по превью 15.10.2026.

## 1.002 — 15.10.2026

**Запасной вид аватара для панели прототипа.** `render(root, { avatar: 'text' })`
и атрибут `data-avatar="text"` рисуют иконку персоны вместо фото (как в макете
15.10.2026); переключатель — таб «System» панели прототипа, `avatar-view`.
*Требование:* поручение человека 15.10.2026.

## 1.001 — 15.10.2026

**Убраны приветствие и точка «в сети», тайл на всю ширину.** *Почему:* поручение
человека — приветствие и индикатор доступности не нужны, карточка профиля
занимает первый ряд целиком (`col-12`). *Требование:* поручение человека
15.10.2026.
