# DateBadge

## Описание (Purpose)

Компактная дата в ведущем слоте Entity M: список встреч читается по датам, не
открывая каждую строку. Два варианта: «09 / окт» (число и месяц) и «ПТ /
13.10» (день недели и дата, макет главной 15.10.2026). Вид — две строки
текста без подложки и без выделения сегодняшней даты (макет главной
15.10.2026, вторая правка); тайл прижимает блок к верху строки.

Кандидат в ДС: у Entity нет ведущего элемента «дата». Блок декоративен для
чтения с экрана — полную дату называет `aria-label`.

Блок рисует скрипт тайла функцией `LcDateBadge.render(iso, { weekday })` из
шаблона `#lc-date-badge-tpl`; страница вшивает шаблон один раз.

## Раскладка (Layout)

```
span.lc-date[role=img][aria-label=ДД.ММ.ГГГГ]
├── .lc-date__day    — число месяца, две цифры | день недели, две буквы
└── .lc-date__month  — месяц, три буквы       | дата, ДД.ММ
```

Вариант «день недели + дата» несёт класс `lc-date--weekday`: дни недели
пишутся строчными, верхний регистр даёт CSS.

### Свои состояния

Своих состояний нет: сегодняшняя дата не выделяется — в макете выделения нет.

## Обязательность заполнения (Required)

- Компонент обязателен к заполнению целиком: да — у строки встречи всегда есть дата.
- Обязательные поля внутри: `startDateTime`.
- Что показывает, когда обязательное не заполнено: не применимо.
- Что отдаёт наружу: ничего.

## Переполнение (Overflow)

|---|---|

## Осознанные отклонения (Deviations)

| Правило | Как сделано | Почему |
|---|---|---|
| Элемент, которого нет в ДС, сначала заводится в ДС | собран локально | решение человека 09.10.2026 |
| Ведущий элемент Entity — иконка, аватар, чекбокс или грип | в ведущем слоте — блок даты | макет: дата встречи в начале строки |
| «Длинный текст не бывает» | у варианта weekday день недели — две буквы | вариант добавлен по макету 15.10.2026 |
| Габарит ведущего элемента Entity M — 40 × 40 | две строки текста без подложки | макет главной 15.10.2026 (вторая правка) — дата не выделена плашкой, прижата к верху строки; правка человека по превью |
