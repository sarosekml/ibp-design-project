# HomeTasksTile

## Описание (Purpose)

Задачи в порядке срочности: просроченные (самая старая первой), со сроком
сегодня (по приоритету), будущие (по сроку); выполненные — рядом с
остальными, статус читается по чипу. Строка — приоритет (прописными) и срок,
формулировка, статус-чип, сделка и клиент. В выборке «Задачи моего деска»
строка показывает исполнителя: имя, первая его группа — чипом, остальные
свёрнуты в «+N» с тултипом-списком групп (макет 15.10.2026). Переключатель —
свои задачи или все задачи деска.

Смена статуса — через меню строки: «Взять в работу», «Вернуть в ожидание
исполнения», «Отметить выполненной», «Открыть в разделе «Задачи»».
Подтверждение — уведомлением с отменой. Меню шапки — один пункт-переключатель
«Скрыть выполненные»: выполненные убираются из списка и возвращаются
(решение человека 15.10.2026); окно «Новая задача» открывает быстрое действие
профиля. Тайл показывает до пяти задач; пара во фронтенде у раздела —
`tasks-app` (`TasksPage`, `TasksOfMyDeskPage`).

## Раскладка (Layout)

```
Tile («Задачи»; действия: Spinner в обновлении, стрелка «Перейти в раздел Задачи», меню «Скрыть выполненные»)
└── тело (колонка)
    ├── SegmentControl S fullwidth — Мои задачи · Задачи моего деска
    ├── .entity-list — до 5 строк Entity M без ведущего элемента:
    │     Header: Badge dot + приоритет прописными · иконка calendar + срок
    │     Label: формулировка (тултип при усечении)
    │     [деска] строка исполнителя: имя · чип группы · «+N» с тултипом групп
    │     Chips: статус
    │     Subs: Сделка D-… · клиент (с иконками link и bank)
    │     Actions: меню строки
    ├── строка «Выполненные задачи скрыты» — когда фильтр меню убрал все строки
    ├── ContextMenu #lc-tasks-menu — один пункт-чекбокс «Скрыть выполненные»
    ├── ContextMenu #lc-tasks-row-menu — одно на все строки
    └── подвал: Divider · «Смотреть все…»
```

## Поля (Fields)

| Поле | Смысл | Тип, единица | Источник | Обязательное |
|---|---|---|---|---|
| `priorityCode` | приоритет — точка и слово в Header, прописными | `TaskPriorityCode` | `TaskRsDto` | да |
| `dueDate` | срок — дата в Header | ISO-дата | `TaskRsDto` | да |
| `title` | формулировка | строка | `TaskRsDto` | да |
| `statusCode` | статус — чип | `TaskStatusCode` | `TaskRsDto` | да |
| `dealNumber` | сделка | строка | `TaskRsDto` | нет |
| `clientName` | клиент | строка | `TaskRsDto` | нет |
| `assigneeName` | исполнитель строки деска | строка | `TaskRsDto` | в выборке деска |
| `assigneeGroups` | группы исполнителя: первая чипом, остальные в «+N» | `string[]` | `TaskRsDto` | в выборке деска |

Тоны статуса: `NEW` — info «Ожидает исполнения», `IN_PROGRESS` — dpurple
«В работе», `DONE` — success «Выполнено», `NEEDS_CORRECTION` — warning
«Требуется корректировка». Нет ни сделки, ни клиента — строка ссылки не
рисуется.

## Состояния (States)

| Состояние | Есть в продукте | Вид |
|---|---|---|
| Загрузка (Loading) | да | скелетоны трёх строк; переключателя и действий шапки нет |
| Данные есть | да | переключатель, до 5 строк, подвал |
| Заполнено частично | да | нет сделки или клиента — строка ссылки без них |
| Данных нет (Empty) | да | иллюстрация (иконка tasks) и текст по выборке: «Нет назначенных задач» / «Нет задач деска»; переключатель и подвал на месте |
| Ошибка (Error) | да | Alert error «Не удалось загрузить задачи» + «Повторить» |
| Обновление | точки входа нет — пункта «Обновить» в меню больше нет | состояние updating осталось: прежние строки на месте, в шапке Spinner S (демо) |
| Редактирование доступно | да | пункты смены статуса в меню строки; «Новая задача» — быстрое действие профиля |
| Только просмотр (Disabled) | да | пунктов смены статуса нет; меню шапки «Скрыть выполненные» доступно |
| Нет права видеть | да | тайла нет на странице — решает страница |

### Свои состояния

| Состояние | Когда | Вид |
|---|---|---|
| Задача взята в работу | меню строки → «Взять в работу» | чип «В работе», уведомление с «Отменить» |
| Задача выполнена | меню строки → «Отметить выполненной» | чип «Выполнено», уведомление с «Отменить» |
| Возвращена в ожидание | меню строки → «Вернуть в ожидание исполнения» | чип «Ожидает исполнения», уведомление с «Отменить» |
| Выполненные скрыты | меню шапки, пункт включён | выполненных строк в списке нет; убрали все — строка «Выполненные задачи скрыты» на месте списка |

## Обязательность заполнения (Required)

- Компонент обязателен к заполнению целиком: нет — это обзор.
- Обязательные поля внутри: приоритет, срок, формулировка, статус — см. «Поля».
- Что показывает, когда обязательное не заполнено: не применимо.
- Что отдаёт наружу: ничего.

## Переполнение (Overflow)

| Случай | Правило |
|---|---|
| Длинный текст в поле | формулировка — одна строка с многоточием и тултипом; код группы — чип сжимается и усекает подпись |
| Много строк или записей | до 5 строк, остальное — в разделе «Задачи» |
| Много групп у исполнителя | первая чипом, остальные — «+N» с тултипом-списком скрытых групп |
| Узкая ширина | без изменений: строка без ведущего элемента |
| Полная ширина | без изменений |

## Поведение (Behavior)

| Триггер | Результат |
|---|---|
| Переключатель «Мои / деска» | список другой выборки |
| Меню строки → смена статуса | статус меняется, уведомление с «Отменить» возвращает прежний |
| Меню строки → «Открыть в разделе «Задачи»», стрелка, «Смотреть все…» | событие перехода: уведомление страницы |
| Меню шапки → «Скрыть выполненные» | выполненные убираются из списка и возвращаются; галочка пункта отражает состояние, меню не закрывается; убрали все — строка «Выполненные задачи скрыты» |
| Alert → «Повторить» | `loading` → данные |
| `HomeStore.focus('tasks')` | тайл прокручивается в зону видимости |
| Новая задача сохранена (`HomeStore`, событие `tasks`) | список пересчитывается |
