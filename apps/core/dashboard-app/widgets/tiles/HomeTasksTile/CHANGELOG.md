# HomeTasksTile — журнал изменений

Формат записи: что изменилось · почему · по какому требованию. Новая запись — сверху.

## 1.005 — 15.10.2026

**Стрелка шапки — нейтральный тон** (`ibtn--neutral`), тот же, что у
иконки меню. Акцентный тон из записи 1.004 — ошибочное прочтение
макета, вернул по правке человека. *Требование:* правка по превью
15.10.2026.

## 1.004 — 15.10.2026

**Меню шапки — один пункт «Скрыть выполненные».** Пункты «Обновить» и
«Новая задача» из меню убраны: окно создания открывает быстрое действие
профиля, точка входа в обновление у тайла больше нет (состояние updating
осталось для демо). Новый пункт — чекбокс ContextMenu (`menuitemcheckbox`,
галочка справа, меню не закрывается): выполненные задачи убираются из списка
и возвращаются; если скрыты все — строка «Выполненные задачи скрыты» на
месте списка. *Требование:* правки человека по превью 15.10.2026
(скриншот с меню).

## 1.003 — 15.10.2026

**Правки по второй правке макета.** Иконки строки (срок в мета, сделка и
клиент в подвале) — 1.15em в `--text-inactive` (канон подписи Entity) вместо
дефолтных 24px; стрелка шапки — IconButton M primary; «Смотреть все…» —
Link accent S без иконки. *Требование:* макет «Главная» 15.10.2026 (new1) —
правки человека по превью.

## 1.002 — 15.10.2026

**Исполнитель в «задачах моего деска», тултипы, приоритет прописными.** В строке
выборки деска — имя исполнителя, первая его группа чипом (`chip--outline
chip--grey`), остальные группы свёрнуты в «+N» с тултипом-списком скрытых групп
(tip--rich, снизу); в «моих задачах» исполнителя нет. Тултип формулировки
проверяет усечение. Приоритет в Header — прописными (как в макете), текст
пустого стейта — по выборке: «Нет назначенных задач» / «Нет задач деска».
*Требование:* макет «Главная» 15.10.2026 (вторая правка дизайна карточек) —
поручение человека 15.10.2026.

## 1.001 — 15.10.2026

**Анатомия строки по макету 15.10.2026.** Убраны счётчики-фильтры и чипы
срока; в строке — приоритет с точкой, срок с иконкой календаря, статус-чип,

строки со сменой статуса сохранено сверх макета — живой сценарий. *Требование:*
поручение человека 15.10.2026.
