# MeetingsTile

## Описание (Purpose)

Ближайшие встречи сотрудника с клиентами (сотрудник — организатор или
участник), начиная с сегодняшних: дата с днём недели, клиент (тултип с полным
именем при усечении), контакт — с «+N» других участников и тултипом-списком
скрытых участников, время начала и статус. Три счётчика — выборки списка:
«Сегодня», «На неделе» (семь дней с сегодняшнего), «Требует внимания»; клик
по счётчику показывает только его выборку, повторный — снимает фильтр.

Тайл показывает до шести встреч; остальные — в разделе «Встречи» (в
прототипе раздела нет, переход показывает уведомление). Точек входа в
создание встречи в тайле нет — создание из быстрых действий профиля.

## Раскладка (Layout)

```
Tile («Встречи»; действия: Spinner в обновлении, стрелка «Перейти в раздел Встречи»)
└── тело (колонка)
    ├── 3 × StatCard S — Сегодня (info) · На неделе · Требует внимания (warning)
    ├── .entity-list — до 6 строк Entity M: DateBadge «день недели + дата» · клиент ·
    │   контакт [, «+N» участников с тултипом] · время с иконкой часов ·
    │   Chip статуса справа строки
    ├── строка «выборка пуста»
    └── подвал: Divider · «Смотреть все…»
```

## Поля (Fields)

| Поле | Смысл | Тип, единица | Источник | Обязательное |
|---|---|---|---|---|
| `startDateTime` | дата (DateBadge) и время начала | ISO дата-время | `MeetingRsDto` | да |
| `clientName` | клиент — тултип с полным именем при усечении | строка | `MeetingRsDto` | да |
| `contactName` | контакт клиента | «Фамилия И. О.» | `MeetingRsDto` | да |
| `contactPosition` | должность контакта | строка | `MeetingRsDto` | да |
| `participants` | другие участники с клиентской стороны: «+N» в строке, список — в тултипе | `Array<{name, position}>` | `MeetingRsDto` | нет |
| `statusCode` | статус | `MeetingStatusCode` | `MeetingRsDto` | да |

Тоны статуса: `SCHEDULED` — info «Запланирована», `NEEDS_ATTENTION` —
warning «Требует внимания», `PROTOCOL_DONE` — success «Протокол заполнен»,
`CANCELLED` — grey «Отменена» (отменённые на главную не попадают).

## Состояния (States)

| Состояние | Есть в продукте | Вид |
|---|---|---|
| Загрузка (Loading) | да | скелетоны трёх счётчиков и четырёх строк; действий шапки нет |
| Данные есть | да | счётчики, до 6 строк, подвал |
| Заполнено частично | нет | у встречи все поля обязательны |
| Данных нет (Empty) | да | счётчики остаются с нулями, список заменяет иллюстрация (иконка календаря) и «Пока нет запланированных встреч»; подвал на месте (макет главной) |
| Ошибка (Error) | да | Alert error «Не удалось загрузить встречи» + «Повторить» |
| Обновление | да | прежние строки на месте, в шапке Spinner S |
| Редактирование доступно | нет | точек входа в правку в тайле нет |
| Только просмотр (Disabled) | нет | не применимо |
| Нет права видеть | да | тайла нет на странице — решает страница |

### Свои состояния

| Состояние | Когда | Вид |
|---|---|---|
| Выборка | включён счётчик | только его встречи, счётчик выбран (`aria-pressed`) |
| Выборка пуста | у выборки нет встреч | строка «Сегодня встреч нет» / «На ближайшие семь дней встреч нет» / «Встреч, требующих внимания, нет» |

## Переполнение (Overflow)

| Случай | Правило |
|---|---|
| Длинный текст в поле | клиент — одна строка с многоточием и тултипом с полным именем; контакт с «+N» — строка с усечением; подписи счётчиков — многоточие |
| Много строк или записей | до 6 строк, остальное — в разделе «Встречи» |

| Полная ширина | без изменений |

## Поведение (Behavior)

| Триггер | Результат |
|---|---|
| Клик по счётчику | список — только его выборка; повторный клик — снять |
| Alert → «Повторить» | `loading` → данные |
| Стрелка шапки, «Смотреть все…» | событие перехода: страница показывает уведомление (раздела в прототипе нет) |
| `HomeStore.focus('meetings', filter)` | включается выборка, тайл прокручивается в зону видимости, фокус — на счётчик |
| Новая встреча сохранена (`HomeStore`, событие `meetings`) | список и счётчики пересчитываются |
