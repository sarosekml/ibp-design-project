# Page: HomePage — Главная — дашборд

## 1. Назначение (Purpose)

Стартовая страница сотрудника: за несколько секунд ответить «что у меня
сегодня» — встречи, сроки задач, новости по клиентам — и дать быстрый вход в
создание встречи и задачи. Редизайн главной с навигационными тайлами:
навигация по разделам остаётся только в меню (решение человека 09.10.2026).

**Роль пользователя:** аналитик ДИД (профиль макета).
**Права:** свои встречи и задачи — просмотр и правка; встречи и задачи деска —
просмотр; новости — просмотр.

## 2. Адрес и навигация (Route)

- **Адрес в продукте:** не решено (09.10.2026) — раздел 17, вопрос 2.
- **Пункт бокового меню** в состоянии `nav__item--selected`: «Главная».
  Состав меню — общий каталог ДС `patterns/HomeRoles/ibp-home.js`, роль по
  умолчанию (`IBPHome.defaultRole`).
- **Крошек нет** — решение человека 15.10.2026: страница стартовая, путь
  один; зона крошек каркаса на ней не рисуется, отступ сверху контента даёт
  `.screen__content`.
- Строка пользователя в футере меню ведёт на хаб проектов
  (`../../../../index.html`), аватар — фото профиля.

## 3. Раскладка (Layout)

Стартовая страница (Layout, «Стартовая страница»): шапки страницы нет,
контентная область — один блок, сетка `.grid12` (12 колонок, зазор 16px по
обеим осям). Первый тайл — профиль сотрудника на всю строку, под ним в ряд —
встречи, задачи и новости.

```
Page (Layout, nav--rail)
└── .grid12#home-grid
    ├── HomeProfileTile (12) — профиль, быстрые действия
    ├── MeetingsTile (4)     — встречи: счётчики-фильтры, список
    ├── HomeTasksTile (4)    — задачи: мои / деска, список
    └── NewsTile (4)         — новости: три выборки клиентов
```

| № | Блок | Виджет | Колонок 1920 / ≤ 1024 | Содержимое |
|---|---|---|---|---|
| 1 | Профиль | `widgets/tiles/HomeProfileTile` | 12 / 12 | Entity L: фото, ФИО, должность и деск, связь; «Новая встреча», «Новая задача» |
| 2 | Встречи | `widgets/tiles/MeetingsTile` | 4 / 12 | 3 счётчика-фильтра, до 6 встреч: дата с днём недели, клиент (тултип полного имени), контакт с «+N» участников (тултип-список), время, статус справа |
| 3 | Задачи | `widgets/tiles/HomeTasksTile` | 4 / 12 | переключатель, до 5 задач: приоритет прописными и срок, формулировка, [в деске] исполнитель с группой чипом и «+N», статус, сделка и клиент |
| 4 | Новости | `widgets/tiles/NewsTile` | 4 / 12 | переключатель из трёх выборок, до 5 новостей: дата, источник прописными, заголовок, содержание, клиент; «Смотреть все…» |

Перестроение — одно, от ширины рабочей области (`@container screen`): три
рабочих тайла стоят в ряд до окна ~1024px (контейнер 920px при панели rail),
ниже каждый — на всю строку (`col-N` / `colw-N` на метках). Высоты тайлов
ряда выравнивает сетка; подвалы «Смотреть все…» прижаты к низу тайла и стоят
на одной линии.

Перестроение — от ширины рабочей области (`@container screen`): ≤ 1300px —
пары `col-N` / `colw-N`; ≤ 760px — всё в одну колонку правилом экрана
`.grid12 > .tile` той же специфичности, что правило пары, и ниже по файлу.
Высоты тайлов ряда выравнивает сетка; подвалы «Смотреть все…» прижаты к низу
тайла и стоят на одной линии.

Вертикальный скролл: есть, скроллится страница. Горизонтального скролла нет.

## 6. Поведение (Behavior)

| Триггер | Результат |
|---|---|
| Открытие страницы | тайлы стоят в `loading` (скелетоны) и появляются каскадом: профиль 0,5 с, встречи 0,7 с, задачи 0,9 с, новости 1,1 с — каждый по ответу своего сервиса |
| «Новая встреча» / «Новая задача» в профиле | открывается окно создания (`data-modal`) |
| Сохранение встречи или задачи | запись появляется в своём тайле, счётчики встреч и списки пересчитываются, уведомление «Встреча создана» / «Задача создана» |
| Клик по счётчику встреч | список встреч — только его выборка; повторный клик снимает |
| «Взять в работу», «Отметить выполненной», «Вернуть в ожидание исполнения» (меню строки задач) | статус задачи меняется, уведомление с кнопкой «Отменить» возвращает прежний статус |
| Меню тайла задач → «Скрыть выполненные» | выполненные задачи убираются из списка и возвращаются; если скрыты все — строка «Выполненные задачи скрыты» |
| Переключатели таба «System» панели прототипа | «Аватар профиля» (фото / без фото) и «Наполнение карточек» (заполненные / пустые / ошибка) применяются на странице без перезагрузки |
| Стрелка в шапке тайла, «Смотреть все…», «Открыть профиль», «Открыть в источнике», «Открыть в разделе «Задачи»» | в прототипе разделов нет — уведомление «… — в следующей версии прототипа» |
| Наведение на стрелку шапки тайла, усечённое имя клиента, «+N» участников встречи или групп исполнителя | тултип: переход в раздел / полное имя / список скрытых участников или групп — по одной строке на значение |
| Сужение рабочей области | см. раздел 3 |

Поведение тайлов — в их паспортах. Связь тайлов — через хранилище
`HomeStore`: правка в одном тайле перерисовывает зависимые (`on`, события
`meetings`, `tasks`, `focus`).

## 8. Состояния (States)

### Loading
Каждый тайл — каркас со скелетонами в габаритах содержимого (Skeleton);
шапки тайлов на месте, действий в шапке нет.

### Empty
Пустой стейт — по макету 15.10.2026: иллюстрация (крупная иконка ДС) и строка
причины, без действий. «Встречи» — счётчики остаются с нулями, список заменяет
иллюстрация календаря и «Пока нет запланированных встреч»; «Задачи» —
иллюстрация и «Задач пока нет»; «Новости» — иллюстрация и текст по выборке.
Подвалы «Смотреть все…» и переключатели выборок остаются. Профиль пустым
не бывает.

### Error
Ошибка живёт внутри тайла: Alert `error` с причиной и «Повторить»;
остальные тайлы работают.

### Disabled
Роль без права создавать встречи и задачи — `mode="view"` у профиля, встреч
и задач: быстрых действий, «Добавить», «Взять в работу» и пунктов смены
статуса нет.

### Обновление
Точек входа в обновление у тайлов данных нет: у задач в меню остался один
пункт «Скрыть выполненные» (решение человека 15.10.2026), у встреч и новостей
пункта не было с новой версии макета. Состояние `updating` в тайлах осталось —
шапка показывает Spinner S.

## 12. Скрипт экрана (Script)

Инлайн-скрипт страницы делает только своё: строит меню из каталога ДС
(футер — фото и ФИО профиля, ссылка на хаб), ставит тайлам состояние после
«ответа» (каскад или параметр `?state=`), показывает уведомление на
переходы `[data-home-goto]` и событие `home:goto` и объявляет переключатели
таба «System» панели прототипа (`window.PP_SYSTEM`: `avatar-view`,
`card-content`). Порядок подключения:
данные → `ds-body.js` → `StatCard.js`, `DateBadge.js` → тайлы →
`MeetingCreateModal.js` (общий слой форм `LcHomeForm`) → `TaskCreateModal.js`
→ скрипт страницы.

| Блок даты «день + месяц», «день недели + дата» | `widgets/tiles/DateBadge` | ведущий элемент Entity «дата», модификатор «сегодня» |
| Тон поверхности тайла | `NewsTile.css`, `.tile.lc-news` | модификатор поверхности Tile (`--primary-bg`) |

## 16. Доступность

- `<main>` для контентной области, `<nav aria-label="Главное меню">`;
- `h1` нет — стартовая страница (Layout); у тайлов `h3`, у новостей `h4`;
- счётчики встреч — кнопки с `aria-pressed` и полной подписью `aria-label`;
- переключатели выборок — `radiogroup` с `aria-checked`;
- у всех кнопок-иконок есть `aria-label`; списки — `aria-live="polite"`;
- у «+N» (участники встречи, группы исполнителя) есть `aria-label`
  «Ещё участников/групп: N» и тултип со списком скрытых значений;
- контраст — токены ДС.
