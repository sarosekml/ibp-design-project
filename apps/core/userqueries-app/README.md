## Имена фронтенда

Сущности модуля во фронтенде (снято с дерева фронтенда 24.09.2026) —
разложены по нашей форме. Экран или виджет, у которого здесь есть пара, называется
так же: разработчик находит его без перевода (`apps/README.md`, «widgets»).

| Куда у нас | Имена во фронтенде |
|---|---|
| `pages/` | GigaChatPage |
| другие виджеты | GigaChatWidget — своей группы у нас нет: новая группа — в `project.json → appShape.widgetGroups` |
| мелкие элементы | ChatHistory, ChatInputs, ChatList, ChatTypeSelector, CreateChatButton — у фронтенда `features/`; у нас — в разметке страницы или виджета |
