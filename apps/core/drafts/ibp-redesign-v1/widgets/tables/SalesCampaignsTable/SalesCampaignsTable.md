# SalesCampaignsTable

## Описание (Purpose)

Реестр раздела «кампаний продаж» — «Потенциалы ДИД, отправленные на проработку в рабочее место КМ». Вкладка — подфильтр одной таблицы (Р4 MS0014): колонки общие, строки отбираются по вкладке; адрес вкладки — имя страницы фронтенда (`?tab=`). Строка ведёт на страницу сделки. Непросмотренная строка источника подсвечена модификатором `tbl__row--accent` и снимается после открытия сделки.

## Раскладка (Layout)

```
Tile headless
├── Alert ошибки (__error, только data-state="error")
└── Table (.dtable--fill)
    ├── тулбар: TableFilter (кнопка + чип «Применено: N») · «Краткий отчет»
    ├── тело: шапка и строки TableCell / .dtable__empty
    └── подвал: Pagination
```

## Поведение (Behavior)

- клик по ID → страница сделки (`Opportunity.preview.html?source=&id=&tab=`), строка помечается просмотренной;
- «Фильтр» → модалка `.tfm`; «Применить» отбирает строки подстрокой по полю и показывает чип «Применено: N»; крестик чипа сбрасывает фильтр целиком;
- «Краткий отчет» → Toast «Файл выгружен»;
- вкладка → подфильтр строк, `?tab=<страница фронтенда>`.
