# SimpleSettingsTable

## Описание (Purpose)

Таблица справочника «Статусы задач» по ТЗ MS0014 §4.11: «Статус» (зелёная `check-circle-filled` у действующего, `blocked` и дата у выключенного) · «Код» · «Наименование»; фильтр, пагинация. Выбор строки открывает SimpleSettingsTile справа. Имена фронтенда — допущение (вопрос В6 MS0014a).


## Состояния (States)

| Состояние | Есть в продукте | Вид |
|---|---|---|
| Загрузка (Loading) | да | каркас тайла и скелетоны строк (`.lc-simple-settings__loading`) |
| Данные есть | да | базовый вид |
| Заполнено частично | да | незаполненное поле — прочерк на своём месте |
| Данных нет (Empty) | да | строка причины без иллюстрации (`.lc-simple-settings__empty`) |
| Ошибка (Error) | да | Alert внутри компонента с повтором (`.lc-simple-settings__error`) |
| Обновление | да | прежние значения видны; локальной индикации в прототипе нет |
| Редактирование доступно | нет | в части 1 правка не воссоздаётся (Р6): точки входа видны, по клику ничего |
| Только просмотр (Disabled) | да | `data-mode="view"`: действия правки не рисуются |
| Нет права видеть | не решено (10.10.2026) | компонент не ставится экраном |

## Переполнение (Overflow)

| Случай | Правило |
|---|---|
