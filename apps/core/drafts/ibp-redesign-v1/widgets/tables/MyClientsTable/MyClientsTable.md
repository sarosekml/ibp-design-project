# MyClientsTable

## Описание (Purpose)

Реестр «Мои клиенты» по ТЗ MS0014 §4.7: колонки Клиент · Полное наименование · ИНН · Статус (чип «Активен») · Дата (чип квартала с `calendar`) · Компания роста (чип `trend-up`) · Цели клиента (чип «Цели зафиксированы» с ⓘ) · Отрасль · Макроотрасль · Подотрасль · Сегмент · ТБ · ГОСБ · ГКМ · CRM ID; по наведению — «в избранное». Колонка сопоставляется с полем по ключу (ревью MS0014, Б6). Пустая вкладка — пустое состояние с текстом макета.

## Раскладка (Layout)

```
Tile headless
└── dtable (fill)
    ├── тулбар: Фильтр · «Краткий отчет» · «Добавить клиента» · SegmentControl (таблица / дерево)
    ├── Table: 15 колонок, «в избранное» — .tc__hidden
    ├── пустое состояние: иллюстрация · заголовок · текст · «Добавить клиента»
    └── Pagination
```

## Состояния (States)

| Состояние | Есть в продукте | Вид |
|---|---|---|
| Загрузка (Loading) | да | каркас тайла и скелетоны строк (`.lc-my-clients-table__loading`) |
| Данные есть | да | базовый вид |
| Заполнено частично | да | незаполненное поле — прочерк на своём месте |
| Данных нет (Empty) | да | пустое состояние `.dtable__empty` с текстом макета |
| Ошибка (Error) | да | Alert внутри компонента с повтором (`.lc-my-clients-table__error`) |
| Обновление | да | прежние значения видны; локальной индикации в прототипе нет |
| Редактирование доступно | нет | в части 1 правка не воссоздаётся (Р6): точки входа видны, по клику ничего |
| Только просмотр (Disabled) | да | `data-mode="view"`: действия правки не рисуются |
| Нет права видеть | не решено (10.10.2026) | компонент не ставится экраном |

## Переполнение (Overflow)

| Случай | Правило |
|---|---|
| Длинный текст в поле | перенос по словам; заголовки и подписи — усечение с тултипом компонента ДС |
| Много строк или записей | не применимо |
| Узкая ширина | сетка полей в одну колонку по ширине самого компонента (container query) |
| Полная ширина | сетка полей по паспорту, лишнего воздуха нет |

## Поведение (Behavior)

- «Клиент» → ClientInfoPage.
- Фильтр, «Краткий отчет», пагинация — общий рендер.
- SegmentControl → `onView(view)`: страница показывает дерево MyClientsHierarchicalTree.
- «Добавить клиента», «в избранное», ⓘ — по клику ничего (Р6).
