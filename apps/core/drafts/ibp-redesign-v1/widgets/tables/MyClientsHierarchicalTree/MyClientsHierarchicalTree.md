# MyClientsHierarchicalTree

## Описание (Purpose)

Вид «дерево» реестра «Мои клиенты» по ТЗ MS0014 §4.7: строки-группы холдингов с раскрытием и клиенты холдинга. Колонки — по конфигу фронтенда (клиент, полное наименование, ИНН, отрасль, ТБ, ГКМ, CRM ID). Фильтров в виде дерева нет, как во фронтенде.

## Раскладка (Layout)

```
Tile headless
└── dtable (fill)
    ├── тулбар: «Краткий отчет» · «Добавить клиента» · SegmentControl
    └── Table: группа холдинга (TableCell tree) → клиенты (уровень 1)
```

## Поля (Fields)

| Поле | Смысл | Тип, единица | Источник | Обязательное |
|---|---|---|---|---|
| Холдинг | группа | строка, число клиентов | data/clients.js (holdingName) | нет |
| Клиент |  | ссылка | data/clients.js | нет |
| Полное наименование, ИНН, Отрасль, ТБ, ГКМ, CRM ID |  | строки | data/clients.js, data/employees.js | нет |

Порядок строк — порядок отображения. Имя поля — как в описании типа демо-данных.
Незаполненное поле — прочерк на своём месте, с места не уходит.

| Состояние | Есть в продукте | Вид |
|---|---|---|

## Переполнение (Overflow)

| Случай | Правило |
|---|---|
| Длинный текст в поле | перенос по словам; заголовки и подписи — усечение с тултипом компонента ДС |
| Много строк или записей | не применимо |
| Узкая ширина | сетка полей в одну колонку по ширине самого компонента (container query) |
| Полная ширина | сетка полей по паспорту, лишнего воздуха нет |

## Поведение (Behavior)

- Шеврон группы сворачивает клиентов холдинга.
- Клиент → ClientInfoPage.
- SegmentControl → `onView(view)`.
- «Краткий отчет» — Toast «Файл выгружен»; «Добавить клиента» — по клику ничего (Р6).
