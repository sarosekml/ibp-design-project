# FinancialsTable

## Описание (Purpose)

Таблица «Показатель × квартал» вкладки «Финансовые показатели» по ТЗ MS0014 §4.8: первая колонка — показатель (закреплена), дальше кварталы; в ячейке — значение и подзначение второй строкой.

## Раскладка (Layout)

```
Tile headless
└── Table: Показатель (закреплён) · кварталы (числа, значение + подзначение)
```

|---|---|---|

## Поля (Fields)

| Поле | Смысл | Тип, единица | Источник | Обязательное |
|---|---|---|---|---|
| Показатель |  | строка | data/clients.js (financials.fok.rows) | нет |
| Значение по кварталу | значение и подзначение | строки | data/clients.js | нет |

Порядок строк — порядок отображения. Имя поля — как в описании типа демо-данных.
Незаполненное поле — прочерк на своём месте, с места не уходит.

## Переполнение (Overflow)

| Случай | Правило |
|---|---|
