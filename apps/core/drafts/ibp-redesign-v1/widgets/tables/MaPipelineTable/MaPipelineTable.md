# MaPipelineTable

## Описание (Purpose)

Таблица «M&A Pipeline» вкладки «Сделки» клиента по ТЗ MS0014 §4.8: ID · наименование · сумма · дата · чип статуса · дата. Рисует общий рендер реестров в компактном режиме: заголовок вместо фильтра, по 10 строк.

## Раскладка (Layout)

```
Tile headless
└── dtable: заголовок · таблица · пагинация
```

| Компонент | Откуда | Варианты и ключевые параметры |
|---|---|---|
| Tile | ДС | headless |
| Table | ДС | компактный режим общего рендера |
| Chip | ДС | статус — rounded info |
| Pagination | ДС | по 10 |

## Переполнение (Overflow)

| Случай | Правило |
|---|---|
| Длинный текст в поле | перенос по словам; заголовки и подписи — усечение с тултипом компонента ДС |
| Много строк или записей | не применимо |
| Узкая ширина | сетка полей в одну колонку по ширине самого компонента (container query) |
| Полная ширина | сетка полей по паспорту, лишнего воздуха нет |

## Поведение (Behavior)

Компонент только показывает строки. Колонка второй даты на снимке подписана «Дата» — смысл не ясен, в концепте «Дата закрытия» (допущение).
