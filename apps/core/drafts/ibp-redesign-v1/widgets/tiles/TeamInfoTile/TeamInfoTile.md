# TeamInfoTile

## Описание (Purpose)

Тайл команды клиента по ТЗ MS0014 §4.8. Два экземпляра: «Главный клиентский менеджер» (аватар, ФИО, табельный номер, роль) и «Команда клиента ДИД» (аватар, ФИО, роль; карандаш). Во фронтенде — один TeamInfoTile с заголовком и содержимым от страницы.

## Раскладка (Layout)

```
Tile
├── шапка: заголовок от страницы · карандаш (команда)
└── entity-list: Entity × N (аватар · ФИО · подпись)
```

## Компоненты (Components)

| Компонент | Откуда | Варианты и ключевые параметры |
|---|---|---|
| Tile | ДС | обычный |
| Entity | ДС | M, ведущий Avatar |
| Avatar | ДС | M, circular, инициалы |

## Поля (Fields)

| Поле | Смысл | Тип, единица | Источник | Обязательное |
|---|---|---|---|---|
| Сотрудник | ФИО и инициалы | Entity | data/employees.js | нет |
| Роль |  | строка | data/clients.js (team.roleCode), data/dictionaries.js | нет |
| Табельный номер | главный КМ | строка | data/employees.js (id) | нет |

Порядок строк — порядок отображения. Имя поля — как в описании типа демо-данных.
Незаполненное поле — прочерк на своём месте, с места не уходит.

## Права (Permissions)

| Роль | Просмотр | Редактирование |
|---|---|---|
| Аналитик ДИД | да | не воссоздаётся в части 1 (Р6) |

## Состояния (States)

| Состояние | Есть в продукте | Вид |
|---|---|---|
| Загрузка (Loading) | да | каркас тайла и скелетоны строк (`.lc-team-info__loading`) |
| Данные есть | да | базовый вид |
| Заполнено частично | да | незаполненное поле — прочерк на своём месте |
| Данных нет (Empty) | да | строка причины без иллюстрации (`.lc-team-info__empty`) |
| Ошибка (Error) | да | Alert внутри компонента с повтором (`.lc-team-info__error`) |
| Обновление | да | прежние значения видны; локальной индикации в прототипе нет |
| Редактирование доступно | нет | в части 1 правка не воссоздаётся (Р6): точки входа видны, по клику ничего |
| Только просмотр (Disabled) | да | `data-mode="view"`: действия правки не рисуются |
| Нет права видеть | не решено (10.10.2026) | компонент не ставится экраном |

## Переполнение (Overflow)

| Случай | Правило |
|---|---|
| Длинный текст в поле | перенос по словам; заголовки и подписи — усечение с тултипом компонента ДС |
