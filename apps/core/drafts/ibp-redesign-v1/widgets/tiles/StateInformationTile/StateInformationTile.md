# StateInformationTile

## Описание (Purpose)

Тайл «Статус» страницы сделки по снимку системы (ТЗ MS0014 §4.3): статус, стадия, вероятность сделки, чекбоксы «Согласован One Pager» и «Пройден ПИК / ИК». У выбывшей сделки (архив) добавляются «Причина выбытия» и «Комментарий». После «Взять в работу» тайл показывает стадию «Проработка идеи сделки» (ревью MS0014, С8).

## Раскладка (Layout)

```
Tile
├── шапка: «Статус» · карандаш
└── tile__grid 2 колонки
    ├── Статус · Стадия
    ├── Причина выбытия · Комментарий (у выбывшей)
    ├── ProgressBar «Вероятность сделки» (на всю ширину)
    └── чекбоксы One Pager, ПИК / ИК (на всю ширину)
```
