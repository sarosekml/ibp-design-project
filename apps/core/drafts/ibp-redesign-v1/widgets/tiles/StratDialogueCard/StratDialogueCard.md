# StratDialogueCard

## Описание (Purpose)

Карточка цели по ТЗ MS0014 §4.8 (вкладка «Цели»): чип типа («Бизнес», «Личная», «Стратегическая цель», «Цифровая трансформация»), период с `calendar`, заголовок, «Метрика», «Значение», «Комментарий», участники (аватар, ФИО, роль). Во фронтенде — StratDialogueCard с частями StratDialogueBadge и StratDialogueUser.

## Раскладка (Layout)

```
Tile Card
├── шапка: чипы типа и периода · заголовок
└── тело
    ├── tile__grid 2: Метрика · Значение · Комментарий (на всю ширину)
    └── entity-list: участники (Entity S, Avatar S)
```

## Переполнение (Overflow)

| Случай | Правило |
|---|---|
| Длинный текст в поле | заголовок — до двух строк с многоточием (`.tile__title`), ФИО — усечение |
| Много строк или записей | карточки идут рядами по три |
| Узкая ширина | по две в ряд (container query экрана) |
| Полная ширина | сетка полей по паспорту, лишнего воздуха нет |

## Поведение (Behavior)

Компонент только показывает значения. Сетку карточек строит `list(goals)`: число карточек — по данным.
