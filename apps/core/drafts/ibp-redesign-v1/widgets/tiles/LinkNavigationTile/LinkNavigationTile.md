# LinkNavigationTile

## Описание (Purpose)

Плитка со ссылками страницы «Администрирование» по ТЗ MS0014 §4.11: заголовок, пояснение, ссылки — плоским списком или группами с подписью («Сотрудники», «Задачи», «География»). Живая ссылка одна — «Статусы задач»; остальные вне объёма (Р5): выглядят как живые, клик гасится (ревью MS0014, З1).

## Раскладка (Layout)

```
Tile
├── шапка: заголовок, подзаголовок-пояснение
└── сетка групп (1–4 колонки): подпись группы · ссылки столбцом
```

## Компоненты (Components)

| Компонент | Откуда | Варианты и ключевые параметры |
|---|---|---|
| Tile | ДС | обычный, `.tile__subtitle` |
| Link | ДС | accent M; вне объёма — `data-inert` |

## Поля (Fields)

| Поле | Смысл | Тип, единица | Источник | Обязательное |
|---|---|---|---|---|
| Заголовок, пояснение |  | строки | страница AdminPage | нет |
| Группы ссылок | подпись и ссылки | список | страница AdminPage | нет |

Порядок строк — порядок отображения. Имя поля — как в описании типа демо-данных.
Незаполненное поле — прочерк на своём месте, с места не уходит.

## Состояния (States)

| Состояние | Есть в продукте | Вид |
|---|---|---|
| Загрузка (Loading) | да | каркас тайла и скелетоны строк (`.lc-link-nav__loading`) |
| Данные есть | да | базовый вид |
| Заполнено частично | да | незаполненное поле — прочерк на своём месте |
| Данных нет (Empty) | да | строка причины без иллюстрации (`.lc-link-nav__empty`) |
| Ошибка (Error) | да | Alert внутри компонента с повтором (`.lc-link-nav__error`) |
| Обновление | да | прежние значения видны; локальной индикации в прототипе нет |
| Редактирование доступно | нет | в части 1 правка не воссоздаётся (Р6): точки входа видны, по клику ничего |
| Только просмотр (Disabled) | да | `data-mode="view"`: действия правки не рисуются |
| Нет права видеть | не решено (10.10.2026) | компонент не ставится экраном |

## Переполнение (Overflow)

| Случай | Правило |
|---|---|
| Длинный текст в поле | перенос по словам; заголовки и подписи — усечение с тултипом компонента ДС |
| Много строк или записей | не применимо |
| Узкая ширина | сетка полей в одну колонку по ширине самого компонента (container query) |
| Полная ширина | сетка полей по паспорту, лишнего воздуха нет |

## Поведение (Behavior)

- «Статусы задач» → TaskStatesPage.
- Остальные ссылки — по клику ничего (Р5), вид как у живых (З1).
