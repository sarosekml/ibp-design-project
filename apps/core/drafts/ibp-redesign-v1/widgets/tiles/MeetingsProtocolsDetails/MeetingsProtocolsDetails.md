# MeetingsProtocolsDetails

## Описание (Purpose)

Правая панель реестра встреч: всё, что известно о встрече, без перехода на отдельную страницу. Источник встречи — лид («Потенциал»), клиент или сделка ДИД — ссылка на свою страницу. Состав — снимок системы и Pixso «Встречи – Предпросмотр»: общая информация строками с иконкой, участники с обеих сторон, признаки встречи, повестка с задачами и связи. Ранее назывался MeetingPreviewTile (MS0014), переименован по имени фронтенда (MS0014a).

## Раскладка (Layout)

```
Tile
├── шапка: «Встреча M-… от …» + чип статуса, строка «дата, время, место, UTC» · правка · закрыть
└── тело
    ├── действия: «Создать лид» · «Завершить» · «Отменить» (у запланированной)
    ├── Источник встречи: тип + Link
    ├── две колонки: Общая информация (Entity с иконкой) | Участники (Entity с Avatar)
    ├── Checkbox × 3 (только чтение)
    ├── Повестка встречи: Tile Inset на тему, задачи — Entity с чипами и «Исполнить»
    └── Связи: подпись + Link
```

## Поведение (Behavior)

- «Завершить», «Отменить» → `onAction(finish|cancel)`: страница показывает подтверждение и меняет статус (Р7);
- «Исполнить» у задачи повестки → `onAction(doTask, task)`;
- крестик → `onAction(close)`, страница закрывает панель;
- «Создать лид» и карандаш — по клику ничего (Р6), лид из встречи появится в MS0015;
- ссылки источника и связей ведут на страницы лида, клиента или сделки.

### Связанные артефакты

| Триггер | Тип | Что внутри | Что меняется после | Кто ещё вызывает |
|---|---|---|---|---|
| «Завершить» / «Отменить» | окно подтверждения страницы | текст подтверждения | статус встречи, строка реестра | вкладка «Встречи» клиента |
| «Исполнить» в повестке | модальное окно | ChangeTaskStatusModal | статус задачи | TaskPreviewTile |
