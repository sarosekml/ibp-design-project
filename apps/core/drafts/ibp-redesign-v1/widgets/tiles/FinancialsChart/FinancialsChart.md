# FinancialsChart

## Описание (Purpose)

Тайл «Выручка» вкладки «Финансовые показатели» по ТЗ MS0014 §4.8: значение («346,27 млн RUB»), рост («↑ 12.6% гг»), выбор метрики и периода («36 месяцев»), график combo по кварталам — «Чистый долг» линией и «Чистый долг/EBITDA» столбцами; легенда — Chart ДС.

## Раскладка (Layout)

```
Tile
├── шапка: «Выручка» · метрика ▾ · период ▾
└── тело
    ├── ReadOnlyField «Выручка» + Badge роста
    └── Chart combo (легенда, перекрестие)
```
