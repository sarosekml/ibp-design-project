# ClientCreditsList

## Описание (Purpose)

Карточки кредитов вкладки «Кредиты» по ТЗ MS0014 §4.8. Действующий кредит: чип вида (три тона), период, иконка документа, название и номер, метрики — видны всегда; раскрытая карточка — таблицы «Сроки» и «Финансовые показатели» на вложенных Tile Inset. Кредит в Pipeline: «Оборотный кредит», КФЮЛ ID, этап (чип «В работе»), ставка, валюта, сумма; раскрытая — «Данные по сделке» и «Описание сделки».

## Раскладка (Layout)

```
.tile-stack страницы → .lc-client-credits (flex-колонка, --space-16)
└── Tile accordion × N (частичный коллапс)
    ├── шапка: чипы вида и периода · иконка документа · название · шеврон
    ├── .tile__body: tile__grid 4 — метрики (видны всегда)
    └── .tile__collapsible: Tile Inset × 2 — таблицы
```
