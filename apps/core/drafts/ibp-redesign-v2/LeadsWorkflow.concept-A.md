# LeadsWorkflow — концепт A (Консервативный)

## Суть
Один лид, общий реестр и доска на существующих компонентах ДС.
Рассмотрение остаётся первой колонкой; путь открывается кнопкой в Drawer.

## Состав
| Экран / блок | Чем собран (компонент ДС) | Колонки из 12 | Что внутри |
|---|---|---|---|
| Главная / шапка | PageHeader, SegmentControl | 12 | «Мои проекты», неделя 42, новый лид, Доска / Таблица |
| Главная / сводка | Entity, Chip, Note | 12 | Подборка, в работе, встречи недели; отдельная подпись периода для Q4; ссылка на клиентов плана |
| Главная / представления | Tab | 12 | Активные, Передано в Pipeline, Клиент отказался; финалы отображаются таблицей |
| Главная / фильтр | TableFilter, Chip | 12 | Клиент плана, основание, продукт, ответственный; одна выборка доски и таблицы |
| Главная / доска | Kanban, Tile, Chip, Badge, Avatar | 12 | 7 колонок: Рассмотрение, Идея, В проработке, Встреча назначена, Встреча проведена, Вторая встреча проведена, Подготовка документов |

## Отличия от соседних концептов
| Решение | A | Цена |
|---|---|---|
| Рассмотрение | Первая колонка | Сохраняет исходный образ доски пользователя |
| Финалы | Вкладки с таблицами | На активной доске их нельзя использовать как зоны переноса |
| Путь | Штатный Drawer | Модальный просмотр временно закрывает взаимодействие со страницей; плавающий виджет из ТЗ не реализуется |
| Основания | Текстовые Chip без новых иконок | Не требуется расширять анатомию карточки |
| Подборка | Те же карточки первой колонки | Решение через кебаб или предпросмотр, без новых быстрых кнопок |

## Геометрия и приоритет
| Условие | Решение |
|---|---|
| 7 колонок по 288 | Трек 2016 px; горизонтальный скролл ожидаем даже на FHD |
| Более узкое окно или закреплённое меню | Не сжимать карточки; доступны штатный скролл и Таблица |
| Высота | `.screen--app`; хост доски `flex:1; min-height:0`; оба скролла — у viewport, отдельного скролла колонок нет |
| Первый экран | Сводка компактна; основная высота отдана работе с карточками |
| Детальная страница | Верх отвечает «кто / откуда / что дальше»; длинные списки вынесены на полную ширину |

## Предложения к расширению ДС
Нет. A показывает границу существующей ДС, включая отсутствие плавающего пути.

## Общие правила и интеграция
| Область | Условие сборки |
|---|---|
| Единица работы | Вариант с лидом; отдельного проекта нет — требует ответа на вопрос 1 |
| Стадии | Черновик MS0015 §4; не становится утверждённым правилом до ответа человека |
| Данные | Адаптер поверх данных v2; исходные объекты не дублируются в слое лида |
| Основание | Ссылки через актуальную карту `data/nav-links.js`; старые имена из ТЗ заменяются именами MS0014a |
| Отмена | Перенос через `kanban:beforemove`; SnackBar с Отменить; диалог только для недостающих данных / причины |
| История | События и критерии в одной матрице `lead-stages.js`; история отображается Table |
| КФЮЛ | Источник отсутствует в базе MS0014; не создавать фиктивную страницу или пустую ссылку |
| Было / стало | В v2 остаются локальные страницы части 1; v1 не участвует в изменяемом состоянии |
