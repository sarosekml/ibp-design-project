# Page: HomePage — Главная (Аналитик ДИД)

## 1. Назначение (Purpose)

Стартовая страница роли «Аналитик ДИД»: вход во все разделы прототипа плитками
по группам и через боковое меню. Воссоздаёт главную стенда ift «как сейчас» —
контекст для сравнения с новой главной задачи MS0015.

**Роль пользователя:** Аналитик ДИД (демо-пользователь «Ким А. С.», деск
«SMB Природные ресурсы +6» — допущение агента из ТЗ §3, тот же персонаж, что
в new-dashboard-mvp).
**Права:** просмотр каталога разделов роли; правка на главной отсутствует.

## 2. Адрес и навигация (Route)

- **Адрес в продукте:** `/` (стенд ift).
- **Пункт бокового меню** в состоянии `nav__item--selected`: «Главная».

| Уровень крошек | Текст | Ссылка |
|---|---|---|
| 1 (текущий) | Главная | — |

Строка пользователя в футере меню ведёт на хаб проектов
(`../../../../../index.html`, `aria-label="Хаб проектов"`).

## 3. Раскладка (Layout)

```
Page (Layout, nav--rail)
└── Grid 12, gap 16/24, фон — background-illustration (opacity .6)
    ├── Группа «Origination»       — 7 плиток NavTile
    ├── Группа «Pipeline»          — 4 плитки
    ├── Группа «Текущий портфель ДИД» — 3 плитки
    ├── Группа «Отчёты»            — 1 плитка со ссылками (Отчёты для Рисков)
    ├── Группа «Клиенты и задачи»  — 3 плитки
    └── Группа «Администрирование» — 2 плитки
```

Группы — `section.home-group.col-3.colw-6` в `.grid12` (4 группы в ряд на
широкой рабочей области, 2 при закреплении панели, 1 на узкой — контейнерные
запросы экрана). Заголовок группы — `h2.home-group__head` (подпись-разделитель).
Плитки строит `IBPHome.tileHTML` из каталога роли; группы и пункты меню —
`IBPHome.itemsFor('Аналитик ДИД')`.

## 6. Поведение (Behavior)

| Триггер | Результат |
|---|---|
| Клик по плитке с разделом части 1 | переход на страницу раздела (карта `NAV_LINKS`) |
| Клик по плитке вне объёма части 1 (Pipeline ЦКП, M&A Pipeline, Календарь КПКИ, Текущий портфель ДИД, CF СБИ, Корпоративные запросы, Отчёты для Рисков, Отчеты Qliksense) | ничего: адрес не меняется, окна и сообщения нет (Р5); вид плитки — как у живой, без бледного состояния (ревью MS0014, З1) |
| Клик по ссылке плитки «Отчёты для Рисков» | ничего (Р5) |
| Клик по пункту меню с разделом части 1 | переход на страницу раздела |
| Клик по пункту меню вне объёма части 1 | ничего (Р5) |
| Клик «Главная» в меню | остаётся на этой странице |
| Клик по строке пользователя (футер) | переход на хаб проектов |
| Сужение рабочей области до 1700px | группы перестраиваются 4 → 2 в ряд |
| Сужение рабочей области до 900px | группы в один столбец |
| Кнопка выхода (футер меню) | ничего — смены роли в прототипе нет |

Плитки «Лиды» и «Встречи» без иллюстрации: пустое имя `data-illu=""` снимается
при сборке плитки (иначе запрос `.svg` без имени даёт 404), слот рисуется
штриховой заглушкой `.illu:empty` (в ДС иллюстраций нет — открытый вопрос 12 ТЗ).

## 8. Состояния (States)

### Loading
Не моделируется: каталог роли статичен, загрузка мгновенная.

### Empty
Не бывает: у роли всегда есть группы.

### Error
Не моделируется в части 1.

### Disabled
Пункты и плитки вне объёма части 1 (Р5) видны как обычные, но ссылки не
несут (`role="link" aria-disabled="true"`), курсор не меняется на строго
указательный — отклонение от системы, принято для части 1.

## 12. Доступность

- `<nav aria-label="Главное меню">`, `<nav aria-label="Хлебные крошки">`;
- заголовок «Главная» в крошках — `aria-current="page"`;
- заголовки групп — `h2` (на странице нет `h1`: заголовком страницы служит
  крошка; отклонение от шаблона PageHeader — у главной стенда шапки нет);
- у всех кнопок-иконок есть `aria-label`;
- пункты вне объёма части 1 помечены `aria-disabled="true"`.
