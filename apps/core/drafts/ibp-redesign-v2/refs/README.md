# Проверка демонстрационного процесса

`node apps/core/drafts/ibp-redesign-v2/refs/lead-workflow-check.mjs` проверяет
адаптер, ссылки, переходы, две встречи, передачу, отмену, сохранение и возврат.
Это Node-прогон данных без браузера; поведение DOM и фактическая геометрия
проверяются отдельно. Исходные файлы и браузерное сохранение он не меняет.
