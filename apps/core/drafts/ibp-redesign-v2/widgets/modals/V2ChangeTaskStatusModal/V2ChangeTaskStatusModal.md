# V2ChangeTaskStatusModal

## Описание (Purpose)

Окно действий Р7 над задачей: подтверждение смены статуса («Исполнить» →
DONE, «Отменить» → CANCELLED). Внутренняя ветка `reassign` с полем исполнителя
не вызывается прототипом: «Переназначить» без действия по Р6 и Б7 MS0014a.
После подтверждения страница
обновляет реестр и предпросмотр, SnackBar подтверждает действие; последствия
видны в предпросмотре (статус, исполнитель, история).

## Раскладка (Layout)

```
Modal (w4)
├── шапка — заголовок по действию + крестик
├── тело — текст «Задача N — Название — последствие»; поле исполнителя (reassign)
└── подвал — Отмена / Подтвердить
```
