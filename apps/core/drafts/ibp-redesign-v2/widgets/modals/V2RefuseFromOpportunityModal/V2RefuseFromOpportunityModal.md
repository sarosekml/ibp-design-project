# V2RefuseFromOpportunityModal

## Описание (Purpose)

Окно отказа от сделки (Р7 ТЗ): причина обязательна, комментарий необязателен.
Известна единственная причина «Срок ожидания истек» (открытый вопрос 3 ТЗ —
справочника нет), поэтому список состоит из одного значения и подставлен в
поле сразу. Подтверждение переводит сделку во вкладку «В архиве» её реестра
(статус «Выбыла», стадия «Работа прекращена»), причина и комментарий
сохраняются в демо-данных и видны в колонках архива.

## Раскладка (Layout)

```
Modal (w4)
├── шапка — «Отказаться от сделки» + крестик
├── тело — текст с номером сделки; причина (InputText + DropdownList);
│   комментарий (InputText)
└── подвал — справа «Отмена» (transparent) + «Отказаться» (accent)
```

## Обязательность заполнения (Required)

- Компонент обязателен к заполнению целиком: да (причина).
- Обязательные поля внутри: «Причина отказа».
- Что показывает, когда обязательное не заполнено: причина предзаполнена единственным известным значением — пустым не бывает.
- Что отдаёт наружу: `{ reasonCode, comment }` — страница вызывает `IBPR.refuse(id, rq)`.
