# V2TakeOpportunityToWorkModal

## Описание (Purpose)

Окно подтверждения действия «Взять в работу» (Р7 ТЗ). Состав полей окна
фронтенда неизвестен (открытый вопрос 2 ТЗ), поэтому здесь окно-подтверждение
без полей: текст объясняет последствие, главная кнопка выполняет его.
Подтверждение меняет демо-данные: сделка уходит в Pipeline «Сделки моего
деска» (стадия «Проработка идеи сделки»), исчезает из реестра-источника,
строка помечается просмотренной; результат виден в соседнем реестре Pipeline
и SnackBar.

## Раскладка (Layout)

```
Modal (w3)
├── шапка — «Взять сделку в работу» + крестик
├── тело — текст подтверждения с номером сделки
└── подвал — справа «Отмена» (transparent) + «Взять в работу» (accent)
```
