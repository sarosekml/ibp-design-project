## Обязательность заполнения (Required)

Обязательные поля и критерии — одна матрица data/lead-stages.js. Недостающие поля показаны при передаче; действие disabled, заполнение доступно ссылками.

## Переполнение (Overflow)

| Случай | Правило |
|---|---|
| Длинное значение | ReadOnlyField и перенос в полном ряду |
| Много событий | Полная ширина таблицы / прокрутка тела Popover |
| Узкая область | Перестроение полей по ширине, путь свёрнут |
| Полная ширина | Поля группируются по смыслу |

## Поведение (Behavior)

Действие → изменение через LEADS, затем обновление всех представлений. Перенос и решения отменяются SnackBar. Путь: раскрыть / свернуть / скрыть; Escape сворачивает, состояние сохраняется отдельно от данных лида. Модальные слои и фокус обслуживает DSModal.
