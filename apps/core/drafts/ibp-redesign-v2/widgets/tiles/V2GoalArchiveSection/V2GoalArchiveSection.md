# V2GoalArchiveSection

## Описание (Purpose)

Аккордеоны «Архив 2025» (раскрыт), «Архив 2024», «Архив 2023» вкладки «Цели» по ТЗ MS0014 §4.8. Внутри — сетка карточек V2StratDialogueCard. Сворачивание — Tile ДС в варианте accordion.

```
Tile accordion
├── шапка: «Архив YYYY» · шеврон (.tile__toggle)
└── .tile__collapsible > .tile__body: сетка V2StratDialogueCard
```
