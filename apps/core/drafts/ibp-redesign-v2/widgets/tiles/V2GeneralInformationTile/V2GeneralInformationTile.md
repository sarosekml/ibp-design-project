# V2GeneralInformationTile

## Описание (Purpose)

Тайл «Общая информация» страницы сделки и страницы лида. Во фронтенде это два виджета с одним именем в двух модулях; в концепте — один виджет с вариантом (MS0014a, правило 6). Вариант сделки — по снимку системы (ТЗ MS0014 §4.3): чипы клиента «Компания роста ДИД» и «Топ клиент», проект, приоритет, ТБ и ГОСБ (у обязательных — значок предупреждения), тип недвижимости, источник «Маршрутизация», чекбоксы только для чтения, документы. Вариант лида — по ТЗ §4.6: чип статуса, идея сделки, даты создания и последней активности.

## Раскладка (Layout)

```
Tile
├── шапка: «Общая информация» · карандаш
└── тело
    ├── tile__chiplist: чипы клиента (сделка) или статуса (лид)
    ├── вариант opportunity: tile__grid 2 колонки
    │   ├── Проект · Приоритет (чип)
    │   ├── Территориальный банк · ГОСБ (значок alert-triangle)
    │   ├── Тип недвижимости · Источник сделки (чип star)
    │   ├── чекбоксы (на всю ширину)
    │   ├── Divider
    │   └── «Документы по сделке» · «Презентация для ПИК»
    └── вариант potential: tile__grid 2 колонки
        ├── Идея сделки (на всю ширину)
        └── Дата создания · Дата последней активности
```
