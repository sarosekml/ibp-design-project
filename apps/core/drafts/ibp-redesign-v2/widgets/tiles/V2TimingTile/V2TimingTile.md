# V2TimingTile

## Описание (Purpose)

Тайл «Сроки» по ТЗ MS0014 §4.3: четыре даты столбцом. У лида во фронтенде похожий тайл TimingsTile; на странице лида части 1 его нет — когда появится, ставится этот же виджет (MS0014a, правило 6).

## Раскладка (Layout)

```
Tile
├── шапка: «Сроки» · карандаш
└── tile__rows: ReadOnlyField × 4
```

| Поле | Смысл | Тип, единица | Источник | Обязательное |
|---|---|---|---|---|
| Дата начала работы |  | дата | data/opportunities.js | нет |
| Планируемая дата КПКИ |  | дата | data/opportunities.js | нет |
| Плановая дата подписания |  | дата | data/opportunities.js | нет |
| Планируемая дата выдачи |  | дата | data/opportunities.js | нет |

Порядок строк — порядок отображения. Имя поля — как в описании типа демо-данных.
Незаполненное поле — прочерк на своём месте, с места не уходит.

## Состояния (States)

| Состояние | Есть в продукте | Вид |
|---|---|---|
| Загрузка (Loading) | да | каркас тайла и скелетоны строк (`.lc-timing__loading`) |
| Данные есть | да | базовый вид |
| Заполнено частично | да | незаполненное поле — прочерк на своём месте |
| Данных нет (Empty) | да | строка причины без иллюстрации (`.lc-timing__empty`) |
| Ошибка (Error) | да | Alert внутри компонента с повтором (`.lc-timing__error`) |
| Обновление | да | прежние значения видны; локальной индикации в прототипе нет |
| Редактирование доступно | нет | в части 1 правка не воссоздаётся (Р6): точки входа видны, по клику ничего |
| Только просмотр (Disabled) | да | `data-mode="view"`: действия правки не рисуются |
| Нет права видеть | не решено (10.10.2026) | компонент не ставится экраном |
