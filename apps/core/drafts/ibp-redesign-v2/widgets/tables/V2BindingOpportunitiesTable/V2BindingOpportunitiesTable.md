# V2BindingOpportunitiesTable

## Описание (Purpose)

Реестр раздела «обязательных сделок» — «Сделки с продуктами ДИД, и/или А-риском» — источник сделок для аналитика ДИД. Вкладка — подфильтр одной таблицы (Р4 MS0014): колонки общие, строки отбираются по вкладке; адрес вкладки — имя страницы фронтенда (`?tab=`). Строка ведёт на страницу сделки; иконки «Действия» открывают окна «Взять в работу» и «Отказаться». Непросмотренная строка источника подсвечена модификатором `tbl__row--accent` и снимается после открытия сделки.

## Раскладка (Layout)


## Переполнение (Overflow)

| Случай | Правило |
|---|---|
| Длинный текст в поле | текст ячейки усекается (`tc__text--truncate`), полное значение — тултипом Table |
| Много строк или записей | пагинация по 50 строк, выбор размера страницы |
| Узкая ширина | горизонтальный скролл тела, первая колонка закреплена |
| Полная ширина | резиновые колонки (fr) делят остаток |

## Поведение (Behavior)

- клик по ID → страница сделки (`Opportunity.preview.html?source=&id=&tab=`), строка помечается просмотренной;
- «Взять в работу» → окно подтверждения → сделка уходит в Pipeline «Сделки моего деска»; «Отказаться» → окно с причиной → вкладка «В архиве» (Р7);
- «Фильтр» → модалка `.tfm`; «Применить» отбирает строки подстрокой по полю и показывает чип «Применено: N»; крестик чипа сбрасывает фильтр целиком;
- «Краткий отчет» → Toast «Файл выгружен»;
- вкладка → подфильтр строк, `?tab=<страница фронтенда>`.
