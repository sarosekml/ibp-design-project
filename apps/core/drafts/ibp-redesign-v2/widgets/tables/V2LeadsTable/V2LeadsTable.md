# V2LeadsTable

## Описание (Purpose)

Один реестр на три раздела лидов. Вид лида задаёт конфиг реестра: «Лиды» — вкладкой (лиды ДИД, лиды для КМ), «Обязательные лиды» и «Возможные лиды» — своим видом. Колонки «Обязательных» и «Возможных» — по Pixso (вкладка «Сделки → Лиды» клиента), снимка разделов нет (Р4). Во фронтенде и API лид — «потенциал»: строка ведёт на PotentialPage.

## Раскладка (Layout)

```
Tile headless
├── Alert ошибки (__error)
└── Table (.dtable--fill): TableFilter · «Краткий отчет» · строки · Pagination
```

## Поведение (Behavior)

- клик по ID → страница лида;
- «Фильтр» → `.tfm`, «Применить» отбирает строки, чип «Применено: N»;
- «Краткий отчет» → Toast «Файл выгружен»;
- вкладки «Лиды» / «Лиды для КМ» → подфильтр, `?tab=LeadsPage | LeadsForCmPage`.
