# V2TaskHistoryTable

## Описание (Purpose)

История задачи из MS0014 §4.10 и MS0014a §4.2. Содержит события выбранной задачи; изменения статуса добавляют событие через общий store. Отдельный виджет с именем фронтенда вшивается в TaskPreviewTile и используется на странице задач и вкладке клиента.

## Раскладка (Layout)

```
Tile headless + Table
└── dtable__body (внутренняя прокрутка)
    └── TableCell: шапка + строки событий
```

## Компоненты (Components)

| Компонент | Откуда | Варианты и ключевые параметры |
|---|---|---|
| Tile | ДС | headless |
| Table · TableCell | ДС | 6 колонок, разделители, изменение ширины |
| Chip | ДС | статус — rounded S, приоритет — S |
| Skeleton · Alert · EmptyState | ДС | loading, error, empty |

## Поля (Fields)

| Поле | Смысл | Тип, единица | Источник | Обязательное |
|---|---|---|---|---|
| date | Дата события | ISO date → ДД.ММ.ГГГГ | task.history | да |
| event | Событие | string | task.history | да |
| name | Название задачи | string | task.history | да |
| statusCode | Статус задачи при событии | enum | task.history | да |
| description | Описание события | string | task.history | нет |
| priorityCode | Приоритет | enum | task.history | нет |

Незаполненные значения остаются на месте как прочерк. Порядок событий — из данных, не придумывается таблицей.

## Права (Permissions)

| Роль | Просмотр | Редактирование |
|---|---|---|
| Аналитик ДИД | да | нет; события добавляет действие задачи |

## Состояния (States)

| Состояние | Есть в продукте | Вид |
|---|---|---|
| Загрузка (Loading) | состояние компонента | Skeleton, таблица скрыта |
| Данные есть | да | шапка и события |
| Заполнено частично | да | прочерки в пустых полях |
| Данных нет (Empty) | да | EmptyState «История отсутствует» |
| Ошибка (Error) | состояние компонента | Alert «Не удалось загрузить историю задачи» |
| Обновление | состояние компонента | прежние данные до следующего render |
| Редактирование доступно | нет | таблица только для чтения |
| Только просмотр (Disabled) | да | все данные видны, изменений нет |
| Нет права видеть | не моделируется | родитель не показывает компонент |

## Обязательность заполнения (Required)

Нет: отсутствие событий допустимо. Обязательные поля событий — в разделе «Поля». Компонент не валидирует задачу и ничего не сохраняет.

## Переполнение (Overflow)

| Случай | Правило |
|---|---|
| Длинные название, событие, описание | tc__text--truncate, Tooltip ДС |

| Узкая ширина | горизонтальная прокрутка dtable__body |

## Поведение (Behavior)

| Триггер | Результат |
|---|---|

| Перетаскивание ручки колонки | ширину меняет Table ДС |

## Для разработчиков (Implementation)

### Параметры метки (Props)

| Атрибут метки | На корне компонента | Значения | Смысл |
|---|---|---|---|
| state | data-state | loading, data, partial, empty, error, updating | состояние данных |
| mode | data-mode | view | только просмотр |

`LcTaskHistoryTable.render(host, { task })` вызывается родителем. Страницы TasksPage и ClientInfoPage собирают HTML-фрагмент в `template#task-history-template`; V2TaskPreviewTile клонирует его в своё место истории. Рендер строк один, дубликата в V2TaskPreviewTile нет. После обновления строки связывает DSTable.
