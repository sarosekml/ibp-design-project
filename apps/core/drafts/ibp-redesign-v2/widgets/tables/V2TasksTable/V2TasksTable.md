# V2TasksTable

## Описание (Purpose)

Левая панель раздела «Задачи». Колонки — снимок системы: № · Клиент · Холдинг · Название · Описание задачи · Статус · Приоритет · Срок исполнения · Тип задачи · Исполнитель · Дата создания · Инициатор · Связанный объект · Номер связанного объекта. Таблица шире панели — горизонтальный скролл, как в системе. Клик по строке выбирает задачу, её карточку показывает V2TaskPreviewTile справа.

## Раскладка (Layout)

```
Tile headless
└── Table (.dtable--fill): TableFilter · «Краткий отчет» · строки · Pagination
```

## Состояния (States)

| Состояние | Есть в продукте | Вид |

## Переполнение (Overflow)

| Случай | Правило |
|---|---|
| Длинный текст в поле | усечение с тултипом Table |
| Много строк или записей | пагинация по 50 строк |
| Узкая ширина | горизонтальный скролл тела внутри левой панели |
| Полная ширина | резиновые колонки |

## Поведение (Behavior)

- клик по строке → выбор и `onSelect(task)`;
- номер связанного объекта → его страница;
- «Фильтр» → `.tfm`, чип «Применено: N»;
- «Краткий отчет» → Toast «Файл выгружен»;
- вкладки — подфильтр (`setTab`), `?tab=TasksPage | TasksOfMyDeskPage`.
