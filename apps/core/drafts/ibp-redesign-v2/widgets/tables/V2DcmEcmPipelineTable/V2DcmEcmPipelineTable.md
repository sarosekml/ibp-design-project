# V2DcmEcmPipelineTable

## Описание (Purpose)

Таблицы «Pipeline DCM» (ID · Наименование сделки · Ожидаемый доход, млн RUB · Ожидаемая дата дохода) и «Pipeline ECM» (ID · Проект · Ожидаемый доход · Дата комиссионного дохода; пусто — «Нет данных») по ТЗ MS0014 §4.8. Один виджет с видом, как во фронтенде; рисует общий рендер реестров в компактном режиме.

## Раскладка (Layout)

```
Tile headless
└── dtable: заголовок · таблица · пагинация
```
