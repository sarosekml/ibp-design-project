# TasksTile

## Описание (Purpose)

Открытые задачи в порядке срочности: просроченные (самая старая первой),
со сроком сегодня (по приоритету), будущие (по сроку). Строка — приоритет,
формулировка, сделка и клиент, срок и статус. Переключатель — свои задачи или
все задачи деска; у задач коллег в строке исполнитель. Три счётчика —
выборки: «Новые» (с пояснением, сколько пришло сегодня), «Сегодня»,
«Просрочено» (с возрастом самой старой).

Свою новую задачу берут в работу кнопкой в строке; меню строки — «Вернуть в
новые», «Отметить выполненной», «Открыть в разделе «Задачи»». Смена статуса
подтверждается уведомлением с отменой. Тайл показывает до пяти задач; пара
во фронтенде у раздела — `tasks-app` (`TasksPage`, `TasksOfMyDeskPage`).

## Раскладка (Layout)

```
Tile (иконка tasks accent, «Задачи»; действия: Spinner в обновлении, «Все задачи», меню)
└── тело (колонка)
    ├── SegmentControl S fullwidth — Мои задачи · Задачи моего деска
    ├── 3 × StatCard M — Новые (accent) · Сегодня (warning) · Просрочено (error)
    ├── .entity-list — до 5 строк Entity M без ведущего элемента:
    │     Header: Badge dot + приоритет · Label: формулировка · Subs: исполнитель, сделка, клиент
    │     Chips: срок · «В работе» · Actions: «Взять в работу» (своя новая) · меню строки
    ├── строка «выборка пуста»
    ├── ContextMenu #lc-tasks-row-menu — одно на все строки
    └── подвал: Divider · «Все задачи» · «Показано N из M» · «Добавить»
```

## Права (Permissions)

| Роль | Просмотр | Редактирование |

| Аналитик ДИД | свои и деска | статус своих задач, создание задачи |

## Состояния (States)

| Состояние | Есть в продукте | Вид |
|---|---|---|
| Загрузка (Loading) | да | скелетоны трёх счётчиков и трёх строк |
| Данные есть | да | счётчики, до 5 строк, подвал |
| Заполнено частично | да | задача без сделки или клиента — «Без сделки и клиента» |
| Данных нет (Empty) | да | «Открытых задач нет» + «Новая задача» |
| Ошибка (Error) | да | Alert error «Не удалось загрузить задачи» + «Повторить» |
| Обновление | да | прежние строки на месте, в шапке Spinner S |
| Редактирование доступно | да | «Взять в работу», пункты смены статуса, «Добавить» |
| Только просмотр (Disabled) | да | кнопки и пунктов смены статуса нет |
| Нет права видеть | да | тайла нет на странице — решает страница |

### Свои состояния

| Состояние | Когда | Вид |
|---|---|---|
| Выборка | включён счётчик | только его задачи, счётчик выбран |
| Выборка пуста | у выборки нет задач | «Новых задач нет» / «Задач со сроком сегодня нет» / «Просроченных задач нет» |
| Список длиннее пяти | задач больше пяти | в подвале «Показано 5 из N» |
| Задача коллеги | `isMine = false` | исполнитель в Subs, без «Взять в работу», меню — только «Открыть в разделе» |

## Переполнение (Overflow)

| Случай | Правило |
|---|---|
| Длинный текст в поле | формулировка — одна строка с многоточием и тултипом; Subs — одна строка |
| Много строк или записей | до 5 строк, «Показано 5 из N», остальное — в разделе «Задачи» |
| Узкая ширина | до 420px своей ширины счётчики — в колонку |
| Полная ширина | без изменений |

## Поведение (Behavior)

| Триггер | Результат |
|---|---|
| Переключатель «Мои / деска» | список и счётчики другой выборки; фильтр снимается |
| Клик по счётчику | только его выборка; повторный клик — снять |
| «Взять в работу» в строке, меню → «Взять в работу» | статус `IN_PROGRESS`; уведомление «Задача взята в работу» с «Отменить» |
| Меню → «Вернуть в новые» | статус `NEW`; уведомление с «Отменить» |
| Меню → «Отметить выполненной» | статус `DONE`, строка уходит из списка; уведомление с «Отменить» |
| Меню → «Открыть в разделе «Задачи»», стрелка, «Все задачи» | событие перехода: уведомление страницы |
| Меню → «Обновить», «Повторить» | `updating` 0,9 с → данные |
| `HomeStore.focus('tasks', filter)` («Мой день») | выборка, переключатель «Мои», прокрутка, фокус на счётчик |

Меню строки рантайм ДС уносит в общий слой: задачу, чьё меню открыто, тайл
запоминает по триггеру до открытия (Л88), пункты показывает по её статусу.
