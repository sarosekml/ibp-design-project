# MeetingsTile

## Описание (Purpose)

Ближайшие встречи с клиентами, начиная с сегодняшних: дата, клиент, время,
ответственный и статус. Переключатель показывает свои встречи (сотрудник —
организатор или участник) или все встречи деска. Три счётчика — выборки
списка: «Сегодня», «На неделе» (семь дней с сегодняшнего), «Требует
внимания»; клик по счётчику показывает только его выборку, повторный —
снимает фильтр.

Тайл показывает до шести встреч; остальные — в разделе «Встречи» (в
прототипе раздела нет, переход показывает уведомление). Создание встречи —
окно `MeetingCreateModal` из подвала, меню шапки и пустого состояния.

## Раскладка (Layout)

```
Tile (иконка calendar accent, «Встречи»; действия: Spinner в обновлении, «Все встречи», меню)
└── тело (колонка)
    ├── SegmentControl S fullwidth — Мои встречи · Встречи моего деска
    ├── 3 × StatCard S — Сегодня (info) · На неделе · Требует внимания (warning)
    ├── .entity-list — до 6 строк Entity M: DateBadge · клиент · время и ответственный · Chip статуса
    ├── строка «выборка пуста»
    └── подвал: Divider · «Все встречи» · «Показано N из M» · «Добавить»
```

## Поля (Fields)

| Поле | Смысл | Тип, единица | Источник | Обязательное |
|---|---|---|---|---|
| `startDateTime` | дата (DateBadge) и время начала | ISO дата-время | `MeetingRsDto` | да |
| `clientName` | клиент | строка | `MeetingRsDto` | да |
| `endDateTime` | время окончания | ISO дата-время | `MeetingRsDto` | да |
| `organizerName` | ответственный | «Фамилия И. О.» | `MeetingRsDto` | да |
| `statusCode` | статус | `MeetingStatusCode` | `MeetingRsDto` | да |
| `topic` | тема — в тултипе Label | строка | `MeetingRsDto` | да |

Тоны статуса: `SCHEDULED` — dpurple «Встреча назначена», `NEEDS_ATTENTION` —
warning «Требует внимания», `PROTOCOL_DONE` — success «Протокол заполнен»,
`CANCELLED` — grey «Отменена» (отменённые на главную не попадают).

## Состояния (States)

| Состояние | Есть в продукте | Вид |
|---|---|---|
| Загрузка (Loading) | да | скелетоны трёх счётчиков и четырёх строк; переключателя и действий шапки нет |
| Данные есть | да | счётчики, до 6 строк, подвал |
| Заполнено частично | нет | у встречи все поля обязательны |
| Данных нет (Empty) | да | «Встреч пока нет» + «Новая встреча» (тайл на 4 колонках — без иллюстрации) |
| Ошибка (Error) | да | Alert error «Не удалось загрузить встречи» + «Повторить» |
| Обновление | да | прежние строки на месте, в шапке Spinner S |
| Редактирование доступно | да | «Добавить», «Новая встреча» в меню и в пустом тайле |
| Только просмотр (Disabled) | да | точек входа в создание нет |
| Нет права видеть | да | тайла нет на странице — решает страница |

### Свои состояния

| Состояние | Когда | Вид |
|---|---|---|
| Выборка | включён счётчик | только его встречи, счётчик выбран (`aria-pressed`) |
| Выборка пуста | у выборки нет встреч | строка «Сегодня встреч нет» / «На ближайшие семь дней встреч нет» / «Встреч, требующих внимания, нет» |
| Список длиннее шести | встреч больше шести | в подвале «Показано 6 из N» |

## Переполнение (Overflow)

| Случай | Правило |
|---|---|
| Длинный текст в поле | клиент — одна строка с многоточием и тултипом «клиент — тема»; подписи счётчиков — многоточие |
| Много строк или записей | до 6 строк, «Показано 6 из N», остальное — в разделе «Встречи» |
| Узкая ширина | до 300px своей ширины счётчики — в колонку |
| Полная ширина | без изменений |

## Поведение (Behavior)

| Триггер | Результат |
|---|---|
| Переключатель «Мои / деска» | список и счётчики другой выборки; фильтр счётчика снимается |
| Клик по счётчику | список — только его выборка; повторный клик — снять |
| Меню → «Обновить», Alert → «Повторить» | `updating` 0,9 с → данные |
| Стрелка шапки, «Все встречи» | событие перехода: страница показывает уведомление (раздела в прототипе нет) |
| `HomeStore.focus('meetings', filter)` («Мой день») | включается выборка, переключатель — «Мои», тайл прокручивается в зону видимости, фокус — на счётчик |
| Новая встреча сохранена (`HomeStore`, событие `meetings`) | список и счётчики пересчитываются |
