# HomeProfileTile

## Описание (Purpose)

Первый тайл главной: сотрудник, который вошёл. Entity L — фото с точкой «в
сети», приветствие по времени суток, имя, должность и деск, кнопки связи:
скопировать телефон, написать письмо, открыть профиль. Под профилем (в
широком тайле — справа) — быстрые действия «Новая встреча» и «Новая задача».

Фото нет или не загрузилось — инициалы (цепочка Avatar: фото → инициалы →
иконка). Пара во фронтенде — `new`; ближайшая — `employees-app/widgets/tiles/ProfileInfoTile`.

## Раскладка (Layout)

```
Tile headless
└── тело (колонка; от 640px своей ширины — строка)
    ├── Entity L
    │   ├── ведущий: Avatar XL circular с фото + Badge dot success (в сети)
    │   ├── Header: приветствие · Label: имя отчество фамилия · Subs: должность · деск
    │   └── Icons: IconButton S — телефон, почта, профиль
    └── действия: Button outline S «Новая встреча» · Button accent S «Новая задача»
```

## Переполнение (Overflow)

| Случай | Правило |
|---|---|
