# NewsTile

## Описание (Purpose)

Лента публикаций о клиентах: дата, источник, заголовок и краткое содержание.
Переключатель — клиенты сотрудника или все клиенты деска. До пяти
новостей, свежие сверху; остальные — «Смотреть все» (в прототипе — уведомление).
Поверхность тайла тонирована, как на макете: лента отделена от рабочих тайлов.

## Раскладка (Layout)

```
Tile (тон --primary-bg; «Новости»; действия: Spinner в обновлении, «Все новости», «Обновить»)
└── тело (колонка)
    ├── SegmentControl S fullwidth — Мои клиенты · Клиенты моего деска
    ├── лента: до 5 записей — дата · источник · «Открыть в источнике» / заголовок / краткое содержание
    └── подвал: «Смотреть все»
```

## Компоненты (Components)

| Компонент | Откуда | Варианты и ключевые параметры |
|---|---|---|
| Tile | ДС | обычный; фон — модификатор концепта (раздел «Осознанные отклонения») |
| SegmentControl | ДС | `.segctrl--s.segctrl--fullwidth`, `data-segctrl` |
| IconButton | ДС | M — шапка; S — `arrow-up-right` «Открыть в источнике» (переход во внешнюю систему) |
| Link | ДС | accent S with-icon — «Смотреть все» |
| Skeleton, Spinner, Alert, Tooltip | ДС | загрузка, обновление, ошибка, подсказки кнопок |

Запись ленты — своя раскладка на токенах ДС (`.lc-news__*`): заголовок
переносится до двух строк, а Label Entity — только одна строка.

## Состояния (States)

| Состояние | Есть в продукте | Вид |
|---|---|---|
| Загрузка (Loading) | да | скелетоны трёх записей |
| Данные есть | да | до 5 записей и «Смотреть все» |
| Заполнено частично | да | нет краткого содержания — только заголовок |
| Данных нет (Empty) | да | «О ваших клиентах новостей пока нет» / «О клиентах деска новостей пока нет» |
| Ошибка (Error) | да | Alert error «Не удалось загрузить новости» + «Повторить» |
| Обновление | да | прежние записи на месте, в шапке Spinner S |
| Редактирование доступно | нет | — |
| Только просмотр (Disabled) | да | единственный режим |
| Нет права видеть | да | тайла нет на странице — решает страница |

## Переполнение (Overflow)

| Случай | Правило |
|---|---|
| Длинный текст в поле | заголовок и краткое содержание — до двух строк с многоточием; источник — одна строка |
| Много строк или записей | до 5 записей, остальное — «Смотреть все» |
| Узкая ширина | запись — колонка, кнопка источника остаётся справа в строке даты |
| Полная ширина | без изменений |

## Поведение (Behavior)

| Триггер | Результат |
|---|---|
| Переключатель «Мои / деска» | лента другой выборки |
