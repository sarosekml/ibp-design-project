# StatCard

## Описание (Purpose)

Показатель-фильтр: число записей выборки, подпись и, у размера M, короткое
пояснение. Клик включает выборку в списке своего тайла, повторный — снимает;
выбранная карточка несёт рамку в своём тоне. Тон кодирует смысл выборки, а не
украшает: «Просрочено» — error, «Сегодня» — warning, «Новые» — accent.

Кандидат в ДС: в ДС нет компонента «показатель с тоном и выбором». Состояния
сделаны по образцу Card (`.tile--card`), тоновые подложки — те же, что у Alert и
SnackBar, поэтому при переносе в ДС меняется только имя класса.

Карточку рисует скрипт тайла функцией `LcStatCard.render()` из шаблона
`#lc-stat-card-tpl`; страница вшивает шаблон один раз.

## Раскладка (Layout)

```
button.lc-stat (или span.lc-stat--static)
├── .lc-stat__label    — подпись
├── .lc-stat__value    — число
└── .lc-stat__caption  — пояснение (только M)
```

У размера S число стоит над подписью, пояснения нет.

## Компоненты (Components)

| Компонент | Откуда | Варианты и ключевые параметры |
|---|---|---|
| Skeleton | ДС | в загрузке тайла вместо карточки — `sk-block--rounded` той же высоты (рисует тайл) |

Своих компонентов ДС внутри нет: карточка — кандидат на новый компонент ДС.

## Поля (Fields)

| Поле | Смысл | Тип, единица | Источник | Обязательное |
|---|---|---|---|---|
| `label` | название выборки | строка, до 20 знаков | тайл | да |
| `value` | число записей в выборке | целое | `HomeStore` (`meetingCounters`, `taskCounters`) | да |
| `caption` | контекст числа | строка | тайл | нет; у S не показывается |

Порядок строк — порядок отображения у размера M. Нет значения — прочерк.

## Права (Permissions)

Не применимо: карточка не правит данные, её клик — фильтр отображения. Видна
всем, кто видит тайл.

## Состояния (States)

| Состояние | Есть в продукте | Вид |
|---|---|---|
| Загрузка (Loading) | да | не рисуется: тайл показывает `sk-block--rounded` той же высоты |
| Данные есть | да | число, подпись, пояснение на тоновой подложке |
| Заполнено частично | нет | — |
| Данных нет (Empty) | да | число «0», карточка остаётся на месте |
| Ошибка (Error) | нет | ошибку показывает тайл |
| Обновление | нет | индикацию держит шапка тайла |
| Редактирование доступно | нет | — |
| Только просмотр (Disabled) | да | `.lc-stat--static` — без наведения и выбора |
| Нет права видеть | нет | решает тайл |

### Свои состояния

| Состояние | Когда | Вид |
|---|---|---|
| Наведение | курсор над кнопкой | рамка в тоне, 40% |
| Выбрана | включён фильтр, `aria-pressed="true"` | рамка в тоне, 100% |
| Фокус | клавиатура | обводка `--primary` 2px, отступ 2px |

## Обязательность заполнения (Required)

- Компонент обязателен к заполнению целиком: нет — это показатель.
- Обязательные поля внутри: `label`, `value`.
- Что показывает, когда обязательное не заполнено: прочерк вместо числа.
- Что отдаёт наружу: `data-stat` — ключ выборки для тайла.

## Переполнение (Overflow)

| Случай | Правило |
|---|---|
| Длинный текст в поле | подпись и пояснение — одна строка с многоточием |
| Много строк или записей | число любой длины, моноширинные цифры |
| Узкая ширина | тайл перестраивает ряд карточек в колонку (`@container` тайла) |
| Полная ширина | карточка тянется на ячейку сетки тайла |
