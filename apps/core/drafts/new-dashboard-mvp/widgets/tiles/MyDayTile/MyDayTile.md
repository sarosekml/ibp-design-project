# MyDayTile

## Описание (Purpose)

План дня сотрудника на одной строке: свои встречи сегодня в порядке времени и
две строки сроков — «Срок сегодня» и «Просрочено». Фаза встречи считается от
текущего времени: прошла (статус встречи), идёт сейчас, ближайшая («Через 1 ч
20 мин»), позже. Подзаголовок — день недели, дата и «сейчас».

Тайл ничего не правит: он ведёт к выборкам. Клик по встрече включает в тайле
«Встречи» выборку «Сегодня», по строке задач — «Сегодня» или «Просрочено» в
тайле «Задачи», и прокручивает к нему. Блока нет на макете — добавлен по
решению человека 09.10.2026.

## Раскладка (Layout)

```
Tile (иконка clock-timer accent, «Мой день», подзаголовок «Пятница, 9 октября · сейчас 12:40»)
└── .entity-list сеткой (5 колонок на 8 колонках страницы, по своей ширине 3 · 2 · 1)
    ├── встреча ×N — Entity M interactive: иконка calendar (ближайшая — accent) · время · клиент · Chip фазы и статуса
    ├── «Срок сегодня» — Entity M: иконка tasks · число задач · Chip «Высокий: N»
    └── «Просрочено» — Entity M: иконка alert-triangle · число задач · Chip «До N дней»
```

## Компоненты (Components)

| Компонент | Откуда | Варианты и ключевые параметры |
|---|---|---|
| Tile | ДС | обычный, иконка заголовка accent, подзаголовок |
| Entity | ДС | M, `--interactive`, `role="button"`; ведущий — `.entity__icon` accent / neutral |
| Chip | ДС | XS rounded: фаза (accent «Через …», info «Идёт сейчас», grey «Прошла») и статус встречи |
| Skeleton, Alert | ДС | загрузка, ошибка |

## Поля (Fields)

| Поле | Смысл | Тип, единица | Источник | Обязательное |
|---|---|---|---|---|
| `startDateTime`, `endDateTime` | время встречи — Header | ЧЧ:ММ–ЧЧ:ММ | `MeetingRsDto` | да |
| `clientName` | клиент — Label | строка | `MeetingRsDto` | да |
| `statusCode` | статус прошедшей и будущей встречи | `MeetingStatusCode` | `MeetingRsDto` | да |
| фаза | прошла · идёт · ближайшая · позже | вычисляется | `HomeStore.day()` от `HomeStore.now` | да |
| задачи со сроком сегодня | число и число с высоким приоритетом | целые | `HomeStore.day()` | да |
| просроченные задачи | число и возраст самой старой | целые, дни | `HomeStore.day()` | да |

Строка задач без задач не показывается.

## Состояния (States)

| Состояние | Есть в продукте | Вид |
|---|---|---|
| Загрузка (Loading) | да | пять скелетонов строк: квадрат 40 и две строки текста |
| Данные есть | да | строки дня, подзаголовок с датой и «сейчас» |
| Заполнено частично | да | нет встреч или нет задач — показываются только существующие строки |
| Данных нет (Empty) | да | «На сегодня встреч нет и сроки задач не горят» |
| Ошибка (Error) | да | Alert error «Не удалось собрать план на день» + «Повторить» |
| Обновление | нет | тайл перерисовывается по событиям хранилища без индикации |
| Редактирование доступно | нет | — |
| Только просмотр (Disabled) | да | единственный режим |
| Нет права видеть | да | тайла нет на странице — решает страница |

### Свои состояния

| Состояние | Когда | Вид |
|---|---|---|
| Ближайшая встреча | первая встреча, которая ещё не началась | иконка accent, Chip «Через N ч M мин»; требует внимания — второй Chip warning |
| Идёт сейчас | начало ≤ сейчас < окончание | иконка accent, Chip info «Идёт сейчас» |
| Прошла | окончание ≤ сейчас | иконка neutral, Chip статуса встречи (назначенная — grey «Прошла») |

## Обязательность заполнения (Required)

- Компонент обязателен к заполнению целиком: нет.
- Обязательные поля внутри: см. «Поля».
- Что показывает, когда обязательное не заполнено: не применимо.
- Что отдаёт наружу: `HomeStore.focus(widget, filter)` — просьбу показать выборку.

## Переполнение (Overflow)

| Случай | Правило |
|---|---|
| Длинный текст в поле | клиент — одна строка с многоточием |
| Много строк или записей | строк больше колонок — следующий ряд сетки |
| Узкая ширина | колонок 5 → 3 (≤ 960px своей ширины) → 2 (≤ 600) → 1 (≤ 380) |
| Полная ширина | 5 колонок |

## Поведение (Behavior)

| Триггер | Результат |
|---|---|
| Клик, Enter, Space по встрече | `HomeStore.focus('meetings', 'today')` — тайл «Встречи» показывает встречи сегодня |
| … по «Срок сегодня» | `HomeStore.focus('tasks', 'today')` |
| … по «Просрочено» | `HomeStore.focus('tasks', 'overdue')` |
| Создана встреча, изменён статус задачи (события `meetings`, `tasks`) | строки дня пересчитываются |
| «Повторить» | `loading` 0,7 с → данные |
