# TaskCreateModal

## Описание (Purpose)

Окно создания задачи с главной: формулировка, срок, приоритет, клиент и номер
сделки. Задача ставится себе и приходит со статусом «Новая» — её видно в
счётчике «Новые», а если срок сегодня — и в «Моём дне». Списки и ошибки полей
окно берёт у общего слоя форм `LcHomeForm` (`MeetingCreateModal.js`).

## Раскладка (Layout)

```
Modal --w4 (заголовок «Новая задача», крестик)
├── тело (одна колонка)
│   ├── InputText «Задача*»
│   ├── InputDate «Срок*»
│   ├── SegmentControl fullwidth «Приоритет*» — Высокий · Средний · Низкий
│   ├── список «Клиент» (первая строка — «Без клиента»)
│   └── InputText «Номер сделки»
└── подвал справа: «Отменить» · «Создать задачу»
```

| Поле | Смысл | Тип, единица | Источник | Обязательное |
|---|---|---|---|---|

## Обязательность заполнения (Required)

- Компонент обязателен к заполнению целиком: нет — клиент и сделка необязательны.
- Обязательные поля внутри: «Задача», «Срок», «Приоритет» — звёздочка `ds-label__req`.
- Что показывает, когда обязательное не заполнено: ошибка поля, фокус — на первое ошибочное.
- Что отдаёт наружу: `HomeStore.addTask(rq)`.

Проверки: срок — формат ДД.ММ.ГГГГ и не раньше сегодня; номер сделки, если
есть, — `D-` и шесть цифр.

## Переполнение (Overflow)

| Случай | Правило |
|---|---|
| Длинный текст в поле | формулировка — до 160 знаков |
| Много строк или записей | список клиентов прокручивается |
| Узкая ширина | окно — шаг колонок `--w4` |
| Полная ширина | не применимо |

## Поведение (Behavior)

| Триггер | Результат |
|---|---|
| Открытие любым триггером | поля сбрасываются |
| «Создать задачу» с ошибками | ошибки полей, окно открыто |
| «Создать задачу» без ошибок | задача в `HomeStore`, окно закрывается, уведомление «Задача создана · срок» |
| «Отменить», крестик, Esc | окно закрывается без сохранения |
