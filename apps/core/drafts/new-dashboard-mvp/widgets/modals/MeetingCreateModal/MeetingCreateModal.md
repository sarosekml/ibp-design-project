# MeetingCreateModal

## Описание (Purpose)

Окно создания встречи с главной: клиент, тема, дата, начало и окончание.
Встреча создаётся сотрудником — она появляется в «Моих встречах», а если она
сегодня — и в «Моём дне». Полная карточка встречи — в разделе «Встречи»,
которого в прототипе нет.

Файл окна несёт и общий слой форм главной `window.LcHomeForm` (список выбора,
ошибка поля, разбор даты) — его берёт и окно `TaskCreateModal`: одно правило —
один владелец.

## Раскладка (Layout)

```
Modal --w4 (заголовок «Новая встреча», крестик)
├── тело (одна колонка)
│   ├── InputAutocomplete-список «Клиент*»
│   ├── InputText «Тема встречи*»
│   ├── ряд «Когда»: InputDate «Дата*» · список «Начало*» · список «Окончание*»
│   └── Note — где появится встреча
└── подвал справа: «Отменить» · «Создать встречу»
```

## Обязательность заполнения (Required)

- Компонент обязателен к заполнению целиком: да — все четыре поля «Клиент», «Тема», «Дата», «Начало», «Окончание».
- Обязательные поля внутри: помечены звёздочкой `ds-label__req`.
- Что показывает, когда обязательное не заполнено: ошибка поля, фокус — на первое ошибочное.
- Что отдаёт наружу: `HomeStore.addMeeting(rq)`.

Проверки: дата — формат ДД.ММ.ГГГГ и не раньше сегодня; окончание позже начала.

## Переполнение (Overflow)

| Случай | Правило |
|---|---|
| Длинный текст в поле | тема — до 120 знаков; клиент в списке — многоточие |
| Много строк или записей | списки прокручиваются (`ddl--scroll`) |
| Узкая ширина | окно — шаг колонок `--w4`, ряд «Когда» сжимается |
| Полная ширина | не применимо |

## Поведение (Behavior)

| Триггер | Результат |
|---|---|
| Открытие любым триггером | поля сбрасываются к значениям по умолчанию |
| «Создать встречу» с ошибками | ошибки полей, окно открыто |

| «Отменить», крестик, Esc | окно закрывается без сохранения |
